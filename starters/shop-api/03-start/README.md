# shop-api — шаг 3 из 5: Фильтры и проверка query

Учебный проект из урока «Express на TypeScript». Эта папка — состояние **до** шага 3: всё из предыдущих шагов уже сделано.

## Задание

Поддержите в `GET /api/products` параметры `search` (по названию, без учёта регистра), `category`, `minPrice`, `maxPrice`. Нечисловая или отрицательная цена — 400. Логику фильтрации вынесите в чистую функцию `filterProducts` в `src/domain/products.ts`.

## Как работать

```bash
npm install
npm test          # тесты этого шага красные — это нормально
npm run dev       # сервер с перезапуском при изменениях
npm run typecheck # проверка типов (tsx её не делает)
```

Шаг готов, когда `npm test` и `npm run typecheck` проходят без ошибок. Тесты в `tests/` не меняйте: они — требования.
Решение шага — в папке `04-start`.
