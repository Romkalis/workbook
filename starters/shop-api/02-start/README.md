# shop-api — шаг 2 из 5: Товар по id и обработка ошибок

Учебный проект из урока «Express на TypeScript». Эта папка — состояние **до** шага 2: всё из предыдущих шагов уже сделано.

## Задание

Добавьте `GET /api/products/:id`. Если товара нет, бросьте `HttpError(404, 'Товар не найден')`. Подключите после маршрутов middleware для 404 и общий обработчик ошибок, который превращает `HttpError` в JSON `{ error }`, а остальное — в 500.

## Как работать

```bash
npm install
npm test          # тесты этого шага красные — это нормально
npm run dev       # сервер с перезапуском при изменениях
npm run typecheck # проверка типов (tsx её не делает)
```

Шаг готов, когда `npm test` и `npm run typecheck` проходят без ошибок. Тесты в `tests/` не меняйте: они — требования.
Решение шага — в папке `03-start`.
