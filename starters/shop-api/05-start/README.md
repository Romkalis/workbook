# shop-api — шаг 5 из 5: CORS и конфигурация

Учебный проект из урока «Express на TypeScript». Эта папка — состояние **до** шага 5: всё из предыдущих шагов уже сделано.

## Задание

Разрешите запросы с адреса фронтенда из переменной `CLIENT_ORIGIN` (по умолчанию `http://localhost:5173`) через пакет `cors`. Вынесите чтение `PORT` и `CLIENT_ORIGIN` в `loadConfig(env)` с проверкой порта.

## Как работать

```bash
npm install
npm test          # тесты этого шага красные — это нормально
npm run dev       # сервер с перезапуском при изменениях
npm run typecheck # проверка типов (tsx её не делает)
```

Шаг готов, когда `npm test` и `npm run typecheck` проходят без ошибок. Тесты в `tests/` не меняйте: они — требования.
Решение шага — в папке `06-done`.
