# shop-api — шаг 1 из 5: Список товаров

Учебный проект из урока «Express на TypeScript». Эта папка — состояние **до** шага 1: всё из предыдущих шагов уже сделано.

## Задание

Добавьте маршрут `GET /api/products`: он отдаёт массив `PRODUCTS` из `src/data/products.ts`. Ответ типизируйте как `Response<Product[]>`.

## Как работать

```bash
npm install
npm test          # тесты этого шага красные — это нормально
npm run dev       # сервер с перезапуском при изменениях
npm run typecheck # проверка типов (tsx её не делает)
```

Шаг готов, когда `npm test` и `npm run typecheck` проходят без ошибок. Тесты в `tests/` не меняйте: они — требования.
Решение шага — в папке `02-start`.
