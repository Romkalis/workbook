# shop-api — шаг 4 из 5: Расчёт корзины

Учебный проект из урока «Express на TypeScript». Эта папка — состояние **до** шага 4: всё из предыдущих шагов уже сделано.

## Задание

Добавьте `POST /api/cart/quote`. Тело `{ items: { productId, quantity }[], promo? }` проверяется type guard: неверное тело — 400. Цены берутся с сервера. Ответ `{ subtotal, discount, total }`, промокод `SALE10` даёт 10%.

## Как работать

```bash
npm install
npm test          # тесты этого шага красные — это нормально
npm run dev       # сервер с перезапуском при изменениях
npm run typecheck # проверка типов (tsx её не делает)
```

Шаг готов, когда `npm test` и `npm run typecheck` проходят без ошибок. Тесты в `tests/` не меняйте: они — требования.
Решение шага — в папке `05-start`.
