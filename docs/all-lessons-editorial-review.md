# Редакторская проверка всех уроков

Проверены семь уроков. Цель — сделать термины, порядок изложения, примеры и самопроверку понятнее человеку, который изучает программирование.

| Урок | Основные изменения |
|---|---|
| Основы ООП | Расшифровка ООП, объяснение интерфейса и композиции; исправлено размещение обычных методов в прототипе, конструктор по умолчанию и чрезмерные обобщения; уточнены чтение UML и число вопросов теста. |
| Classes & Prototypes | Различены внутренняя ссылка прототипа и свойство конструктора, собственные и перечисляемые свойства; добавлен порядок чтения наследования и примесей; уточнены super и конструктор по умолчанию. |
| Chrome DevTools | Раньше объяснены DOM, узел, селектор, origin, брейкпоинт и стек; уточнены запуск демо-сервера и смысл диагностических подсветок. Rendering перенесён перед практикой, источники находятся в конце. |
| Как работают браузеры | Введён словарь стадий, процессов и потоков; уточнены HTML-парсинг, paint/raster, условия композиции и перерасчёта; исправлены обобщения о passive и тяжёлой работе в requestAnimationFrame. |
| TypeScript Basic | Объяснены компилятор, контракт, аннотация, сужение, generic и сигнатура; уточнены последовательность запуска, смысл enum и импортов типов. |
| Design Patterns | Раньше определены клиент, контракт, продукт и делегирование; каждый из 15 примеров дополнен трассировкой вызовов; отдельно объяснены iterator/iterable, генератор, middleware, контекст и отписка. |
| TypeScript Advanced | Сохранена предыдущая подробная редактура; уточнён оставшийся термин в итоговом списке. |

Изменены формулировки вопросов и пояснений, которые могли закреплять прежние обобщения. Записи кода в тестах с обратными кавычками преобразованы в HTML code для штатного отображения. Позиции правильных ответов сохранены.

Технические уточнения сверены с первоисточниками: [MDN Classes](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Classes), [MDN getPrototypeOf](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Global_Objects/Object/getPrototypeOf), [MDN method definitions](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Functions/Method_definitions), [web.dev о layout thrashing](https://web.dev/articles/avoid-large-complex-layouts-and-layout-thrashing), [Chrome: renderer process](https://developer.chrome.com/blog/inside-browser-part3), [MDN addEventListener](https://developer.mozilla.org/en-US/docs/Web/API/EventTarget/addEventListener), [MDN requestAnimationFrame](https://developer.mozilla.org/en-US/docs/Web/API/Window/requestAnimationFrame) и [web.dev rendering performance](https://web.dev/articles/rendering-performance). Это уточнения учебной модели, а не обещание одинакового внутреннего устройства всех браузеров.

## Проверки результата

- 115 HTML-разделов: корректная вложенность разметки.
- Все 415 существующих якорей сохранены, включая тесты; перестановка Rendering не меняет адреса ссылок.
- Все 138 блоков pre с кодом побайтно совпадают с исходным состоянием этой редакторской задачи. Они не переписывались и повторно не исполнялись в рамках этой вычитки.
- Оглавления и внутренние ссылки проверены существующими функциями учебника.
- 21 поисковый запрос, по три на урок: результаты находятся и ведут к существующим якорям.
- Все 183 вопроса: четыре различных варианта, допустимый индекс правильного ответа и непустое пояснение; позиции правильных ответов не изменены.
- `npm run typecheck` и `npm run build` завершились без ошибок.
- Зависимости, стили и компоненты интерфейса не менялись.

## Непроверенное

Браузерный хост вернул `The browser access host is unavailable`. Поэтому в этой задаче не выполнены визуальная проверка обеих тем, интерактивное прохождение тестов и эмуляция 430×932, DPR 3. Статическая проверка разметки не подтверждает отсутствие горизонтальной прокрутки. Эти пункты остаются для проверки после восстановления браузера.
