# Проверка TypeScript Advanced

Урок: `/lessons/typescript-advanced`, Stage 2, order 7.

## Полнота содержания

Урок содержит 19 разделов, 25 самостоятельных TS-примеров, проверочный проект Webpack/ESLint, практические задачи и 42 вопроса с объяснениями.

Покрыты темы программы RS School: встроенные guards и пользовательские предикаты, generics и ограничения, utility types, mapped types, conditional types и infer, литеральные и шаблонные строковые типы, tsconfig, сборка и миграция JS в TS. Есть план подготовки к News API и указание на обязательный `[St2] TS Advanced`.

Ссылки на программу, письменные первоисточники и статусы разбора сохранены в разделе источников. Видео и отдельные дополнительные статьи не разобраны; это явно указано. Сам проект News API в рамках урока не реализован.

## Редакторская проверка с позиции студента

Исправлены следующие препятствия для чтения:

- Компилятор, runtime, контракт и DTO объясняются в начале, а не только в итоговом словаре.
- Английские названия сопровождаются русским смыслом. Отдельно объяснены предикат, сужение типа, частичное обновление, alias, source map, fixture и CI.
- У сложных примеров появились разборы подстановок: что такое T, K и T[K], что получится из Parameters/ReturnType/Awaited, как работают infer и распределение объединения.
- Первый пример infer упрощён: извлечение элемента массива и возврат исходного типа вместо сопоставления функции через never[].
- Переименование ключей с условием и шаблонной строкой перенесено после объяснения этих конструкций. Идентификаторы заголовков сохранены.
- Распределяемый Omit перенесён после conditional types и помещён в раскрываемое дополнение.
- NoInfer и утилиты this явно помечены как дополнительные темы.
- Инструкция Playground указывает strict, noUncheckedIndexedAccess, exactOptionalPropertyTypes и target ES2020. Объяснено, почему при других настройках директива ожидаемой ошибки может не сработать.
- Порядок создания отдельного сборочного проекта уточнён: папка, package.json, src, конфигурации, объединение scripts и ожидаемый результат команд.
- Формулировки теста упрощены, включая удаление необъяснённого naked type parameter. Содержание ответов и их позиции сохранены.

## Проверки

- Проверена вложенность HTML и уникальность якорей.
- Все 25 TS-примеров извлечены из окончательных HTML-файлов, скомпилированы со strict и двумя дополнительными флагами, выполнены в Node.js. Намеренные ошибки подтверждены через @ts-expect-error. Результат упрощённого примера infer проверен отдельно.
- Проверены существующие функции загрузки контента, оглавления и поиска: 45 подтем, 65 якорей с учётом теста; 20 поисковых запросов ведут к существующим якорям.
- В 42 вопросах по четыре различных варианта, один отмеченный правильный и объяснение. Позиции правильных ответов: 11 / 11 / 10 / 10.
- Учебные конфигурации Webpack и ESLint ранее выполнены в отдельной временной папке: положительная сборка, source map и запуск bundle, отклонение неверного аргумента компилятором и сборкой, отклонение explicit any линтером. При редактуре эти конфигурации не менялись.
- `npm run typecheck` и `npm run build` выполнены успешно.
- Зависимости и интерфейс учебника не менялись.
