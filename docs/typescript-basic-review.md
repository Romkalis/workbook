# Проверка урока TypeScript Basic

Дата: 1 ноября 2026. Урок: `/lessons/typescript-basic`, Stage 2, сквозной order 5.

## Соответствие программе

Программа сверена с README RS School:
https://github.com/rolling-scopes-school/tasks/tree/master/stage2/modules/typescript-basic
(прочитан raw README, поскольку HTML-страница GitHub не открылась).

| Критерий | Где раскрыт |
|---|---|
| Читать и писать TS, отличать от JS | `ts-start`, `ts-inference`, `ts-practice` |
| Примитивы, массивы, кортежи, null/undefined | `ts-primitives`, `ts-special` |
| Interface, type, object types, различия и совместимость | `ts-objects` |
| Union, intersection и narrowing | `ts-unions` |
| Any, unknown, never, void | `ts-special`, `ts-unions` |
| Функции, optional/default/rest, колбэки, this, Promise, перегрузки | `ts-functions` |
| Generic, constraints, keyof, indexed access | `ts-generics` |
| Type inference | `ts-inference` |
| Type assertions, non-null assertion, const assertions, satisfies | `ts-assertions` |
| Классы, интерфейсы, доступ, abstract, наследование | `ts-classes` |
| Enum, обратное отображение, альтернативы | `ts-enums` |
| Модули, import/export, import type, namespace, .d.ts | `ts-modules` |
| Самостоятельное чтение и написание кода | Три практические задачи с критериями в `ts-practice` |
| Обязательная практика школы | Явная инструкция пройти `[St2] TS Basic` в RS-App → Auto Test |
| Дополнительные материалы | `ts-sources`: все ссылки программы, инструменты и честные статусы разбора |

Проверена полнота покрытия перечисленных учебных тем, а не совпадение с закрытым банком вопросов RS-App. Курсы Scrimba и видеоматериалы не разобраны; это явно указано в уроке. Техническая основа — официальная документация TypeScript из программы и дополнительные официальные разделы. Советы и utility types вне списка помечены как дополнение из общих знаний.

## Пройденные проверки

- 15 HTML-разделов, 38 подтем. По одному section и h2 на файл; все 54 якоря, включая тест, уникальны.
- Stage 2, order 5: сквозные номера уроков не повторяются.
- 31 TS-пример: 29 отдельных фрагментов и два связанных файла модуля. Проверены локальным TypeScript с `strict`, ES2020, CommonJS; выпущенный JS запущен в Node.js. Намеренные ошибки подтверждены через `@ts-expect-error` внутри неисполняемых веток. Это не тест установки npm и не проверка всех окружений запуска.
- 32 вопроса: четыре различных варианта, один отмеченный правильный, у каждого есть объяснение. Правильные позиции распределены равномерно: по 8 на каждую.
- Тексты теста экранированы для вывода через существующий HTML-рендерер: generic-сигнатуры с угловыми скобками не превращаются в теги.
- Оглавление и 38 ссылок на подтемы соответствуют существующим якорям.
- Реальный алгоритм поиска находит урок по 14 запросам: TypeScript, interface, union, intersection, unknown, never, satisfies, keyof, generic, enum, namespace, модули, вывод типов, утверждение. Найденные ссылки ведут к существующим якорям.
- Источники оформлены отдельным `section.sources`; существующий механизм вставляет тест перед ними.
- Используются существующие компоненты контента. Новых зависимостей, CSS, внешних изображений, фиксированных ширин и анимаций нет.
- `npm run typecheck` и `npm run build` выполнены успешно.

## Не удалось проверить

Браузерный хост недоступен как для Chrome, так и для встроенного браузера (`The browser access host is unavailable`). Поэтому визуальная проверка обеих тем, интерактивное прохождение теста и точная эмуляция 430×932, DPR 3 не выполнены. Отсутствие новых стилей не заменяет эту проверку.

Когда браузер станет доступен:

1. Открыть урок в светлой и тёмной темах, проверить код, таблицу и вопросы.
2. Эмулировать 430×932, DPR 3. Проверить `document.documentElement.scrollWidth === 430` и `visualViewport.scale === 1`, локальную прокрутку кода и таблицы.
3. Открыть поиск, перейти к satisfies и keyof, проверить положение заголовков после перехода из оглавления.
4. Ответить на вопросы теста, проверить объяснения, итог и сброс ответов.
