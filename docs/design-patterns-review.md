# Проверка урока Design Patterns

Дата: 1 ноября 2026. Урок: `/lessons/design-patterns`, Stage 2, сквозной order 6.

## Покрытие программы

Прочитаны README [модуля RS School](https://github.com/rolling-scopes-school/tasks/tree/master/stage2/modules/design-patterns) и связанное [задание Codewars](https://github.com/rolling-scopes-school/tasks/blob/master/tasks/codewars/Codewars-2022Q1-DP.md) через raw-доступ. Все 15 письменных страниц Refactoring Guru из программы открыты и разобраны. Ссылки на источники есть рядом с каждым паттерном и в заключительном разделе урока.

| Критерий | Разделы / якоря |
|---|---|
| Понятие паттерна, польза, цена, три группы | `patterns-intro`, `patterns-compare` |
| Порождающие: Factory Method, Abstract Factory, Builder, Singleton | `factory-method`, `abstract-factory`, `builder`, `singleton` |
| Структурные: Adapter, Decorator, Facade, Proxy | `adapter`, `decorator`, `facade`, `proxy` |
| Поведенческие: Chain of Responsibility, Command, Iterator | `chain-of-responsibility`, `command`, `iterator` |
| Поведенческие: Mediator, Observer, State, Visitor | `mediator`, `observer`, `state`, `visitor` |
| Применение в проекте | `patterns-project`: мини-проект и проверяемые критерии |
| Дополнительные темы обязательных упражнений | `strategy-choice`, `dependency-injection`, `sortable-shapes` |
| Codewars Design Patterns | `patterns-codewars`: девять ссылок из задания |
| Обязательный Auto Test | `patterns-school-test`: `[St2] Design Patterns` в RS App |
| Ориентир 6 часов, повторение и словарь | `patterns-practice`, `patterns-checklist` |
| Источники и границы разбора | `patterns-sources` |

Для каждого из 15 паттернов описаны задача, роли, направление вызова, работающий пример, результат и ограничения. Отдельно сравниваются Factory Method и простая фабрика; Adapter, Decorator, Proxy и Facade; Mediator и Observer; State и Strategy. Отмечены цена новых видов продуктов в Abstract Factory и новых видов элементов в Visitor, ограничения Singleton, правила отписки и предположения отмены Command.

Дополнительные источники: Strategy от Refactoring Guru, статья Мартина Фаулера о DI, MDN о протоколах итерации и JS Proxy. Эти источники и дополнения из общих знаний обозначены в уроке. Три видеозаписи модуля не разобраны; это явно указано. Условия отдельных kata и закрытый банк RS App не изучались, задания от имени студента не отправлялись. Старые правила Codewars 2022Q1 отделены от расписания текущего потока.

## Выполненные проверки

- Урок загружается существующим механизмом контента: 21 раздел, 62 подтемы. Stage 2, order 6 не конфликтует с другими уроками.
- Все 84 якоря, включая тест, уникальны. Ссылки общего оглавления и поиска соответствуют существующим якорям.
- 17 независимых TS-примеров прошли строгую компиляцию с ES2020/CommonJS и запуск в Node.js с проверками результатов через `node:assert/strict`.
- Дополнительно к результатам примеров проверены: ошибка незаполненного Builder, неизвестный id Facade, число обращений к источнику Proxy, остановка цепочки на пустом и слишком длинном запросе, отмена истории, независимость и завершение обходов, отписка Observer, последовательность состояний, результат Visitor и отсутствие мутации массива при сортировке Strategy.
- В Visitor параметр результата `R` позволяет другому посетителю вернуть другой тип без изменения классов элементов.
- Проверена вложенность HTML. В каждом файле один section и один h2; у h3 есть уникальный id. Источники оформлены как `section.sources`, тест вставляется перед ними существующим компонентом.
- В 40 вопросах по четыре различных варианта и по одному отмеченному правильному ответу, у каждого есть объяснение. Правильные позиции: 10 / 10 / 10 / 10. Тексты экранированы для существующего HTML-рендерера.
