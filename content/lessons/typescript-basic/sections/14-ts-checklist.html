Аннотация
Явная запись типа в исходнике.
Inference
Вывод типа из значения и контекста.
Narrowing
Сужение набора возможных типов после проверки.
Structural typing
Совместимость по форме, а не только по имени объявления.
Discriminant
Общее поле с литеральными значениями, различающее варианты union.
Generic
Параметр типа, сохраняющий зависимость частей контракта.
Assertion
Утверждение программиста о типе без проверки данных.
Runtime
Время выполнения JavaScript, когда большинства TS-типов уже нет.
