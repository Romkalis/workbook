any, unknown, never и void

Разделяйте две ситуации: неизвестно, что пришло снаружи (unknown), и значение вообще невозможно получить на данном пути (never). Void описывает результат, который вызывающий код не использует. Ни один из этих типов не является командой преобразовать реальные данные.

Доверять данным или проверять их

any отключает значимую проверку операций: можно обращаться к несуществующим полям и передавать значение дальше почти куда угодно. Ошибка обнаружится лишь при выполнении. unknown тоже принимает любое значение, но не позволяет пользоваться им до проверки. Для непроверенных внешних данных это удобная отправная точка.

function readTitle(value: unknown): string {
  if (typeof value === "object" && value !== null && "title" in value) {
    if (typeof value.title === "string") return value.title;
  }
  throw new Error("Ожидался объект со строковым title");
}
const raw: unknown = JSON.parse('{"title":"Учебник"}');
console.log(readTitle(raw));
try { readTitle({ title: 5 }); }
catch { console.log("Некорректные данные отклонены"); }

JSON.parse обычно возвращает any. Явно сохранив результат как unknown, мы обязуемся проверить форму. Предикат value is Student может оформить такую проверку в переиспользуемую функцию, но его реализация должна действительно проверять нужные поля: компилятор доверяет написанному предикату.

Невозможный результат и игнорируемый результат

never не содержит ни одного значения: функция всегда бросает исключение или не заканчивает выполнение, либо ветка логически недостижима. void в контракте колбэка означает, что вызывающий код не использует результат. undefined — конкретное значение, это другая идея.

function fail(message: string): never { throw new Error(message); }
const items: string[] = [];
const save: (text: string) => void = text => items.push(text);
save("TS");
console.log(items.length); // 1
try { fail("Нет урока"); } catch { console.log("Ошибка обработана"); }

push возвращает число, но функция подходит колбэку с результатом void: контракт позволяет проигнорировать число. Из этого не следует, что функция с явной аннотацией function f(): void может возвращать любое значение.
