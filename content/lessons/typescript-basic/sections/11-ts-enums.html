Enum и альтернативы

В enum Phase { Draft, Review, Done } имена обозначают числа 0, 1 и 2. Прочитайте обе стороны: Phase.Review получает число 1, Phase[1] получает строку "Review". Это обратное отображение есть у числового enum, но не у строкового.

Enum именует набор вариантов и обычно создаёт объект в JavaScript. Это отличает его от union строковых литералов, который существует только при проверке типов.

Числовой и строковый enum

enum Phase { Draft, Review, Done }
enum Role { Student = "student", Mentor = "mentor" }
console.log(Phase.Draft, Phase.Done, Phase[1]); // 0 2 Review
console.log(Role.Student); // student

Без инициализатора числовые значения идут от нуля; после явно заданного числа продолжают увеличиваться. Числовой enum создаёт обратное отображение: по 1 можно получить Review. У строкового enum обратного отображения нет, значения задаются явно. Избегайте смешанных enum без особой необходимости: их труднее читать.

Когда достаточно объекта или union

const Phase = { Draft: "draft", Done: "done" } as const;
type Phase = typeof Phase[keyof typeof Phase];
function statusText(phase: Phase): string {
  return phase === Phase.Done ? "Готово" : "Черновик";
}
console.log(statusText("done"));

Объект нужен при выполнении, если требуется Phase.Done или перебор вариантов; union подходит, если нужен только контракт. const enum обычно встраивает значения в места использования и не создаёт обычного объекта enum. У него есть ограничения при сборке некоторыми инструментами, поэтому для первых упражнений проще обычный enum или объект as const. Учтите: в новых проектах иногда включают настройку erasableSyntaxOnly. Она разрешает только такой TypeScript, который можно превратить в JavaScript простым удалением типов. Enum так не превратить (он создаёт объект), поэтому с этой настройкой он запрещён.
