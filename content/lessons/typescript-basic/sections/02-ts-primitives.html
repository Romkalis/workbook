Примитивы, массивы и кортежи

Примитив — простое значение вроде строки, числа или boolean, в отличие от объекта с полями. Union, или объединение, записывают через вертикальную черту: string | null разрешает строку либо null. Кортеж — массив с заранее заданным смыслом и типом каждой позиции.

Аннотация задаёт множество допустимых значений. Пишите string, number, boolean со строчной буквы: String, Number, Boolean относятся к объектным обёрткам. Отдельных типов int и float нет.

Семь видов примитивных значений

let title: string = "Учебник";
let progress: number = 0.5;
let finished: boolean = false;
const big: bigint = 12n;
const key: symbol = Symbol("lesson");
let missing: undefined = undefined;
let empty: null = null;
console.log(title, progress, finished, big, typeof key, missing, empty);
if (false) {
  // @ts-expect-error: boolean не принимает строку
  finished = "false";
}

bigint — целые произвольной точности, symbol — уникальные идентификаторы. Для литералов bigint нужен подходящий target, здесь ES2020. null и undefined при строгой проверке не подставляются произвольно вместо строки или числа. Если отсутствие допустимо, добавьте его явно через объединение: string | null.

Массив — повторяющиеся элементы, кортеж — известные позиции

const scores: number[] = [80, 95];
const names: Array<string> = ["Анна", "Лев"];
const pair: [string, number] = ["Анна", 95];
const point: readonly [number, number] = [10, 20];
console.log(scores.map(n => n + 1), names.join(", "), pair[1], point[0]);
if (false) {
  // @ts-expect-error: массив принимает только числа
  scores.push("100");
  // @ts-expect-error: readonly запрещает запись через point
  point[0] = 5;
}

number[] и Array<number> равнозначны. В кортеже [string, number] первый элемент — строка, второй — число; порядок важен. readonly запрещает запись только на этапе проверки: редактор подчеркнёт scores[0] = 5. После компиляции типов не остаётся, и в работающей программе массив можно изменить, как обычно. Ещё одна ловушка: для массива number[] TypeScript считает, что scores[100] — это number, хотя на деле там undefined. Флаг noUncheckedIndexedAccess в tsconfig исправляет это: тип становится number | undefined, и компилятор заставит проверить значение.

Когда нужен кортеж вместо массива?

Когда позиции имеют разный смысл и известный порядок: например, координаты или пара «имя, балл». Для списка учеников нужен массив объектов.
