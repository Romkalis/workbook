Вывод типов и литеральные типы

Вывод типа можно увидеть, наведя курсор на переменную в редакторе. «Расширение литерала» означает переход от одного значения, например типа "read", к более широкому string, разрешающему другие строки. Колбэк — функция, которую передают другой функции для вызова позже или во время обработки элементов.

Type inference означает, что компилятор восстанавливает тип по значению и контексту. Аннотация полезна на границе функции или структуры данных; дублировать очевидный тип каждого числа обычно не нужно.

Почему let и const выводятся по-разному

let mode = "read"; // string: переменную можно переназначить
const fixed = "read"; // литеральный тип "read"
const settings = { mode: "read" }; // mode: string
settings.mode = "write";
type Mode = "read" | "write";
function describe(mode: Mode): string {
  return mode === "read" ? "Чтение" : "Запись";
}
console.log(describe(fixed), settings.mode);
if (false) {
  // @ts-expect-error: произвольная строка шире Mode
  describe(mode);
}

Литеральный тип разрешает одно значение, например "read" или 200. Union литералов описывает ограниченный набор состояний. const запрещает переназначить переменную, но свойства её объекта могут изменяться, поэтому settings.mode расширяется до string.

Контекстная типизация

const lengths = ["type", "interface"].map(word => word.length);
const values = [1, "two"]; // (string | number)[]
console.log(lengths, values);
// word получил string из типа массива, а результат map — number[]

В колбэке не нужно снова писать тип word: его даёт сигнатура map. Если вывести желаемое ограничение нельзя, укажите его: let result: string | undefined. При чтении чужого кода начните с параметров и возвращаемого типа, затем проследите ветвления и посмотрите подсказку редактора в каждой ветке.
