Практика: от чтения к самостоятельному коду

Ориентир модуля — около 11 часов вместе с теорией и упражнениями. Рабочий план из общих знаний: 2 часа на запуск, примитивы и вывод; 2 часа на объекты и union; 2 часа на функции, generics и keyof; 2 часа на классы, enum и модули; 3 часа на практику, повторение и тест. Меняйте темп по результатам задач.

Задание 1. Прочитайте типы до запуска

Для выражений let x = "a", const y = "a", const z = { x: "a" } назовите типы x, y и z.x. Затем объясните разницу между string | number, unknown и never. Проверьте ответы подсказками Playground.

Ответ и критерий

Получатся string, литеральный тип "a" и string. Union разрешает один из вариантов и требует сужения перед специфическими операциями. Unknown принимает любые данные, но требует проверки перед использованием. Never обозначает отсутствие возможного значения.

Задание 2. Напишите безопасный разбор данных

Напишите функцию, которая получает unknown и возвращает объект со строковым title и числовым duration либо бросает Error. Не используйте any, as и !. Проверьте корректный объект, null, пустой объект и duration строкой. Успех — все некорректные значения отклоняются до использования полей.

Один из вариантов решения

Сначала исключите null и проверьте typeof value === "object", затем наличие полей через in, после — typeof каждого поля. Верните новый объект из проверенных полей. Дополнительно решите, допустимы ли NaN, Infinity и отрицательная длительность.

Задание 3. Мини-проект «Каталог уроков»

В model.ts объявите интерфейс Lesson с readonly id, title и duration и union состояния загрузки. В catalog.ts реализуйте generic-функцию get по ключу и функцию суммарной длительности. В main.ts импортируйте тип отдельно от значений и выведите результат. Ограничьте фильтр строковыми литералами, проверьте его конфигурацию через satisfies. Реализуйте класс каталога с приватным массивом и публичным методом добавления.

Критерии: строгая компиляция без any и необоснованных утверждений; неизвестные входные данные проверяются; пустой каталог даёт 0; фильтр не принимает опечатку; все состояния загрузки обработаны; тип выбранного поля сохраняется. Проверьте также намеренные ошибки — строку вместо duration и несуществующий ключ. Ожидаемая ошибка должна быть объяснима, а не просто подавлена.
