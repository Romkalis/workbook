Функции: параметры, колбэки и перегрузки

Сигнатура — описание параметров и результата функции. Optional-параметр можно пропустить, default задаёт значение по умолчанию, rest собирает дополнительные аргументы. Перегрузки — несколько разрешённых способов вызова одной функции, а не несколько выполняемых тел.

Сигнатура показывает вход и выход. Проверяйте типы параметров, обязательность аргументов и все пути возврата. Аннотируйте публичный результат, если хотите защитить контракт от случайного изменения реализации.

Optional, default и rest

function greet(name: string, prefix = "Привет", suffix?: string): string {
  return `${prefix}, ${name}${suffix ?? "!"}`;
}
function sum(...values: number[]): number {
  return values.reduce((total, value) => total + value, 0);
}
type Transform = (value: number) => number;
const square: Transform = value => value * value;
console.log(greet("Маша"), sum(1, 2, 3), square(4));

Optional-параметр имеет внутри функции тип с undefined; необязательные параметры ставят после обязательных. Значение по умолчанию срабатывает при пропуске или undefined, но не при null. Rest собирает остаток аргументов в массив. В типе функции стрелка отделяет тип результата, а в обычном объявлении для этого используется двоеточие.

Контракт колбэка и this

Не добавляйте index? в тип колбэка «на всякий случай»: это обещает, что вызывающая сторона вправе не передать index. Если индекс всегда передаётся, пишите number; обработчик, которому он не нужен, просто объявит меньше параметров. Специальный первый параметр this описывает контекст вызова и стирается из JS.

function show(this: { title: string }, prefix: string): string {
  return prefix + this.title;
}
console.log(show.call({ title: "TypeScript" }, "Урок: "));
async function loadCount(): Promise<number> { return 3; }
void loadCount().then(count => console.log(count));

Результат async-функции всегда обёрнут в Promise. Здесь Promise<number> описывает число после успешного ожидания, а не значение, доступное синхронно.

Когда нужны перегрузки

function convert(value: string): number;
function convert(value: number): string;
function convert(value: string | number): number | string {
  return typeof value === "string" ? Number(value) : String(value);
}
const parsed = convert("42"); // number
const printed = convert(42); // string
console.log(parsed.toFixed(0), printed.toUpperCase());

Перегрузки сохраняют зависимость результата от аргумента. Сигнатура реализации должна обслужить все перегрузки, но снаружи сама по себе недоступна. Если зависимость не нужна, одна сигнатура с union проще. Перегрузка не создаёт несколько JS-функций: тело остаётся одно.
