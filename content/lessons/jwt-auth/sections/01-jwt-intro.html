Задача: сервер должен узнавать пользователя

HTTP не помнит прошлых запросов. Каждый запрос приходит на сервер как от незнакомца. Чтобы после входа не вводить пароль на каждой странице, сервер выдаёт пользователю что-то вроде пропуска, а браузер показывает его в каждом следующем запросе.

Есть два популярных вида пропуска:

  • Сессия. Сервер запоминает у себя «сессия №123 — это Аня» и отдаёт браузеру только номер. На каждый запрос сервер ищет номер в своём списке.
  • JWT (JSON Web Token). Сервер ничего не запоминает. Он пишет данные прямо в пропуск («это пользователь с id 664f2a») и ставит подпись, которую подделать нельзя. На каждый запрос сервер просто проверяет подпись.

В этом уроке соберём второй вариант на Express и MongoDB: регистрацию, вход и страницу профиля, доступную только после входа. Цель — понять, что происходит на каждом шаге, а не просто скопировать код.

Что нужно знать

JavaScript, async/await, основы Node.js и Express (маршруты, req, res, middleware). MongoDB должна быть установлена локально или доступна в облаке. Код написан в стиле CommonJS (require), как в исходном материале.
