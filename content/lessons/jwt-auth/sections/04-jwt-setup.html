Подготовка проекта

npm install express mongoose bcrypt jsonwebtoken dotenv cookie-parser
ПакетЗачем
expressСервер и маршруты
mongooseРабота с MongoDB через модели
bcryptХеширование паролей. К JWT не относится, но всегда идёт рядом
jsonwebtokenСоздание и проверка токенов
dotenvЧитает секреты из файла .env, чтобы они не лежали в коде
cookie-parserНужен, только если хранить токен в cookie (раздел «Где хранить токен»)

Пакет bcrypt собирается из кода на C++, и на некоторых системах установка падает. Тогда ставьте bcryptjs: он написан на чистом JavaScript, медленнее, но методы те же (hash, compare). Примеры этого урока мы проверяли именно на нём.

Файл .env в корне проекта:

JWT_SECRET=длинная-случайная-строка-не-короче-32-символов
JWT_EXPIRES_IN=1d
MONGO_URI=mongodb://localhost:27017/myapp

Секрет должен быть длинным и случайным. Получить такой можно командой node -e "console.log(require('crypto').randomBytes(32).toString('hex'))".

Не отправляйте .env в git

Добавьте строку .env в .gitignore. Кто знает JWT_SECRET, тот может выпустить токен от имени любого пользователя.
