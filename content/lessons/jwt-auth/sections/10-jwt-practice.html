Проверяем, что всё работает

Пройдите по шагам. Запросы удобно отправлять из Postman, Insomnia или вкладки Network в DevTools.

  1. POST /api/auth/register с {"email":"a@a.ru","password":"1234"} → ответ 201. В MongoDB у документа в поле password строка, начинающаяся с $2, а не «1234».
  2. POST /api/auth/login с теми же данными → в ответе строка из трёх частей через точки.
  3. Вставьте токен на jwt.io → в разделе Payload видно { id, iat, exp }.
  4. GET /api/user/profile без заголовка → 401 «Токен не предоставлен».
  5. Тот же запрос с заголовком Authorization: Bearer <токен> → 200 и данные профиля без пароля.
  6. Измените в токене одну букву во второй части → 401: подпись больше не совпадает.
  7. Временно поставьте JWT_EXPIRES_IN=5s, войдите заново, подождите 6 секунд → 401: срок истёк.
  8. Вход с неверным паролем → 401 с тем же текстом, что и для несуществующего email.

Шаги 6 и 7 мы проверили на библиотеке jsonwebtoken: подделанный токен даёт invalid signature, просроченный — jwt expired.
