Prettier

Prettier — «упрямый» (opinionated) форматтер. Он не проверяет стиль, а переписывает файл целиком: разбирает код в дерево (как это делает движок JavaScript) и печатает его заново по своим правилам. Как вы расставили пробелы и переносы, не важно — результат всегда одинаковый.

Зачем он нужен

Страница Why Prettier из материалов модуля называет главную причину: прекратить бесконечные споры о стиле. Все согласны, что общий стиль нужен, но договориться о нём мучительно, и никто не любит получать и писать замечания о пробелах. Prettier — единственный стайлгайд, который соблюдается полностью автоматически; даже если он форматирует не совсем так, как хочется вам, это стоит того. Кроме того, он помогает новичкам в проекте и в языке («раньше я всегда ставил пробелы не там») и экономит силы: код пишется как угодно, а одно сочетание клавиш делает его аккуратным.

Установка и команды

npm install -D prettier
npx prettier --check .    # проверить, не меняя файлы
npx prettier --write .    # отформатировать все файлы

Проверка на нашем файле: --check сообщил «Code style issues found» и завершился с кодом 1, а --write привёл файл к такому виду:

import { unused } from './utils.js';
let total = 0;
const items = [1, 2, 3];
for (const item of items) {
  total += item;
}
if (total == '6') {
  console.log('всё сходится');
}

Появились точки с запятой, пробелы после запятых, переносы и отступы в два пробела, кавычки стали одинарными (по нашей настройке). А == и неиспользуемый импорт остались: это не форматирование, а забота линтера. Prettier понимает не только JavaScript, но и TypeScript, CSS, SCSS, HTML, JSON, Markdown, YAML.

Настройка

Опций у Prettier мало — нарочно, чтобы спорить было не о чем (список опций). Их задают в файле .prettierrc:

{
  "singleQuote": true,
  "semi": true,
  "printWidth": 100,
  "trailingComma": "all"
}
  • printWidth — желаемая длина строки (по умолчанию 80). Это ориентир, а не жёсткий предел.
  • singleQuote — одинарные кавычки; semi — ставить ли ;; tabWidth и useTabs — отступы; trailingComma — запятая после последнего элемента.

Файл .prettierignore перечисляет, что не трогать (по синтаксису как .gitignore): сборку, сгенерированные файлы. node_modules и файлы из .gitignore Prettier пропускает сам. Для настройки отступов и окончаний строк во всех редакторах, даже без Prettier, есть ещё файл .editorconfig; Prettier читает и его.

Версию Prettier фиксируют точно (npm install -D --save-exact prettier): даже минорное обновление может немного поменять форматирование, и у разных разработчиков получатся разные файлы.
