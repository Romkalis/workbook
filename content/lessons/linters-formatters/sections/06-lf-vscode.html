Интеграция с VS Code

Запускать команды вручную неудобно. Редактор может показывать ошибки ESLint прямо при наборе и форматировать файл при каждом сохранении — это показано во втором видео модуля.

  1. Установите расширения ESLint (от Microsoft) и Prettier — Code formatter. Они используют ESLint и Prettier, установленные в проекте, и его конфиги.
  2. Создайте в проекте файл .vscode/settings.json — настройки попадут в git, и у всей команды редактор будет вести себя одинаково:
{
  "editor.defaultFormatter": "esbenp.prettier-vscode",
  "editor.formatOnSave": true,
  "editor.codeActionsOnSave": {
    "source.fixAll.eslint": "explicit"
  }
}
  • defaultFormatter — каким расширением форматировать (в VS Code их может быть несколько).
  • formatOnSave — форматировать при сохранении (Ctrl+S / Cmd+S).
  • source.fixAll.eslint — при сохранении применять автоисправления ESLint.

Если подчёркиваний нет, откройте панель Output и выберите в списке ESLint: там видны ошибки конфига. Частые причины — ESLint не установлен в проекте или конфиг лежит не в корне открытой папки. Отформатировать файл вручную: Shift+Alt+F (Windows), Shift+Option+F (macOS).
