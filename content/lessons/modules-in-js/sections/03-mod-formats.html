Форматы модулей: CommonJS, AMD, UMD

Статья Юргена Ван де Мера «A 10 minute primer to JavaScript modules» из теории модуля разделяет три понятия. Формат модуля — синтаксис, которым описан модуль (CommonJS, AMD, ES). Загрузчик модулей — программа, которая во время работы находит и выполняет модули нужного формата (RequireJS, SystemJS). Сборщик — программа, которая заранее, при сборке, склеивает модули в файлы для браузера (webpack, Vite).

CommonJS

Когда Райан Дал в 2009 году вынес JavaScript на сервер (Node.js), HTML и тегов <script> там не было, и для подключения файлов взяли формат CommonJS:

// math.js
function sum(a, b) { return a + b; }
module.exports = { sum };

// app.js
const { sum } = require('./math');

require загружает модуль синхронно: программа ждёт, пока файл прочитается. На сервере файлы лежат на диске, это быстро. В браузере каждый файл пришлось бы ждать из сети, и страница замирала бы. Поэтому в браузере CommonJS напрямую не работает, его код собирают сборщиком. Подробно CommonJS разобран в уроке «Основы Node.js».

AMD

AMD (Asynchronous Module Definition) — формат для браузера: модули загружаются асинхронно, а функция модуля вызывается, когда загружены все зависимости. Популярный загрузчик — RequireJS.

define(['jquery', './utils'], function ($, utils) {
  function show() { /* ... */ }
  return { show: show };
});

Как и IIFE, модуль — это функция, а зависимости приходят параметрами. Лекция RS School описывает AMD как идеи CommonJS, перенесённые в браузер. Сегодня AMD почти не встречается: его вытеснили сборщики и ES-модули. Этот пример приведён для узнавания синтаксиса и при подготовке урока не запускался — для этого нужен RequireJS.

UMD

UMD (Universal Module Definition) — «универсальная» обёртка для библиотек, которые должны работать везде: с AMD-загрузчиком, в Node.js (CommonJS) и просто через <script> (глобальная переменная). Она проверяет, что доступно, и выбирает подходящий способ (шаблоны UMD):

(function (root, factory) {
  if (typeof define === 'function' && define.amd) {
    define([], factory);                 // AMD
  } else if (typeof module === 'object' && module.exports) {
    module.exports = factory();          // CommonJS
  } else {
    root.mathLib = factory();            // глобальная переменная
  }
})(typeof self !== 'undefined' ? self : this, function () {
  return { sum: (a, b) => a + b };
});

Проверено: в Node.js через require получилось sum(2, 3) = 5, а при выполнении без module библиотека появилась в глобальной переменной mathLib. UMD до сих пор встречается в сборках библиотек на CDN (серверах, которые раздают файлы библиотек по прямой ссылке).
