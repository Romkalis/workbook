HTTPS и заголовки безопасности

HTTPS шифрует трафик и подтверждает, что вы говорите с настоящим сервером. Без него пароли, токены и cookie читаются в публичной Wi-Fi-сети. Заголовок Strict-Transport-Security (HSTS) велит браузеру больше никогда не открывать сайт по HTTP. Набор полезных заголовков ответа:

ЗаголовокЗачем
Strict-Transport-Security: max-age=31536000только HTTPS
Content-Security-Policyоткуда можно грузить скрипты и кто может встраивать страницу
X-Content-Type-Options: nosniffне угадывать тип файла (скрипт под видом картинки)
Referrer-Policy: strict-origin-when-cross-originне отдавать полный адрес чужим сайтам

В Express их ставит пакет helmet одной строкой (из общих знаний).

Задача 13. Заголовки безопасности ★☆☆ разминка

Напишите middleware securityHeaders(), который ставит HSTS на год, X-Content-Type-Options: nosniff, Referrer-Policy: strict-origin-when-cross-origin и CSP: всё только со своего источника, никаких плагинов (object-src 'none'), запрет встраивания в чужие фреймы. Уберите заголовок X-Powered-By, который Express ставит сам.

Зачем: пять заголовков закрывают целые классы атак: понижение до HTTP, кликджекинг, подмену типа файла, утечку адресов. Это дешёвая защита, которую часто забывают. X-Powered-By: Express бесплатно сообщает атакующему, какие уязвимости пробовать.

Решение и разбор
// app.ts
import express, { type RequestHandler } from 'express';

export function securityHeaders(): RequestHandler {
  const csp = ["default-src 'self'", "object-src 'none'", "frame-ancestors 'none'", "base-uri 'self'"].join('; ');
  return (_req, res, next) => {
    res.set({
      'Strict-Transport-Security': 'max-age=31536000; includeSubDomains',
      'X-Content-Type-Options': 'nosniff',
      'Referrer-Policy': 'strict-origin-when-cross-origin',
      'Content-Security-Policy': csp,
    });
    next();
  };
}

export function createApp() {
  const app = express();
  app.disable('x-powered-by');
  app.use(securityHeaders());
  app.get('/', (_req, res) => {
    res.send('ok');
  });
  return app;
}

base-uri 'self' не даёт внедрённому тегу <base> перенаправить все относительные ссылки на чужой домен (из общих знаний: рекомендация шпаргалки OWASP по CSP). HSTS действует только для ответов по HTTPS. Браузер игнорирует его на HTTP, иначе злоумышленник мог бы его подделать. Готовый вариант — пакет helmet: он ставит эти и ещё около десятка заголовков, но полезно один раз написать их руками и понимать, что каждый делает.
