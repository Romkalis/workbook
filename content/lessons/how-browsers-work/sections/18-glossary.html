Глоссарий

Blink / WebKit / Gecko
Движки рендеринга Chrome, Safari и Firefox. Blink это форк WebKit; подробнее в разделе «WebKit и другие движки».
Browser process
Процесс Chrome, отвечающий за интерфейс браузера, сеть и доступ к файлам.
Renderer process
Процесс, который выполняет и рисует содержимое вкладки.
IPC
Inter-process communication, обмен сообщениями между процессами.
Site Isolation
Отдельный процесс для каждого сайта, включая кросс-сайтовые iframe.
MIME sniffing
Определение типа данных по содержимому, когда Content-Type отсутствует или неверен.
CORB
Cross-Origin Read Blocking, защита от попадания чувствительных кросс-сайтовых данных в renderer.
Service worker
JS-прокси между страницей и сетью, управляющий кэшем.
DOM
Document Object Model, дерево объектов документа и API доступа к нему.
CSSOM
CSS Object Model, структура со стилями, из которой берутся правила для узлов DOM.
Токенизация
Разбиение входного текста на токены: теги, атрибуты, текст.
Preload scanner
Параллельный сканер, заранее находящий ресурсы для загрузки.
Computed style
Итоговые значения свойств элемента после каскада и наследования.
Специфичность
Вес селектора при разрешении конфликтов в каскаде.
Render tree
Дерево видимых элементов со стилями, основа для layout и paint.
Layout / reflow
Вычисление размеров и позиций элементов.
Dirty bit
Флаг, помечающий узел как требующий пересчёта layout.
Paint / repaint
Составление списка команд рисования и растеризация; перерисовка после изменений.
Растеризация
Превращение команд рисования в пиксели.
Stacking context
Группа боксов, упорядоченных по оси z и рисуемых вместе.
Compositor thread
Поток, собирающий кадр из слоёв независимо от основного потока.
Тайл
Прямоугольный кусок слоя, растеризуемый отдельно.
Draw quad / compositor frame
Описание тайла для отрисовки и набор таких описаний, образующих кадр.
Jank
Заметные рывки из-за пропущенных кадров.
INP
Interaction to Next Paint, метрика отзывчивости страницы на ввод.
Non-fast scrollable region
Область страницы с обработчиками событий, ввод в которой нужно пересылать основному потоку.
Hit test
Определение элемента под заданными координатами.
Event loop
Бесконечный цикл основного потока, обрабатывающий события и задачи.
