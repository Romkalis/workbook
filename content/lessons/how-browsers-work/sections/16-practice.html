Сводка по всему модулю в виде вопросов, которые можно задавать своему коду.

ПроблемаЧто делать
JS блокирует парсинг HTMLdefer или async, модули, не использовать document.write.
CSS блокирует первую отрисовкуУменьшить объём, минифицировать, некритичное вынести под media-запросы.
Ресурс нужен срочно, а браузер находит его поздно<link rel="preload">.
Тормозит анимацияАнимировать transform/opacity, не геометрию; при необходимости will-change, но без злоупотребления слоями.
Много reflowМенять классы, группировать записи DOM, разделять чтение и запись, кэшировать геометрию.
Тяжёлый JS занимает основной потокРазбивать вычисления на небольшие задачи и отдавать управление браузеру; подходящие вычисления переносить в Web Worker. requestAnimationFrame использовать для коротких обновлений перед кадром, а не как способ вынести тяжёлую работу с основного потока.
Прокрутка дёргается из-за обработчиков{ passive: true }, touch-action, не вешать глобальные обработчики без необходимости.
Огромный DOMУменьшать число узлов, лениво рендерить невидимое.
Медленный уход со страницыНе навешивать beforeunload без причины.
Не знаю, где проблемаИзмерять: DevTools (Performance, Layers, Rendering), Lighthouse. Сначала профайлер, потом оптимизация.
