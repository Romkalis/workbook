Путь от URL до пикселей

Читайте стрелки как передачу результата: HTML становится деревом узлов, стили задают внешний вид, расчёт раскладки определяет геометрию. Это учебная модель. Браузер может выполнять части работы постепенно, параллельно и повторно — не обязательно ждать полного завершения всей загрузки.

Если держать в голове только одну схему, пусть будет эта. Каждая стадия берёт результат предыдущей и строит из него новую структуру данных.

Подсветка идёт по стадиям по кругу. Наведите курсор на схему, чтобы остановить.

Две важные мысли сразу:

  • Процесс инкрементальный. Браузер не ждёт, пока придёт весь HTML. Он строит DOM по мере поступления данных и старается показать что-нибудь как можно раньше.
  • Если что-то в начале цепочки изменилось, всё после него надо пересчитывать. Изменили геометрию, значит нужны layout, paint и composite. Изменили только цвет, layout не нужен. Именно на этом построены почти все советы по оптимизации.
