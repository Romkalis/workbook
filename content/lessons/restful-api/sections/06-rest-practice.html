Практика, вопросы и словарь

Упражнения

  1. Поднимите json-server с db.json из урока. В Postman выполните все шесть запросов из таблицы CRUD и посмотрите, как меняется файл.
  2. Повторите опыт лектора: PUT с одним полем и PATCH с одним полем. Объясните разницу.
  3. Отправьте POST без заголовка Content-Type. Что сохранилось?
  4. Напишите модуль api.js из урока и страницу со списком сотрудников, фильтром по роли и кнопками страниц.
  5. Спроектируйте адреса API для блога: пользователи, статьи, комментарии. Какие методы и коды ответов нужны?
  6. Определите, какая версия json-server стоит в проекте Async Race, и какие параметры пагинации там работают.

Вопросы

Чем REST отличается от HTTP?

HTTP — протокол передачи. REST — архитектурный стиль, набор правил, как проектировать API поверх HTTP: ресурсы с адресами, действия через методы, отсутствие состояния на сервере.

Почему /deleteUser?id=5 — плохой адрес?

Действие выражено в адресе, а не методом, и для удаления используется GET, который не должен менять данные. Правильно: DELETE /users/5.

Почему повторить POST опаснее, чем PUT?

POST не идемпотентен: повтор создаст ещё одну запись. PUT заменяет ресурс тем же содержимым, повтор ничего не меняет.

Когда нужно повышать версию API?

При ломающих изменениях: изменился формат ответа или тип поля, удалена часть API. Новые поля и адреса добавляют без смены версии.

Словарь

API
Договорённость о том, как программы обращаются друг к другу.
REST
Архитектурный стиль API Роя Филдинга: ресурсы, методы HTTP, отсутствие состояния, кеширование.
RESTful
API, построенный по принципам REST (на практике часто соблюдает их не все).
Ресурс
Сущность, к которой обращается API: пользователь, заказ, статья.
Endpoint
Адрес, по которому API принимает запросы к ресурсу.
CRUD
Create, Read, Update, Delete — четыре базовые операции с данными.
Идемпотентность
Свойство метода давать тот же итог при повторе.
Пагинация
Выдача коллекции частями-страницами.
Версионирование
Способ выпускать несовместимые изменения, не ломая старых клиентов.
json-server
Пакет, который превращает JSON-файл в учебный REST-API.
SOAP, GraphQL
Альтернативы REST: строгий XML-протокол и язык запросов с выбором полей.
