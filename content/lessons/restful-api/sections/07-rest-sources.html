Источники

Программа модуля: RS School, Stage 2, RESTful API Style. Материалы открыты и разобраны 14 ноября 2026 года.

Лекция

  • REST API Video Lecture [RU] — по автоматической расшифровке: ограничения REST, анатомия запроса, CRUD, JSON, json-server и Postman, PUT против PATCH, клиент на fetch с фильтрами и пагинацией через X-Total-Count. Неточности лектора отмечены в тексте.
  • REST API Slides — определение, ограничения, анатомия запроса, заголовки, пример JSON.

Статьи

  • tutsplus: Понимание REST и RESTful API — принципы, методы, коды ответов, адреса, SOAP и GraphQL.
  • Codecademy: What is REST? — клиент-сервер, отсутствие состояния, глаголы, заголовки, пути, проектирование на примере магазина.
  • dev.to: Fundamentals of REST API — открыта; текст страницы извлечён без заголовков, использована для сверки основ.
  • restfulapi.net: API Versioning — когда и как версионировать; неточность про GitHub отмечена в тексте.
  • AWS: What is an API? — виды API по протоколу и доступу.
  • json-server — проверены версии 0.17.4 и 1.0.0-beta.15; сервер Async Race (async-race-api) использует ^0.16.3.
