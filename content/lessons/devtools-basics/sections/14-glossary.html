Глоссарий

Брейкпоинт (breakpoint)
Точка остановки: выполнение кода замирает перед указанной строкой или при наступлении события.
Box model
Блочная модель: content, padding, border, margin.
Call Stack
Цепочка вызовов функций, приведшая к текущей точке выполнения.
Computed
Вкладка с итоговыми вычисленными значениями CSS-свойств.
Console drawer
Нижняя панель с консолью, которую открывает Esc на любой вкладке.
DOM
Объектная модель документа: дерево узлов, которое браузер строит из HTML.
DOMContentLoaded
Событие: HTML разобран и DOM построен, без ожидания картинок и стилей.
Core Web Vitals
Набор пользовательских показателей качества загрузки (LCP), интерактивности (INP) и визуальной стабильности (CLS).
CSS-псевдокласс
Состояние элемента, выбранное селектором с двоеточием, например :hover при наведении или :focus при фокусе.
Event Listener Breakpoint
Настройка отладчика, которая приостанавливает JavaScript, когда браузер начинает обрабатывать выбранное событие, например щелчок мышью.
Initiator
Колонка Network: что вызвало запрос (файл, строка, цепочка).
Keep log
Настройка, сохраняющая журнал при перезагрузках (раньше Preserve log).
Live Expressions
Закреплённые выражения Console, значение которых DevTools обновляет каждые 250 мс.
load
Событие: страница и все её ресурсы загружены.
localStorage
Постоянное хранилище «ключ-значение» в браузере, привязанное к origin.
Local Overrides
Инструмент, который сохраняет локальную замену загруженного ресурса или ответа сервера и использует её при последующих запросах в этом браузере.
Logpoint
Брейкпоинт, который не останавливает код, а выводит выражение в консоль.
Origin
Схема, домен и порт. Хранилища браузера изолированы по origin.
Paint flashing
Подсветка областей страницы, которые браузер перерисовывает; помогает заметить лишние перерисовки.
REPL
Интерактивная командная среда: принимает код, выполняет его и показывает результат.
Rendering
Панель с визуальными инструментами для исследования отрисовки страницы, слоёв, смещений и частоты кадров.
Scope
Панель отладчика с переменными текущей области видимости.
Specificity
Специфичность селектора: вес, по которому CSS выбирает победившее правило.
console.assert
Метод Console, который выводит сообщение, если проверяемое условие ложно; сам по себе не останавливает программу.
Frame Rendering Stats
Экранный оверлей с оценкой кадров в секунду, графиком кадров и сведениями о графическом процессоре.
Throttling
Искусственное замедление сети для проверки на плохом соединении.
TTFB
Time to first byte: время до получения первого байта ответа. В DevTools подписано «Waiting for server response».
User agent stylesheet
Стили браузера по умолчанию. В Styles показаны курсивом и не редактируются.
Waterfall
График в Network: когда каждый запрос начался и сколько занял.
