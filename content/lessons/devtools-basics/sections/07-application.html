Application: localStorage Теория: View and edit local storage

Пример origin: у https://example.com:443 схема https, домен example.com и порт 443. Другая схема, домен или порт означают другой origin. Сериализация — превращение объекта в строку через JSON.stringify; JSON.parse выполняет обратный разбор.

Вкладка Application показывает всё, что приложение хранит в браузере: cookies, кэши, IndexedDB, service workers. В модуле нужен один раздел, Storage → Local storage. Под ним список источников (origin), выберите свой, и справа откроется таблица пар «ключ → значение».

localStorage — хранилище типа «ключ-значение», доступное из JavaScript. Обычно данные сохраняются после закрытия вкладки и перезапуска браузера. Пользователь или настройки браузера могут их удалить; в приватном режиме срок хранения отличается. Для разработчика важны три свойства (это общие знания, в статьях модуля они расписаны подробнее): значения хранятся только как строки (объекты нужно сериализовать через JSON.stringify и разбирать через JSON.parse), объём ограничен примерно 5 МБ на источник, хранилище привязано к origin (схема + домен + порт), и страница с другого origin его не увидит.

В DevTools можно посмотреть, отредактировать и удалить пары ключ-значение: измените ячейку двойным щелчком или удалите выбранную строку клавишей Delete. Поле Filter над таблицей отбирает записи по имени ключа. Те же данные доступны JavaScript-коду в панели Console:

localStorage.setItem('theme', 'dark'); // добавить или заменить
localStorage.getItem('theme');         // 'dark'
localStorage.removeItem('theme');      // удалить один ключ
localStorage.clear();                  // удалить все ключи текущего origin

В демо-странице выше видны ключи lang, theme, visits и user — последний хранит JSON-строку {"name":"Анна","role":"student"}.

Хранилище другого сайта из консоли

Из консоли localStorage указывает на источник текущего контекста. Чтобы поработать с хранилищем iframe или другого origin, переключите JavaScript context (выпадающий список в панели Console) на нужный.
