Вопросы для самопроверки

Сначала отвечайте вслух, потом открывайте ответ. Если ответ звучит как «ну, там такая кнопка...», вернитесь в раздел и повторите действие руками.

Общее

Как открыть DevTools и чем это можно заменить, если F12 не работает?

F12, Ctrl+Shift+I (Cmd+Option+I), правая кнопка → Inspect или меню Chrome → More tools → Developer tools.

Для чего нужно командное меню?

Запуск любых действий DevTools по названию: переключение панелей, скриншоты, блокировка запросов, запуск сниппетов.

Что общего у всех правок, сделанных в DevTools?

Они локальные и временные: меняют только вашу вкладку и пропадают при перезагрузке. Исключение: Workspace, который сохраняет правки в файлы на диске.

Elements

Чем Elements отличается от «Просмотра кода страницы»?

Elements показывает живой DOM, то есть результат работы скриптов, а не исходный файл с сервера.

Как быстро найти элемент на странице в дереве DOM?

Правая кнопка → Inspect либо инструмент выбора Ctrl+Shift+C. Искать по дереву можно через Ctrl+F: текст, селектор или XPath.

Как изменить HTML целого узла вместе с вложенным содержимым?

Контекстное меню → Edit as HTML, применить правку Ctrl+Enter.

Что такое $0?

Последний выделенный в Elements узел, доступный в консоли как переменная. Для сохранения узла есть ещё Store as global variable.

Как посмотреть стили, которые есть только при наведении курсора?

Кнопка :hov в Styles (или Force state в меню узла) принудительно включает :hover, :active, :focus.

Что значит зачёркнутое свойство в Styles? А бледное?

Зачёркнутое: перебито более приоритетным правилом или значение невалидно (тогда есть значок предупреждения). Бледное: валидно, но не действует в этом контексте, значок «i» объяснит почему.

Как узнать, в каком файле и строке объявлено свойство?

По ссылке справа от блока правила (style.css:8) либо Ctrl-клик по имени свойства.

Что показывает Computed и чем он лучше Styles?

Итоговые вычисленные значения после каскада и наследования, с возможностью развернуть свойство и увидеть, какое правило победило. Styles показывает исходные правила, Computed отвечает на вопрос «что в итоге».

Console

Какие уровни сообщений есть в консоли и какие методы к ним относятся?

Verbose (debug), Info (log, info), Warnings (warn), Errors (error). Verbose по умолчанию скрыт.

Как вывести массив объектов таблицей?

console.table(array). Если DevTools открыт уже после вызова, таблицы может не быть, а будет обычный вывод массива.

Как оставить в консоли только сообщения вашего кода, без браузерных?

Включить фильтр User messages в боковой панели, либо фильтровать по url:app.js.

Что делает Keep log (Preserve log) и когда он нужен?

Не очищает консоль при перезагрузке и переходах. Нужен, когда ошибка происходит как раз в момент навигации или отправки формы.

Как очистить консоль?

Кнопка Clear, Ctrl+L, console.clear() или clear().

Что такое Live Expressions?

Выражение, значение которого консоль пересчитывает постоянно и показывает над журналом. Подходит для слежения за переменной, не засоряя консоль.

Sources

Как устроено дерево файлов на вкладке Page?

Верхний уровень (top) → источник (origin) → папки и файлы. У iframe свой отдельный раздел.

Сохранятся ли изменения кода, сделанные в редакторе Sources?

Нет, если не подключён Workspace: они действуют до перезагрузки. В JS применяется только изменённое тело функций, и нужно нажать Ctrl+S.

Назовите виды брейкпоинтов.

На строку, условный, logpoint, на событие (Event listener), на изменение DOM, на XHR/fetch, на исключение.

Чем Step over отличается от Step into?

Step over выполняет строку целиком, не заходя в функции. Step into заходит внутрь вызванной функции.

Как найти код, обрабатывающий клик по кнопке, если не знаешь где он?

Event Listener Breakpoints → Mouse → click, затем кликнуть: отладчик остановится на первом обработчике.

Как устроена отладка «5 + 1 = 51»?

Ставим брейкпоинт в функцию, шагаем и смотрим Scope: addend1 и addend2 — строки (.value возвращает строку), и плюс их склеивает. Решение: привести к числу.

Зачем нужен Focus on your code / ignore list?

Чтобы отладчик не заходил в код библиотек и фреймворков при шагах.

Network

Почему на вкладке Network пусто после открытия DevTools?

Запись идёт только при открытом DevTools. Перезагрузите страницу при открытой вкладке.

Как оставить только запросы к API?

Кнопка Fetch/XHR либо фильтр по домену (domain:) или подстроке URL.

Как найти запрос по тексту внутри ответа?

Вкладка Search (Ctrl+F в Network): она ищет по заголовкам и телам записанных запросов.

Какие вкладки есть у отдельного запроса и что смотреть в каждой?

Headers (заголовки), Payload (отправленные данные), Preview и Response (ответ), Initiator (кто вызвал), Timing (время по фазам), Cookies.

Что значит длинная фаза «Waiting for server response»?

Сервер долго готовит ответ. Раньше эту фазу называли TTFB (time to first byte). Проблема на стороне сервера, а не клиента или сети.

Как проверить, как страница работает на медленном интернете?

Throttling: Slow 4G, 3G и другие пресеты. Для полного отсутствия связи — Offline.

Зачем Disable cache?

Чтобы быть уверенным, что браузер берёт свежие файлы с сервера, а не из кэша.

Application

Как изменить значение в localStorage и убедиться, что страница его увидела?

Двойной клик по ячейке в Application → Local storage, ввести значение, обновить страницу.

Какие ограничения у localStorage?

Только строки, около 5 МБ, привязка к origin. Объекты — через JSON.stringify и JSON.parse.
