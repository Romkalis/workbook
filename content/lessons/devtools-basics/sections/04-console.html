Console Теория: Console overview; Log messages in the Console; Console reference → Persist messages

Лог — выведенное сообщение. Исключение — ошибка, которая прерывает обычное выполнение текущего кода. Стек вызовов показывает путь вложенных вызовов функций до места ошибки. Красная строка помогает найти причину, но сама по себе ещё не объясняет, как её исправить.

Консоль решает две задачи: показывает сообщения (ваши и браузера) и работает как командная строка JavaScript в контексте текущей страницы. Открыть её можно через вкладку Console, а на любой другой вкладке клавиша Esc выдвигает нижнюю панель Console drawer. Прямое сочетание: Ctrl+Shift+J (Cmd+Option+J).

Как вывести сообщение

Основной инструмент — объект console. Методы для разных случаев:

МетодЧто делаетУровень
console.log(), console.info()Обычное сообщениеInfo
console.debug()Отладочное сообщение, по умолчанию скрытоVerbose
console.warn()Предупреждение, жёлтая строкаWarning
console.error()Ошибка, красная строка со стеком вызововError
console.table(data)Массив объектов выводится таблицейInfo
console.group() / groupEnd()Вкладывает сообщения друг в друга, со сворачиваниемInfo
console.trace()Печатает стек вызовов в этой точкеInfo

В строку можно подставлять значения: console.log('Привет, %s', name); формат %c принимает CSS: console.log('%cВажно', 'color: red; font-size: 20px'). У каждого сообщения справа ссылка на файл и строку, из которой оно выведено (на скриншоте app.js:2), по ней можно перейти в Sources.

Что видно на скриншотах

console.table, вызванный до того, как DevTools был открыт, выводится как обычный массив Array(2), а не как таблица. Таблица появляется, если открыть DevTools и перезагрузить страницу или вызвать метод заново. Это важно для практики: открывайте DevTools до загрузки страницы.

Сообщения от самого браузера

Кроме ваших логов консоль показывает то, что генерирует браузер: ошибки загрузки ресурсов (404 Not Found), необработанные исключения (Uncaught TypeError: ...) с указанием строки и стека, предупреждения о производительности вроде [Violation]. На демо-странице вы увидите 404 для несуществующей missing.png. Красные сообщения это первое, что нужно прочесть, когда «страница сломалась».

Фильтрация сообщений

Когда сообщений много, помогают фильтры в верхней панели:

  • выпадающий список Default levels включает и выключает уровни Verbose, Info, Warnings, Errors;
  • поле Filter ищет по тексту; понимает регулярные выражения (в слешах, /ошибка \d+/), исключение через минус (-текст), фильтр по источнику url:app.js и его отрицание -url:app.js;
  • боковая панель (значок слева сверху) группирует сообщения по файлам и типам;
  • User messages оставляет только то, что вывел ваш код, без сообщений браузера.

Управление журналом

По умолчанию при каждой навигации (переходе на другую страницу или перезагрузке) консоль очищается. Если нужно сохранить сообщения, открывайте настройки консоли (значок шестерёнки) и включайте Keep log. В старых версиях Chrome и в статье для этого пункта используется название Preserve log: это одна и та же настройка, её переименовали. Вручную журнал чистится так:

  • кнопка Clear console (значок «перечёркнутый круг»);
  • Ctrl+L (на Mac Cmd+K);
  • из кода или консоли: console.clear() и просто clear().

Другие полезные настройки на этой панели:

  • Network messages (раньше Hide network): показывать ли сообщения о сетевых запросах;
  • Log XMLHttpRequests — выводить в консоль каждый XHR-запрос;
  • Eager evaluation — предпросмотр результата выражения ещё до нажатия Enter (серым под строкой ввода);
  • Autocomplete from history, Group similar (схлопывает одинаковые сообщения в одну строку со счётчиком), Selected context only.

Консоль как командная строка

В строке ввода (внизу) можно выполнять любой JavaScript. Результат выражения печатается сразу. Важные трюки:

  • Shift+Enter переносит строку, не выполняя команду;
  • стрелка вверх возвращает прошлые команды;
  • $0 — выделенный в Elements элемент, $_ — результат прошлого выражения;
  • вложенный объект раскрывается треугольником: собственные свойства отображаются жирным, унаследованные бледнее, плюс служебные [[Prototype]]; приватные поля показываются как #name;
  • Live Expressions (значок глаза в панели) закрепляет выражение над журналом и пересчитывает его каждые 250 мс, показывая текущее значение без новых строк в журнале. В поле Live Expression Shift+Enter переносит выражение на новую строку;
  • выпадающий список JavaScript context (по умолчанию top) позволяет выполнять код внутри iframe или расширения;
  • утилита debug(fn) ставит брейкпоинт на первую строку функции fn, о брейкпоинтах дальше.

Консоль — это REPL (read–eval–print loop): интерактивная среда, которая принимает выражение, выполняет его и показывает результат. Подсказка Autocomplete from history предлагает ранее введённые команды, пока вы печатаете; это поиск по истории консоли, а не только дополнение имён JavaScript.

Проверка условия через console.assert

console.assert(condition, message) выводит сообщение в консоль, только если условие ложно. В отличие от оператора throw он не выбрасывает исключение и не останавливает программу; когда условие истинно, сообщения нет.

const total = 5 + 1;
console.assert(total === 6, 'Сумма должна быть 6'); // ничего не выведет
console.assert(total === 51, 'Ожидали ошибочную сумму'); // выведет сообщение об ошибке
