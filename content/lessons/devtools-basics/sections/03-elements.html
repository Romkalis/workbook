Elements: DOM и CSS Теория: DOM → View and change the DOM; CSS → View and change CSS; Computed; «Find the exact location of where a style is defined»

Не путайте HTML-текст и DOM: браузер разбирает текст, исправляет некоторые ошибки разметки, а JavaScript может менять полученное дерево. Родитель — узел, содержащий другие узлы; дочерний узел находится внутри него. В Styles видны CSS-правила, а в Computed — итоговые значения свойств выбранного элемента.

Вкладка Elements показывает живой DOM, а не исходный HTML-файл. Это важное различие: если скрипт добавил элемент или поменял класс, здесь вы увидите итог. Исходник (то, что отдал сервер) смотрят в Sources или Network.

Дерево DOM

Слева в панели дерево элементов, справа сайдбар со вкладками Styles, Computed, Layout и другими. Чтобы найти нужный узел:

  • нажмите на странице правой кнопкой по элементу → Inspect;
  • или включите инструмент выбора (стрелка в левом верхнем углу панели, Ctrl+Shift+C) и наведите курсор на элемент на странице;
  • двигайтесь по дереву стрелками: вверх и вниз по соседям, вправо раскрывает узел, влево сворачивает;
  • в самом низу панели есть хлебные крошки (breadcrumbs), по ним удобно подниматься к родителям.

Если элемент за пределами экрана, в контекстном меню узла есть Scroll into view. Поиск по дереву (Ctrl+F внутри Elements) принимает текст, CSS-селектор или XPath.

Правим HTML на лету

Практически всё в дереве редактируется. Чтобы изменить тип HTML-элемента, откройте пункт Edit as HTML и переименуйте его тег — например, замените div на section. Разметка узла целиком, включая дочерние элементы, станет доступна для правки:

  • двойной клик по тексту, атрибуту или имени тега меняет его;
  • контекстное меню → Edit as HTML даёт правку узла вместе с потомками целиком, применить можно через Ctrl+Enter (Cmd+Enter);
  • там же: Duplicate element (Shift+Alt+Down), Delete element, Hide element (клавиша H), Copy;
  • узлы можно перетаскивать мышью, меняя порядок;
  • неудачную правку отменяет Ctrl+Z (Cmd+Z).
Правки живут до перезагрузки

DevTools меняет страницу в памяти браузера. Файлы на диске и на сервере остаются прежними, после F5 всё вернётся. Удачную правку нужно перенести в исходный код руками.

Узел как JavaScript-объект

Выделенный в Elements узел доступен в консоли как $0. Через контекстное меню Store as global variable узел сохраняется в переменную вроде temp1, а Copy → Copy JS path копирует готовое выражение document.querySelector(...). Это самый быстрый способ получить ссылку на элемент для экспериментов в консоли.

Ещё полезное в том же меню: Force state (принудительно включить :hover, :active, :focus, чтобы разглядывать стили, которые пропадают при уходе курсора), Break on (брейкпоинт при изменении DOM: подтекст, атрибуты или удаление узла) и Capture node screenshot (снимок одного элемента).

Стили элемента

Во вкладке Styles все CSS-правила, которые относятся к выбранному элементу, от самого приоритетного к менее приоритетному. У каждого блока справа ссылка на файл и строку (style.css:8), а при переходе по ней откроется Sources.

Что можно делать:

  • кликнуть по значению свойства и поменять его, стрелки вверх и вниз на числовом значении меняют его на единицу;
  • снять галочку слева от свойства и посмотреть, как страница выглядит без него;
  • в поле Filter над правилами в Styles ввести имя CSS-свойства, например display, чтобы найти связанные с ним объявления и разобраться, какое правило действует;
  • добавить новое свойство в любое правило, в пустом месте блока;
  • в блок element.style писать стили прямо на элемент;
  • кнопка .cls позволяет добавить и снять классы на элементе, а :hov принудительно включает псевдоклассы.

Правка в element.style добавляет или меняет встроенный атрибут style выбранного HTML-элемента. Это удобно для быстрой проверки, но не меняет внешний CSS-файл и пропадёт после перезагрузки страницы.

Как читать стили

Зачёркнутое свойство перебито более приоритетным правилом либо значение невалидно (в этом случае рядом значок предупреждения). Бледное свойство корректно, но неактивно: например, width у display: inline, значок «i» объяснит причину. Курсив означает правило браузера по умолчанию (user agent stylesheet), его нельзя редактировать. Блоки Inherited from … показывают свойства, пришедшие от родителей.

Нужно быстро понять, где объявлено конкретное свойство? Зажмите Ctrl (Cmd) и кликните по имени свойства: откроется Sources прямо на строке с этим объявлением. Это и есть способ из статьи про точное место объявления стиля.

Box model и вкладка Computed

В сайдбаре есть интерактивная схема блочной модели: из центра наружу идут content, padding, border и margin. Числа в ней кликабельны, значения можно править.

Вкладка Computed показывает итоговые вычисленные значения: то, что браузер реально применил после всех каскадов и наследования. Это ответ на вопрос «почему элемент именно такой». Раскройте стрелку у свойства, и увидите список правил, которые к нему приложились, победившее правило будет первым. Поиск и галочка Show all позволяют увидеть все свойства, не только заданные явно, а Group сгруппирует по категориям.

Если в Computed что-то идёт не так, как задумано, алгоритм такой: открыть Computed, найти свойство, раскрыть, перейти по ссылке к победившему правилу, подумать, почему оно выиграло (специфичность селектора, порядок в файле, !important), и только потом править.

Линейки при наведении

Чтобы оценить размеры и положение элемента, откройте командное меню DevTools: Ctrl+Shift+P на Windows/Linux или Cmd+Shift+P на Mac. Введите rulers и выберите команду показа линеек при наведении (в зависимости от версии Chrome её название может отличаться). Линейки и направляющие появятся при наведении на страницу; это визуальная подсказка для измерений, а не изменение HTML или CSS.
