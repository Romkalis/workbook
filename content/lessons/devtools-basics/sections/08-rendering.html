Rendering: диагностика отрисовки

Термины панели: layout — расчёт размеров и расположения, paint — подготовка рисования, слой — часть графического представления страницы, кадр — очередное изображение на экране. Оверлей — временная диагностическая подсветка поверх страницы; он не меняет исходную разметку.

Панель Rendering показывает визуальные подсказки поверх страницы и помогает искать проблемы с перерисовкой, смещением элементов и плавностью. Откройте DevTools, вызовите командное меню клавишами Ctrl+Shift+P (Windows/Linux) или Cmd+Shift+P (Mac), введите rendering и выберите Show Rendering. Если нужной настройки нет, ищите её название в командном меню: состав панели зависит от версии Chrome.

Paint Flashing: что браузер перерисовывает

Включите Paint flashing, чтобы области страницы, которые браузер заново рисует, мигали зелёным. Например, это помогает заметить, что небольшое изменение текста заставило перерисовать большую часть страницы. Подсветка сама по себе не доказывает проблему: она показывает области перерисовки, которые нужно исследовать.

Layout Shift Regions: где сдвинулся макет

Layout Shift Regions ненадолго подсвечивает области, которые сместились при изменении макета. Это помогает найти неожиданные скачки страницы, например когда поздно загрузившееся изображение сдвигает текст. Не путайте такое смещение с любой перерисовкой: repaint — повторная отрисовка пикселей, layout shift — изменение положения или размера содержимого.

Границы слоёв

Layer borders рисует поверх страницы границы графических слоёв и плиток. Это диагностический оверлей: он помогает увидеть, как браузер разделил страницу для отрисовки, но не показывает дерево DOM и сам по себе не объясняет причину медленной работы.

Frame Rendering Stats: частота кадров

Frame Rendering Stats включает оверлей со статистикой кадров в углу страницы. Он показывает оценку FPS (сколько кадров отображается в секунду), временную диаграмму успешно показанных, частично показанных и пропущенных кадров, а также сведения об использовании графического процессора. Используйте его при прокрутке или анимации, чтобы увидеть рывки и пропущенные кадры; это не панель для анализа сетевых запросов или DOM.

Core Web Vitals: пользовательское качество

Если в вашей версии DevTools доступна визуализация Core Web Vitals, она помогает оценивать страницу по пользовательским показателям, а не только по времени выполнения JavaScript. К основным показателям относятся LCP — скорость появления крупнейшего содержимого, INP — отзывчивость на взаимодействия и CLS — визуальная стабильность, то есть неожиданные сдвиги макета. Панель и способ показа подсказок меняются между версиями Chrome, поэтому конкретное расположение может отличаться.

Не делайте вывод по одной подсветке

Paint Flashing, Layout Shift Regions, Layer Borders и статистика кадров — инструменты диагностики: каждый показывает свой аспект работы страницы. Найдите участок, который ведёт себя необычно, затем проверьте его причину в Elements, Sources или Performance.
