Что нового в DevTools Дополнительно: developer.chrome.com/docs/devtools/news

Этот раздел можно читать после основных панелей. Названия кнопок относятся к версии на скриншотах: если пункт не найден, ищите действие через командное меню. Подсказка специфичности помогает сравнить селекторы, но победитель CSS-правила зависит также от каскада, слоёв и !important.

DevTools обновляется вместе с Chrome, поэтому интерфейс на ваших скриншотах и интерфейс из старых статей расходятся. В модуле просят посмотреть страницу новостей, чтобы быть в курсе. Две вещи оттуда, которые легко попробовать и которые есть на скриншотах.

Подсказка специфичности селектора

Наведите курсор на селектор в панели Styles, и появится подсказка с его специфичностью в формате (0,2,0): количество идентификаторов, классов (и атрибутов, псевдоклассов), тегов. На скриншоте это селектор .item.active: два класса, ни одного id или тега. Это самый быстрый способ понять, почему одно правило победило другое. По записям What's New, функция появилась в Chrome 151.

Edit and resend as fetch

В Network правая кнопка по запросу теперь предлагает пункт Edit and resend as fetch: запрос открывается в редакторе, вы меняете метод, заголовки или тело и отправляете заново, не выходя из DevTools. Раньше для этого копировали запрос как fetch и вставляли в консоль.

Помимо этого в свежих записях упомянуты: пояснения для неактивных стилей, новые пресеты устройств и отдельный раздел для рекламы в Application. Смотрите оригинал, список меняется с каждым релизом Chrome. Записи, вышедшие позже, в этот конспект не попали.
