Вопросы и словарь

Почему после pushState экран не меняется сам?

pushState только меняет адрес и историю; событие popstate при этом не срабатывает. Рисовать новый экран должен роутер.

Почему при обновлении страницы /products/42 получаем 404?

Сервер ищет файл по этому пути. Нужен fallback на index.html.

Почему переходы делают ссылками, а не кнопками?

Ссылки работают с новой вкладкой, копированием адреса, средней кнопкой мыши и читалками.

Что будет, если экран не отписывается в unmount?

Обработчики копятся, старые экраны реагируют на события и обращаются к удалённому DOM, растёт память.

Зачем переносить фокус после перехода?

Иначе пользователь клавиатуры и читалки остаётся «на старой странице» и не узнаёт о смене экрана.

SPA
приложение, которое загружает HTML один раз и меняет экраны с помощью JavaScript.
Роутер
часть приложения, сопоставляющая адрес с экраном.
History API
pushState, replaceState и событие popstate для управления адресом без перезагрузки.
Fallback
настройка сервера: на неизвестный путь отдавать index.html.
Code splitting
разбиение кода на файлы, которые загружаются по мере надобности.
