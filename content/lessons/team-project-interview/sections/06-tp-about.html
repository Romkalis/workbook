«О нас» и навигация

Страница «О нас» открывается первой. Это требование задания, и её же вы покажете в начале интервью. Что на ней должно быть:

  • Одной-двумя фразами: что делает приложение и для кого.
  • Участники: имя или GitHub-логин (лучше ссылкой на профиль) и вклад каждого конкретными словами: «каталог, фильтры и сортировка; настройка CI», а не «фронтенд».
  • По желанию: ссылки на репозиторий и доску.

Навигация на хеше: адрес …/#/cart не уходит на сервер, браузер просто генерирует событие hashchange. Решение «какой экран показать» — чистая функция:

// src/route.ts
export type Route = 'about' | 'catalog' | 'cart';

const ROUTES: readonly Route[] = ['about', 'catalog', 'cart'];

/** '#/cart' → 'cart'. Пустой или неизвестный адрес ведёт на «О нас». */
export function parseRoute(hash: string): Route {
  const name = hash.replace(/^#\/?/, '');
  return ROUTES.find((r) => r === name) ?? 'about';
}
// main.ts — набросок, в браузере не запускался
const screens = { about: renderAbout, catalog: renderCatalog, cart: renderCart };
const show = () => screens[parseRoute(location.hash)](document.querySelector('main')!);
window.addEventListener('hashchange', show);
show();

Пустой и неизвестный адрес ведут на «О нас». Так выполняется требование «открывается при загрузке», и опечатка в адресе не даёт пустую страницу. Ссылки меню — обычные <a href="#/catalog"> внутри <nav>: работают с клавиатуры и кнопкой «назад» без лишнего кода.
