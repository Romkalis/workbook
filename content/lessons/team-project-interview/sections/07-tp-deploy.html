GitHub PagesNetlify
НастройкаSettings → Pages → GitHub Actions + workflow из руководства Viteподключить репозиторий, команда npm run build, папка dist
Подводный каменьсайт живёт по адресу /имя-репозитория/, нужен base: '/team-store/' в vite.config.ts, иначе пустая страница и 404 на скриптыпочти нет
Бонус для пары—Deploy Preview: у каждого PR своя ссылка, ревьюер смотрит результат без клонирования

Для работы в паре Netlify удобнее: ревьюер открывает превью прямо из PR. Если нужен GitHub Pages, первым делом задеплойте пустой каркас и проверьте base.

Проверяйте опубликованную версию в режиме инкогнито. Так вы увидите её глазами проверяющего: без своего localStorage, без входа в аккаунты и без кэша.
