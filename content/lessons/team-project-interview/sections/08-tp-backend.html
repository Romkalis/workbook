А если хочется свой сервер

Задание разрешает «собственный сервер» по желанию. Честно взвесим:

  • Плюсы: больше тем для разговора (REST, коды ответов, валидация, CORS), опыт fullstack.
  • Минусы: два деплоя вместо одного. Бесплатный хостинг усыпляет сервер, и на записи первый запрос может идти полминуты. Появляются загрузка, ошибки сети и CORS. И главное: оба должны понимать серверную часть, иначе один из вас не сможет о ней рассказать.

Разумный компромисс: сделать всё на данных в файле, а сервер добавить отдельной задачей в «если останется время». Логика корзины уже лежит в чистых функциях domain/, поэтому на сервер она переносится без изменений. Ровно так устроен API в уроке Express на TypeScript: там те же filterProducts и calculateCart, маршрут POST /api/cart/quote и тесты через supertest. Основы сервера — в уроке Основы Node.js и Express.
