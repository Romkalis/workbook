Бонус: кэш и дедупликация

Бонус за 6 баллов: одинаковый запрос берётся из кэша, а если такой же уже летит, второй не создаётся. Ловушка в последней фразе условия: если двое ждут один и тот же промис, отмена у одного не должна ломать его второму. Значит, сетевой запрос получает свой, внутренний контроллер, а каждый вызывающий — собственную обёртку над общим промисом.

function withSignal<T>(shared: Promise<T>, signal: AbortSignal): Promise<T> {
  if (signal.aborted) return Promise.reject(signal.reason);
  return new Promise<T>((resolve, reject) => {
    const onAbort = () => reject(signal.reason);
    signal.addEventListener('abort', onAbort, { once: true });
    shared.then(resolve, reject).finally(() => signal.removeEventListener('abort', onAbort));
  });
}

export function createCachedSearch<T>(fetcher: (q: string, s: AbortSignal) => Promise<T>) {
  const done = new Map<string, T>();
  const inFlight = new Map<string, { promise: Promise<T>; controller: AbortController; users: number }>();

  return (query: string, signal: AbortSignal): Promise<T> => {
    const key = query.trim().toLowerCase();
    if (done.has(key)) return Promise.resolve(done.get(key)!);

    let entry = inFlight.get(key);
    if (!entry) {
      const controller = new AbortController();
      const promise = fetcher(key, controller.signal)
        .then((data) => { done.set(key, data); return data; })
        .finally(() => inFlight.delete(key));
      promise.catch(() => {});                    // не даём «необработанному» отказу шуметь
      entry = { promise, controller, users: 0 };
      inFlight.set(key, entry);
    }
    const e = entry;
    e.users++;
    signal.addEventListener('abort', () => {
      if (--e.users === 0) e.controller.abort();   // гасим сеть, только когда запрос не нужен никому
    }, { once: true });
    return withSignal(e.promise, signal);
  };
}

Проверено тестом: два вызова 'Spain' и 'spain' дают один сетевой запрос; отмена первого отклоняет только его промис с AbortError, внутренний сигнал при этом не срабатывает; второй получает данные; третий вызов берёт их из кэша без сети.

В кэш попадают только успешные ответы: ошибка не должна «залипать». Пустой результат 404 кэшировать можно, это тоже ответ. Подключается обёртка так: const search = createCachedSearch(searchCountries), и в createSearch вызывается search вместо searchCountries.

Когда все отказались от запроса, он отменяется, и записи в done не появится. Отменённый запрос не портит кэш, и следующий такой же ввод пойдёт в сеть заново.

Сложность кэша

Map даёт поиск и вставку в среднем за O(1). Нормализация ключа — O(k), где k — длина строки. Память растёт как O(число разных запросов × размер ответа). Без ограничения кэш растёт всю сессию: можно хранить последние, скажем, 50 ключей. Map помнит порядок вставки, поэтому самый старый ключ — map.keys().next().value.
