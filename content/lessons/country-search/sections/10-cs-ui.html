Интерфейс и состояния

Ограничения условия: body в index.html пустой, кроме скрипта, и никакого innerHTML для динамики. Элементы создаются через document.createElement, текст — через textContent. Это заодно защищает от XSS: строка из API никогда не станет разметкой.

function el<K extends keyof HTMLElementTagNameMap>(
  tag: K, text?: string, className?: string,
): HTMLElementTagNameMap[K] {
  const node = document.createElement(tag);
  if (text) node.textContent = text;
  if (className) node.className = className;
  return node;
}

function render(state: State): void {
  list.replaceChildren();                // очистить без innerHTML
  switch (state.kind) {
    case 'idle': return;
    case 'loading': list.append(el('p', 'Ищем…', 'loading')); return;
    case 'empty': list.append(el('p', `По «${state.query}» ничего не найдено`, 'empty')); return;
    case 'error': list.append(el('p', errorText(state.reason), 'error'), retryButton); return;
    case 'results': list.append(...state.items.map(renderCard)); return;
  }
}

Благодаря размеченному объединению State TypeScript внутри каждой ветки знает, какие поля есть: state.items доступен только в results. Добавьте ветку default: { const never: never = state; return never; }: если появится новое состояние, а отрисовать его забудут, компилятор выдаст ошибку.

СостояниеКак выглядит
idleпусто, запросов нет
loadingиндикатор загрузки
resultsкарточки: флаг, название, столица, регион, население
emptyспокойное «ничего не найдено», нейтральный цвет
errorсообщение (разное для таймаута, сети и HTTP) и кнопка «Повторить»

«Ничего не найдено» не должно быть похоже на ошибку: другой цвет, без иконки предупреждения. Индикатор загрузки и сообщения стоит обернуть в контейнер с aria-live="polite", чтобы скринридер озвучивал смену состояния (из общих знаний).

Кнопка «Повторить»

retry() вызывает run(lastQuery), где lastQuery — последний введённый текст, а не текст упавшего запроса. Обычно они совпадают, но если пользователь успел что-то дописать, повторять устаревший запрос нет смысла. Повтор идёт без debounce: пользователь уже явно попросил.

Детальный вид

Карточку делайте кнопкой (<button>) или ссылкой: так она работает с клавиатуры. Детали удобно показать в <dialog> через showModal() — браузер сам ловит Esc и держит фокус внутри. Данные — из того же сырого объекта: площадь, границы (borders — коды стран вроде FRA), языки, валюты. Отдельный запрос не нужен. Для деталей пригодится вторая чистая функция mapCountryDetails, её тоже легко покрыть тестом.

Проверить поведение руками помогут DevTools: вкладка Network, режим Slow 3G для гонки и Offline для ошибки.
