Источники и границы урока

Основа — условие задания. Весь код урока (debounce, searchCountries, HttpError, mapCountryResponse, classifyError, createSearch, кэш с дедупликацией) собран в одном проекте и запущен в Node 22: тесты на node:test проходят, searchCountries проверен на живом countries.dev (200, 404, отмена, таймаут, сетевой сбой). Примеры тестов в уроке записаны в синтаксисе Vitest и повторяют запущенные проверки, сам Vitest не запускался. Структура файлов, задержка debounce, сообщения коммитов и разметка интерфейса — авторские предложения.

  • Country Search — условие задания — разобрано полностью: требования, чек-лист, критерии и штрафы.
  • countries.dev — форма ответа, статус 404 и CORS проверены реальными запросами 15.11.2026. Документация API доступна, отдельно не разбиралась.
  • MDN: AbortController, AbortSignal.timeout(), AbortSignal.any() — сверены имена ошибок и поведение.
  • MDN: Response.ok — диапазон 200–299 и то, что fetch не отклоняется на HTTP-ошибках.
  • Async Programming, Event Loop & Animation, Error Handling — материалы из условия, в этой работе не разбирались. Близкие темы есть в уроках Core JS Promises и Обработка ошибок.
  • Конвенция коммитов RS School, Pull Request Requirements, Cross-check — страницы открываются; содержание PR-требований разобрано в уроке News API.

Условие ссылается на restcountries.com v3.1 как на исторический источник: по словам авторов задания, он устарел, а v5 требует ключ. Старые решения из интернета используют другую форму ответа, учитывайте это.
