searchCountries и HttpError

Главная ловушка: fetch не бросает исключение на ответах 4xx и 5xx. Промис отклоняется только при сетевом сбое или отмене. Статус нужно проверять самим через response.ok (он равен true для статусов 200–299).

export class HttpError extends Error {
  readonly status: number;
  constructor(status: number) {
    super(`HTTP ${status}`);
    this.name = 'HttpError';
    this.status = status;
  }
}

Свой класс ошибки позже позволит отличить его через instanceof. Зачем задавать name и как вообще наследоваться от Error, рассказано в Обработке ошибок.

const API = 'https://countries.dev/name/';
export const TIMEOUT_MS = 8000;

export async function searchCountries(query: string, signal: AbortSignal): Promise<RawCountry[]> {
  const combined = AbortSignal.any([signal, AbortSignal.timeout(TIMEOUT_MS)]);
  const response = await fetch(API + encodeURIComponent(query), { signal: combined });

  if (response.status === 404) return [];          // совпадений нет — это не ошибка
  if (!response.ok) throw new HttpError(response.status);
  return (await response.json()) as RawCountry[];
}

Порядок проверок важен: сначала 404, потом ok. Иначе 404 превратится в HttpError. Тело ответа 404 — простой текст, поэтому response.json() на нём упал бы; мы его и не вызываем. encodeURIComponent защищает адрес от пробелов и символов вроде / или ? в запросе.

Таймаут и объединение сигналов

searchCountries получает один сигнал, а отменять запрос нужно по двум причинам: новый ввод и слишком долгое ожидание. AbortSignal.timeout(ms) создаёт сигнал, который сработает сам через ms миллисекунд. AbortSignal.any([...]) собирает несколько сигналов в один: он срабатывает от первого из них и берёт его причину (reason).

Все строки, кроме CORS, проверены в Node 22 на живом API (TypeError при CORS — по спецификации fetch). AbortSignal.any есть во всех актуальных браузерах с 2024 года и в Node с версии 20.3 (из общих знаний, сверьте с таблицей совместимости).

Как тестировать без сети

Подменяем глобальный fetch функцией, которая возвращает готовый Response:

test('404 — пустой массив', async () => {
  vi.stubGlobal('fetch', async () => new Response('Country not found', { status: 404 }));
  await expect(searchCountries('zz', new AbortController().signal)).resolves.toEqual([]);
});

test('500 — HttpError со статусом', async () => {
  vi.stubGlobal('fetch', async () => new Response('', { status: 500 }));
  await expect(searchCountries('zz', new AbortController().signal))
    .rejects.toMatchObject({ name: 'HttpError', status: 500 });
});

Ещё один полезный тест: мок fetch запоминает URL, и вы проверяете, что запрос "south africa" превратился в south%20africa.
