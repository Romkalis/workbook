debounce

Debounce («подавление дребезга») откладывает вызов функции, пока события не затихнут. Каждое новое нажатие клавиши сбрасывает таймер, и запрос уходит только когда пользователь сделал паузу. Это функция высшего порядка: принимает функцию и возвращает новую.

export function debounce<A extends unknown[]>(fn: (...args: A) => void, delay: number) {
  let timer: ReturnType<typeof setTimeout> | undefined;

  const debounced = (...args: A): void => {
    clearTimeout(timer);                          // сбрасываем прошлый отсчёт
    timer = setTimeout(() => fn(...args), delay); // и начинаем новый
  };
  debounced.cancel = (): void => clearTimeout(timer);
  return debounced;
}

Таймер живёт в замыкании: каждая копия debounce хранит свой. Метод cancel пригодится, когда поле очистили: отложенный запрос по старому тексту уже не нужен. clearTimeout(undefined) ничего не делает и не бросает ошибку, поэтому первый вызов не требует проверки.

Тест с фейковыми таймерами

Ждать 300 мс в каждом тесте — нарушение FIRST (Fast). Фейковые таймеры позволяют «перемотать» время вручную:

import { vi, test, expect } from 'vitest';

test('вызывает fn один раз с последними аргументами', () => {
  vi.useFakeTimers();
  const fn = vi.fn();
  const d = debounce(fn, 300);

  d('s');  vi.advanceTimersByTime(200);
  d('sp'); vi.advanceTimersByTime(200);   // таймер сброшен, прошло только 200
  expect(fn).not.toHaveBeenCalled();

  vi.advanceTimersByTime(100);
  expect(fn).toHaveBeenCalledOnce();
  expect(fn).toHaveBeenCalledWith('sp');
  vi.useRealTimers();
});

Тот же сценарий проверен в node:test с mock.timers. В Jest это jest.useFakeTimers() и jest.advanceTimersByTime().

Какую задержку выбрать

Обычно берут 250–400 мс (из общих знаний): это чуть больше паузы между нажатиями при уверенном наборе. Для DESIGN.md опишите крайние случаи:

  • Без задержки запрос уходит на каждую букву. «spain» — пять запросов, четыре из которых тут же отменяются. Нагрузка на API растёт, мерцает индикатор загрузки.
  • Большая задержка (1–2 с) — интерфейс кажется «тормозным»: человек допечатал и ждёт, ничего не происходит.
