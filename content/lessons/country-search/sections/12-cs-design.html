DESIGN.md, чек-лист и сдача

DESIGN.md стоит 20 баллов и проверяется по четырём пунктам. Каркас, который можно заполнить материалом этого урока:

# Country Search — дизайн решения

## Отмена устаревших запросов
Один AbortController на активный запрос, abort() на каждый ввод...
Почему не флаг: запрос продолжает идти, в Network не виден как canceled...

## Задержка debounce: 300 мс
Без задержки — запрос на каждую букву...; 1–2 с — интерфейс «тормозит»...

## Сложность
mapCountryResponse — O(L), L — число языков...
Кэш — O(1) в среднем на поиск и вставку, память O(запросов × ответ)...

## Чистый код
- Единственная ответственность: src/lib/api.ts только запрос, map-country.ts только маппинг
- Чистые функции: mapCountryResponse, classifyError
- Без магических чисел: TIMEOUT_MS, DEBOUNCE_MS в константах
- Логика не зависит от DOM: src/lib/search.ts сообщает состояние колбэком

В последнем пункте важно указать конкретные файлы и функции: общие слова вроде «код чистый» баллов не принесут. Сами принципы — в уроке Clean Code.

Ручной чек-лист на деплое

  • Пустой ввод: в Network нет запросов, список пуст.
  • Во время запроса виден индикатор (включите Slow 3G, чтобы успеть заметить).
  • Быстрый набор не показывает устаревших результатов, а в Network старые запросы помечены (canceled).
  • Отмена своего запроса не показывается как ошибка.
  • Запрос без совпадений показывает «ничего не найдено».
  • Offline на секунду → ошибка с кнопкой «Повторить», повтор уходит с последним введённым текстом.
  • Клик по карточке открывает детали.

Проверьте себя

Почему fetch не попадает в catch при ответе 500?

Промис fetch отклоняется только при сетевом сбое или отмене. Любой полученный ответ, даже 500, — успех на уровне сети. Статус проверяют через response.ok.

Чем отличается отмена от таймаута в catch?

Оба приходят как DOMException, но с разным name: AbortError — наша отмена, её молча пропускаем; TimeoutError — сервер не ответил, это ошибка для пользователя.

Зачем мок fetch в тесте гонки слушает signal?

Иначе тест не отличит настоящую отмену от игнорирования ответа флагом. Мок, который отклоняется при abort(), проверяет, что приложение действительно отменило запрос.
