Вопросы и словарь

Почему querySelector может вернуть null, а querySelectorAll — нет?

Один элемент может не найтись, и это выражено через null. Коллекция в этом случае просто пустая.

Чем опасен innerHTML с данными?

Строка разбирается как HTML, поэтому текст вроде <img onerror=...> станет элементом и выполнит код (XSS). Данные вставляют через textContent.

Почему значение поля читают через input.value, а не getAttribute('value')?

Атрибут хранит начальное значение из HTML, а свойство — текущее, которое меняет пользователь.

Зачем функция createCard возвращает элемент, а не вставляет его сама?

Так она отвечает за одно — превращение данных в элемент. Её можно протестировать, вставить в любой список или заменить ею старую карточку.

DOM
Дерево объектов, которое браузер строит из HTML; JavaScript меняет страницу через него.
Узел, элемент
Любой объект дерева (в том числе текст) и узел-тег соответственно.
XSS
Внедрение чужого скрипта на страницу, чаще всего через innerHTML с данными.
dataset
Доступ к атрибутам data-* элемента; значения — строки.
template
Тег с разметкой, которая не показывается и клонируется скриптом.
aria-live
Атрибут, при изменении которого программа чтения с экрана объявляет новый текст.
