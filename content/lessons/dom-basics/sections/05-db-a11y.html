Доступность: семантика и сообщения

Кнопка — это button

Кликабельный div не получает фокус с клавиатуры, не нажимается Enter и пробелом и не объявляется программой чтения с экрана как кнопка. <button type="button"> даёт всё это бесплатно. Ссылка <a href> — для перехода по адресу, кнопка — для действия на странице. type="button" важен внутри формы: без него кнопка по умолчанию отправляет форму.

Задача 19. Из div в button ★☆☆ разминка

Разметка ниже сделана на div. Перепишите функцию, создающую кнопку «Удалить», так, чтобы она работала с клавиатуры и называлась для программы чтения с экрана «Удалить Каркассон», хотя на экране виден только значок ✕.

export function createRemoveButton(title: string) {
  const div = document.createElement('div');
  div.className = 'remove';
  div.textContent = '✕';
  return div;
}

Зачем: значок без подписи для незрячего пользователя — просто «крестик» или вообще ничего. А div не попадает в порядок перехода по Tab. Две строки разметки решают обе проблемы.

Решение и разбор
// remove-button.ts
export function createRemoveButton(title: string): HTMLButtonElement {
  const button = document.createElement('button');
  button.type = 'button';
  button.className = 'remove';
  button.textContent = '✕';
  button.setAttribute('aria-label', `Удалить ${title}`);
  return button;
}

button сам получает фокус и нажимается Enter и пробелом. aria-label заменяет доступное имя кнопки, поэтому программа чтения скажет «Удалить Каркассон, кнопка», а не «крестик». Название товара в подписи важно: в корзине десять одинаковых крестиков, и без него непонятно, что удалит каждый.

Сообщить о переменах

Когда JavaScript меняет часть страницы («Товар добавлен», «Найдено 3 товара»), зрячий пользователь это видит, а незрячий — нет. Элемент с атрибутом aria-live="polite" объявляется программой чтения с экрана при каждом изменении текста (из общих знаний о WAI-ARIA). Его создают заранее, пустым, и потом меняют textContent:

<p class="status" aria-live="polite"></p>

Задача 20. Объявить результат поиска ★☆☆ разминка

Напишите announce(status, count), которая пишет в элемент со aria-live="polite" «Найдено N товаров» с правильным окончанием (1 товар, 2 товара, 5 товаров, 11 товаров), а для нуля — «Ничего не найдено».

Зачем: текст объявления — тоже интерфейс, и «Найдено 1 товаров» режет слух так же, как опечатка на кнопке. Функция склонения пригодится в десятке мест: корзина, отзывы, поиск.

Решение и разбор
// announce.ts
export function plural(n: number, [one, few, many]: [string, string, string]): string {
  const mod10 = n % 10;
  const mod100 = n % 100;
  if (mod10 === 1 && mod100 !== 11) return one;
  if (mod10 >= 2 && mod10 <= 4 && (mod100 < 12 || mod100 > 14)) return few;
  return many;
}

export function announce(status: HTMLElement, count: number): void {
  status.textContent = count === 0 ? 'Ничего не найдено' : `Найдено ${count} ${plural(count, ['товар', 'товара', 'товаров'])}`;
}

Склонение вынесено в чистую функцию с кортежем форм: её легко покрыть таблицей тестов, как в задаче про test.each из урока о тестировании. Элемент aria-live создаётся в HTML заранее, а функция только меняет его текст. Если вставить live-элемент одновременно с текстом, часть программ чтения его не объявит (из общих знаний).
