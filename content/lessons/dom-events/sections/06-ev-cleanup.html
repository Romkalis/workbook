Отписка и свои события

Снять обработчики разом

Обработчик держит ссылки на всё, что использует. Если компонент удалён со страницы, а обработчик на window или document остался, он продолжит срабатывать и мешать — это утечка. removeEventListener требует ту же самую функцию, что передавали в add, поэтому стрелку «на месте» снять нельзя. Проще передать всем обработчикам один signal:

export function mountShortcuts(onClose: () => void, onSearch: () => void): () => void {
  const controller = new AbortController();
  const { signal } = controller;
  document.addEventListener('keydown', (e) => { if (e.key === 'Escape') onClose(); }, { signal });
  document.addEventListener('keydown', (e) => { if (e.key === '/' ) onSearch(); }, { signal });
  return () => controller.abort(); // одна функция снимает все обработчики
}

Функция «смонтировать» возвращает функцию «размонтировать» — тот же договор, что у useEffect в React. Тот же AbortController отменяет и запросы fetch (Country Search): один сигнал может остановить и подписки, и загрузку.

Задача 19. Компонент, который убирает за собой ★★☆ практика

Напишите mountDropdown(button, menu): клик по кнопке переключает menu.hidden, клик в любом месте документа вне меню и кнопки закрывает меню, Escape на документе закрывает меню. Функция возвращает unmount(), которая снимает все обработчики одним вызовом.

Зачем: обработчики на document переживают сам компонент. Если меню удалили со страницы, а слушатели остались, они продолжат реагировать на каждый клик, а с повторным монтированием их станет вдвое больше. signal делает уборку одной строкой.

Решение и разбор
// dropdown.ts
export function mountDropdown(button: HTMLElement, menu: HTMLElement): () => void {
  const controller = new AbortController();
  const { signal } = controller;

  button.addEventListener('click', () => {
    menu.hidden = !menu.hidden;
  }, { signal });

  document.addEventListener('click', (event) => {
    const target = event.target;
    if (target instanceof Node && !menu.contains(target) && !button.contains(target)) menu.hidden = true;
  }, { signal });

  document.addEventListener('keydown', (event) => {
    if (event.key === 'Escape') menu.hidden = true;
  }, { signal });

  return () => controller.abort();
}

Клик по кнопке всплывает до document, поэтому обработчик документа исключает и меню, и кнопку. Иначе меню открывалось бы и тут же закрывалось. Все три подписки получили один signal, и unmount снимает их разом, не храня ссылок на функции.

Свои события

Элемент может генерировать и своё событие: new CustomEvent('cart:change', { detail: данные, bubbles: true }) и element.dispatchEvent(event). Слушатели получают данные в event.detail. Это способ связать независимые части страницы: корзина объявляет «изменилась», а счётчик в шапке слушает и обновляется, не зная, как устроена корзина. В TypeScript detail типизируют через CustomEvent<Тип>.

export type CartChange = { count: number };

export function announceCart(el: EventTarget, count: number): void {
  el.dispatchEvent(new CustomEvent<CartChange>('cart:change', { detail: { count }, bubbles: true }));
}

export function onCartChange(el: EventTarget, handler: (detail: CartChange) => void): void {
  el.addEventListener('cart:change', (event) => {
    if (event instanceof CustomEvent) handler(event.detail as CartChange);
  });
}

Задача 20. Счётчик в шапке через своё событие ★★☆ практика

Корзина при каждом изменении генерирует на своём элементе всплывающее событие cart:change с { count }. Напишите mountCartBadge(badge): слушает это событие на document и показывает число в бейдже, пряча его при нуле. Корзина и бейдж не импортируют друг друга.

Зачем: независимые части интерфейса не должны знать друг о друге: шапку можно переделать, не трогая корзину. Событие — договор «что случилось и с какими данными», и его легко проверить в тесте.

Решение и разбор
// badge.ts
export type CartChange = { count: number };

export function mountCartBadge(badge: HTMLElement): void {
  document.addEventListener('cart:change', (event) => {
    if (!(event instanceof CustomEvent)) return;
    const { count } = event.detail as CartChange;
    badge.textContent = String(count);
    badge.hidden = count === 0;
  });
}

export function emitCartChange(from: EventTarget, count: number): void {
  from.dispatchEvent(new CustomEvent<CartChange>('cart:change', { detail: { count }, bubbles: true }));
}

Без bubbles: true событие осталось бы на элементе корзины, и слушатель на document его бы не получил. Тип CartChange вынесен и экспортирован: это общий договор для обеих сторон. В большом проекте договоры событий собирают в один файл. Альтернатива событиям — общий стор с подпиской, его разберём в следующем уроке.
