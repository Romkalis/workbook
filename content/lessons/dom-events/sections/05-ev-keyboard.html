Клавиатура и фокус

event.key

keydown срабатывает при нажатии клавиши. event.key — понятное имя: 'Enter', 'Escape', 'ArrowDown', 'a'. Старое event.keyCode устарело и отличается между раскладками. Закрыть окно по Escape — стандартное ожидание пользователя; для <dialog> браузер делает это сам.

Задача 16. Закрыть по Escape ★☆☆ разминка

Напишите closeOnEscape(panel, close): нажатие Escape, когда фокус внутри панели, вызывает close(). Остальные клавиши ничего не делают. Используйте event.key.

Зачем: Escape — ожидание пользователя для всего, что всплывает: меню, панели, подсказки. Обработчик на панели, а не на всём документе, не мешает другим компонентам со своим Escape.

Решение и разбор
// escape.ts
export function closeOnEscape(panel: HTMLElement, close: () => void): void {
  panel.addEventListener('keydown', (event) => {
    if (event.key === 'Escape') close();
  });
}

keydown всплывает, поэтому обработчик на панели поймает Escape из любого поля внутри неё. event.key === 'Escape' одинаков во всех раскладках, в отличие от устаревшего keyCode === 27.

Задача 17. Теги по Enter ★★☆ практика

Поле ввода тегов: Enter добавляет тег (обрезанный, в нижнем регистре, без повторов и пустых) в список ul и очищает поле. При этом Enter не должен отправлять форму, в которой лежит поле. Backspace в пустом поле удаляет последний тег.

Зачем: клавиатура — полноценный способ управления, а не дополнение к мыши. И это хороший пример, когда preventDefault нужен для keydown: Enter в текстовом поле по умолчанию отправляет форму.

Решение и разбор
// tags.ts
export function mountTags(input: HTMLInputElement, list: HTMLUListElement): () => string[] {
  const tags: string[] = [];
  const render = () => list.replaceChildren(...tags.map((t) => Object.assign(document.createElement('li'), { textContent: t })));

  input.addEventListener('keydown', (event) => {
    if (event.key === 'Enter') {
      event.preventDefault();
      const tag = input.value.trim().toLowerCase();
      if (tag !== '' && !tags.includes(tag)) tags.push(tag);
      input.value = '';
      render();
    } else if (event.key === 'Backspace' && input.value === '' && tags.length > 0) {
      tags.pop();
      render();
    }
  });
  return () => [...tags];
}

Список тегов — данные в массиве, а render рисует его заново после каждого изменения. Здесь это уже маленький «состояние → отрисовка», тема следующего урока. Функция возвращает геттер с копией массива: снаружи теги можно прочитать, но не испортить.

Куда переходит фокус

После действия фокус должен оказаться в разумном месте. Удалили товар из корзины — кнопка удаления исчезла вместе с фокусом, и пользователь клавиатуры оказывается «в начале страницы». Правильно перевести фокус, например, на следующую строку или на заголовок корзины: element.focus(). Элементу без собственного фокуса (заголовку) нужен tabindex="-1", чтобы его можно было сфокусировать скриптом, не добавляя в порядок Tab.

Задача 18. Фокус после удаления строки ★★☆ практика

Напишите removeRowAndRefocus(row, heading): удаляет строку корзины и переводит фокус на кнопку удаления следующей строки, а если следующей нет — предыдущей, а если строк не осталось — на заголовок корзины (у заголовка tabindex="-1").

Зачем: когда удаляется элемент с фокусом, браузер «теряет» фокус, и пользователь клавиатуры оказывается в начале страницы. Перевести фокус в соседнюю строку — то, что ожидает человек, удаляющий несколько товаров подряд.

Решение и разбор
// refocus.ts
export function removeRowAndRefocus(row: HTMLElement, heading: HTMLElement): void {
  const neighbour = (row.nextElementSibling ?? row.previousElementSibling) as HTMLElement | null;
  row.remove();
  const target = neighbour?.querySelector<HTMLElement>('button') ?? heading;
  target.focus();
}

Соседа ищем до удаления: после remove у строки больше нет соседей. Следующая строка в приоритете, потому что она заняла место удалённой, и пользователь продолжает ровно оттуда. Заголовок с tabindex="-1" принимает фокус от скрипта, но не появляется в обходе по Tab.
