Обработчик и объект события

Пользователь кликает, печатает, отправляет форму — браузер создаёт событие и вызывает функции, которые на него подписаны. Подписка — addEventListener(тип, обработчик):

const button = document.querySelector('button');
button?.addEventListener('click', (event) => {
  console.log(event.type); // 'click'
});

Обработчик получает объект события. В нём то, что нужно для реакции: event.target — элемент, где событие произошло (по нему кликнули), event.currentTarget — элемент, на котором висит обработчик, event.key у клавиатуры, event.preventDefault() — отменить действие браузера. Это урок о DOM-событиях; про события в Node.js и EventEmitter — в уроке Основы Node.js, идея та же: подписались и получаем уведомления.

target и currentTarget

Внутри кнопки бывают иконка и текст. Клик по иконке: target — сама иконка (svg или span), currentTarget — кнопка, на которой обработчик. Если вам нужна кнопка, берите currentTarget. target нужен, когда обработчик висит на общем родителе и надо понять, где именно кликнули (делегирование ниже).

Задача 2. target или currentTarget ★☆☆ разминка

Кнопки «В корзину» содержат иконку и текст. Обработчик на кнопке должен прочитать data-id кнопки и вызвать onAdd(id). Код ниже иногда передаёт undefined. Найдите причину и исправьте.

button.addEventListener('click', (event) => {
  const id = (event.target as HTMLElement).dataset.id;
  onAdd(id!);
});

Зачем: баг «работает, только если кликнуть по краю кнопки» — классика. Он проявляется не у всех и не всегда, поэтому его долго не замечают.

Решение и разбор
// add.ts
export function listenAdd(button: HTMLButtonElement, onAdd: (id: string) => void): void {
  button.addEventListener('click', (event) => {
    const id = (event.currentTarget as HTMLElement).dataset.id;
    if (id) onAdd(id);
  });
}

Клик по иконке делает target иконкой, у которой нет data-id. currentTarget — всегда кнопка, на которой висит обработчик. Утверждение as HTMLElement здесь оправдано: обработчик привязан к кнопке, и currentTarget не может быть ничем другим. Проверка if (id) заменяет опасный ! из исходного кода.

Опции: once и signal

Третий аргумент — объект опций. { once: true } снимает обработчик после первого вызова: подходит для «показать подсказку один раз». { signal } привязывает обработчик к AbortController: вызов controller.abort() снимает разом все обработчики с этим сигналом. Подробно — в разделе об отписке.

Задача 1. Счётчик кликов ★☆☆ разминка

Напишите mountCounter(button, output): каждый клик по кнопке увеличивает число в output на 1. Счётчик хранится в переменной, а не читается из текста элемента.

Зачем: источник истины — данные, а DOM их только показывает. Если читать число из textContent, то любое изменение формата («Кликов: 3») сломает подсчёт. Это самый маленький пример принципа, на котором построен урок о состоянии.

Решение и разбор
// counter.ts
export function mountCounter(button: HTMLButtonElement, output: HTMLElement): void {
  let count = 0;
  output.textContent = String(count);
  button.addEventListener('click', () => {
    count += 1;
    output.textContent = String(count);
  });
}

Переменная count живёт в замыкании обработчика: снаружи её не испортить, и у каждого вызова mountCounter свой счётчик. Начальное значение тоже отрисовывается при монтировании, чтобы на экране не было пустоты до первого клика.

Задача 3. Подсказка один раз ★☆☆ разминка

Напишите showHintOnce(field, hint): при первом фокусе на поле показывает подсказку (hint.hidden = false), при следующих — ничего не делает. Без флагов в переменных.

Зачем: опция once выражает намерение прямо в подписке, и обработчик сам убирается после срабатывания. Флаг «уже показали» пришлось бы хранить, проверять и не забывать.

Решение и разбор
// hint.ts
export function showHintOnce(field: HTMLElement, hint: HTMLElement): void {
  field.addEventListener('focus', () => {
    hint.hidden = false;
  }, { once: true });
}

После первого вызова браузер сам снимает обработчик. Если пользователь закрыл подсказку и снова зашёл в поле, она не вернётся, и это именно то поведение, которое нужно.
