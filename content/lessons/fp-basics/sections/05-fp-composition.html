Композиция функций

Композиция — соединение функций в цепочку, где результат одной становится аргументом следующей. Из маленьких функций собирается большая, как труба из отрезков.

const trim = (s) => s.trim();
const lower = (s) => s.toLowerCase();
const toSlug = (s) => s.replace(/\s+/g, '-');

// Вручную: читать изнутри наружу неудобно
toSlug(lower(trim('  Hello Big World '))); // 'hello-big-world'

Чтобы не плодить скобки, пишут вспомогательные функции pipe и compose. Обе принимают список функций и возвращают новую функцию:

// pipe: слева направо, в порядке выполнения
const pipe = (...fns) => (x) => fns.reduce((acc, fn) => fn(acc), x);

// compose: справа налево, как в математике f(g(x))
const compose = (...fns) => (x) => fns.reduceRight((acc, fn) => fn(acc), x);

const slugify = pipe(trim, lower, toSlug);
slugify('  Hello Big World '); // 'hello-big-world'
compose(toSlug, lower, trim)('  Hello Big World '); // то же самое

Порядок важен. При inc = x => x + 1 и double = x => x * 2:

pipe(inc, double)(3);    // (3 + 1) * 2 = 8
compose(inc, double)(3); // 3 * 2 + 1 = 7

Композиция хорошо работает, когда каждая функция принимает один аргумент. Функции с несколькими аргументами приводят к одному с помощью каррирования — оно в разделе ниже. Две задачи Codewars модуля (function-composition) как раз про реализацию compose.

orders.filter(...).map(...).reduce(...) из первого раздела — тоже композиция, только через цепочку методов. pipe нужен, когда функции не являются методами одного объекта.
