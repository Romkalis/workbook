Композиция функций

Композиция — соединение функций в цепочку, где результат одной становится аргументом следующей. Из маленьких функций собирается большая, как труба из отрезков.

const trim = (s) => s.trim();
const lower = (s) => s.toLowerCase();
const toSlug = (s) => s.replace(/\s+/g, '-');

// Вручную: читать изнутри наружу неудобно
toSlug(lower(trim('  Hello Big World '))); // 'hello-big-world'

Чтобы не плодить скобки, пишут вспомогательные функции pipe и compose. Обе принимают список функций и возвращают новую функцию:

// pipe: слева направо, в порядке выполнения
const pipe = (...fns) => (x) => fns.reduce((acc, fn) => fn(acc), x);

// compose: справа налево, как в математике f(g(x))
const compose = (...fns) => (x) => fns.reduceRight((acc, fn) => fn(acc), x);

const slugify = pipe(trim, lower, toSlug);
slugify('  Hello Big World '); // 'hello-big-world'
compose(toSlug, lower, trim)('  Hello Big World '); // то же самое

Порядок важен. При inc = x => x + 1 и double = x => x * 2:

pipe(inc, double)(3);    // (3 + 1) * 2 = 8
compose(inc, double)(3); // 3 * 2 + 1 = 7

Композиция хорошо работает, когда каждая функция принимает один аргумент. Функции с несколькими аргументами приводят к одному с помощью каррирования — оно в разделе ниже. Две задачи Codewars модуля (function-composition) как раз про реализацию compose.

orders.filter(...).map(...).reduce(...) из первого раздела — тоже композиция, только через цепочку методов. pipe нужен, когда функции не являются методами одного объекта.

Задача 9. Конвейер из маленьких функций ★★☆ практика

Напишите pipe(...fns), которая возвращает функцию, применяющую fns слева направо. Соберите из маленьких чистых функций slugify: " Привет, Мир! JS 2026 " → "privet-mir-js-2026". Шаги: обрезать пробелы, нижний регистр, транслитерация (дана), заменить всё, кроме латиницы и цифр, на дефис, схлопнуть повторные дефисы, убрать дефисы по краям.

// translit.ts
const MAP: Record<string, string> = { а: 'a', б: 'b', в: 'v', г: 'g', д: 'd', е: 'e', ё: 'e', ж: 'zh', з: 'z', и: 'i', й: 'y', к: 'k', л: 'l', м: 'm', н: 'n', о: 'o', п: 'p', р: 'r', с: 's', т: 't', у: 'u', ф: 'f', х: 'h', ц: 'ts', ч: 'ch', ш: 'sh', щ: 'sch', ъ: '', ы: 'y', ь: '', э: 'e', ю: 'yu', я: 'ya' };
export const translit = (s: string) => [...s].map((c) => MAP[c] ?? c).join('');

Зачем: композиция превращает сложную функцию в список понятных шагов. Каждый шаг тестируется отдельно, переставляется и заменяется. Порядок важен: транслитерация до «оставить только латиницу», иначе от русского текста ничего не останется.

Решение и разбор
import { translit } from './translit.js';

type Fn<T> = (x: T) => T;
export const pipe =
  <T>(...fns: Fn<T>[]): Fn<T> =>
  (x) =>
    fns.reduce((acc, fn) => fn(acc), x);

const trim: Fn<string> = (s) => s.trim();
const lower: Fn<string> = (s) => s.toLowerCase();
const onlyLatin: Fn<string> = (s) => s.replace(/[^a-z0-9]+/g, '-');
const collapse: Fn<string> = (s) => s.replace(/-+/g, '-');
const trimDashes: Fn<string> = (s) => s.replace(/^-|-$/g, '');

export const slugify = pipe(trim, lower, translit, onlyLatin, collapse, trimDashes);

pipe — это reduce по списку функций: аккумулятор — текущее значение. compose делает то же справа налево (compose(f, g)(x) = f(g(x)), как в математике). Здесь все шаги одного типа string → string, поэтому тип простой. Конвейер, где тип меняется на каждом шаге, в TypeScript описывают перегрузками (так делают библиотеки). Шаг collapse формально лишний, потому что + в onlyLatin уже схлопывает повторы. Его оставили, чтобы конвейер был устойчив к другим заменам.
