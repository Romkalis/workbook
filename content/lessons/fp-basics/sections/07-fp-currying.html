Каррирование и частичное применение

Каррирование — превращение функции от нескольких аргументов f(a, b, c) в цепочку функций от одного аргумента f(a)(b)(c). Название — по фамилии математика Хаскелла Карри.

// Обычная
const add = (a, b) => a + b;
add(1, 2); // 3

// Каррированная
const addC = (a) => (b) => a + b;
addC(1)(2); // 3

Само по себе это выглядит как лишние скобки. Польза появляется, когда передаёшь не все аргументы сразу.

Частичное применение

Частичное применение — вызов функции с частью аргументов, чтобы получить новую функцию, которая ждёт остальные. Первые аргументы «запоминаются» в замыкании.

const increment = addC(1);   // запомнили a = 1
const decrement = addC(-1);
increment(5); // 6
decrement(5); // 4

Это разные понятия, хотя их часто путают (на этом построена задача Codewars currying-vs-partial-application). Каррирование — преобразование функции. Частичное применение — вызов с частью аргументов. Каррированную функцию очень удобно применять частично, но частично применить можно и некаррированную:

const greet = (greeting, name) => `${greeting}, ${name}!`;

// Через встроенный bind (первый аргумент — this, здесь не нужен)
const hello = greet.bind(null, 'Привет');
hello('Аня'); // 'Привет, Аня!'

// Через свою функцию
const partial = (fn, ...fixed) => (...rest) => fn(...fixed, ...rest);
partial((a, b, c) => a + b + c, 1, 2)(3); // 6

Универсальная функция curry

Писать каждую функцию вложенными стрелками неудобно. Статья javascript.info из модуля предлагает helper, который каррирует любую функцию с фиксированным числом параметров. Вот он в стрелочной записи:

const curry = (fn) => {
  const curried = (...args) =>
    args.length >= fn.length
      ? fn(...args)                                // аргументов хватает — вызываем
      : (...more) => curried(...args, ...more);   // иначе ждём ещё
  return curried;
};

const sum3 = (a, b, c) => a + b + c;
const curriedSum = curry(sum3);
curriedSum(1, 2, 3); // 6 — можно и как обычно
curriedSum(1)(2, 3); // 6
curriedSum(1)(2)(3); // 6

fn.length — число параметров в объявлении функции. Отсюда ограничение: для (...nums) => … длина равна 0, и curry вызовет функцию сразу. Параметры со значением по умолчанию тоже не считаются: у (a, b = 2) => … длина равна 1.

Где это пригодится

Каррированные функции удобно передавать в map, filter и pipe, которым нужна функция от одного аргумента. Порядок параметров выбирают так: сначала настройки, данные в конце.

const hasRole = curry((role, user) => user.roles.includes(role));

const users = [
  { name: 'Ann', roles: ['admin'] },
  { name: 'Bob', roles: [] },
];
users.filter(hasRole('admin')); // [{ name: 'Ann', ... }]

Ещё одна польза из статьи barker.codes: тяжёлую работу можно выполнить один раз на этапе частичного применения. Например, отфильтровать большой массив по стране, а потом много раз сортировать уже отфильтрованное.
