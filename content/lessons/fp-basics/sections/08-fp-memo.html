Мемоизация

Мемоизация — запоминание результатов функции: если её уже вызывали с такими аргументами, возвращаем сохранённый ответ вместо повторного расчёта. Это обмен памяти на скорость.

const memoize = (fn) => {
  const cache = new Map();          // живёт в замыкании
  return (...args) => {
    const key = JSON.stringify(args);
    if (!cache.has(key)) cache.set(key, fn(...args));
    return cache.get(key);
  };
};

memoize — функция высшего порядка: принимает функцию и возвращает её версию с кэшем. Ключ строится из всех аргументов через JSON.stringify. В статье freeCodeCamp из модуля ключом служит только первый аргумент, и для функций от нескольких аргументов такая версия даёт неверные ответы.

Пример: числа Фибоначчи

// Без мемоизации: одни и те же значения считаются снова и снова
const slowFib = (n) => (n < 2 ? n : slowFib(n - 1) + slowFib(n - 2));
// slowFib(25) делает 242 785 вызовов

// С мемоизацией: каждое n считается один раз
const fib = memoize((n) => (n < 2 ? n : fib(n - 1) + fib(n - 2)));
fib(25); // 75025 за 26 вызовов внутренней функции

Обратите внимание: внутри рекурсия вызывает fib, то есть мемоизированную версию. Если вызывать исходную функцию, кэш будет работать только на верхнем уровне.

Попутная ловушка: fib(80) вернёт 23416728348467684, а правильный ответ — …685. Результат больше Number.MAX_SAFE_INTEGER (≈ 9·1015), и обычные числа JS теряют точность. Для таких значений нужен BigInt. Это не связано с мемоизацией, но хорошо показывает, что «быстро» не значит «верно».

Когда мемоизировать

  • Только чистые функции. memoize(() => Math.random()) будет всегда возвращать первое случайное число.
  • Когда расчёт дорогой и аргументы повторяются. Мемоизировать (a, b) => a + b бессмысленно: сериализовать ключ дольше, чем сложить.
  • Помните о памяти. Кэш растёт с каждым новым аргументом и никогда не очищается. Для бесконечного потока разных аргументов это утечка.
  • Ключ через JSON.stringify не различает некоторые значения: undefined и null внутри массива дают одинаковую строку, а функции и Map не сериализуются. Для учебных задач его хватает.

Родственник: once

Задача Codewars once просит функцию, которая выполняет переданную только при первом вызове, а дальше возвращает тот же результат. Это мемоизация с одним ключом:

const once = (fn) => {
  let done = false;
  let result;
  return (...args) => {
    if (!done) {
      done = true;
      result = fn(...args);
    }
    return result;
  };
};

const init = once(() => 42);
init(); // 42, функция выполнилась
init(); // 42, из памяти
