Функции первого класса и функции высшего порядка

В JavaScript функции — граждане первого класса (first-class functions): с функцией можно делать всё то же, что с числом или строкой. Положить в переменную, передать аргументом, вернуть из другой функции, хранить в массиве.

const greet = (name) => `Привет, ${name}`; // функция в переменной
const actions = [greet, (name) => name.toUpperCase()]; // в массиве
actions.map((fn) => fn('Аня')); // ['Привет, Аня', 'АНЯ']

Функция высшего порядка (higher-order function, HOF) — функция, которая принимает другую функцию аргументом или возвращает функцию. Функцию, которую передали аргументом, называют колбэком.

// Принимает функцию и возвращает новую
const twice = (fn) => (x) => fn(fn(x));
const inc = (x) => x + 1;
twice(inc)(5); // 7

Самые частые HOF — методы массивов: map (преобразовать каждый элемент), filter (оставить подходящие), reduce (свернуть в одно значение), some, every, find. Функция, которая возвращает true или false, называется предикатом: filter и every принимают предикаты.

Как устроены map и filter

Две задачи Codewars из модуля просят написать map и filter самостоятельно. Вот чистые версии через reduce:

const map = (arr, fn) =>
  arr.reduce((acc, x, i) => [...acc, fn(x, i, arr)], []);

const filter = (arr, predicate) =>
  arr.reduce((acc, x, i) => (predicate(x, i, arr) ? [...acc, x] : acc), []);

map([1, 2, 3], (x) => x * 2);          // [2, 4, 6]
filter([1, 2, 3, 4], (x) => x % 2 === 0); // [2, 4]

reduce идёт по массиву и каждый раз передаёт в колбэк «накопленное» (acc) и текущий элемент. Что вернёт колбэк, то станет новым acc. Второй аргумент reduce — начальное значение, здесь пустой массив.

Копирование [...acc, x] на каждом шаге делает эти версии O(n²) по времени (см. Big O в уроке «Алгоритмы и структуры данных»). Для учебного примера это неважно, а встроенные map и filter работают за O(n). Внутри своей функции мутировать локальный массив, который никто снаружи не видит, допустимо: чистота оценивается снаружи.

Замыкание

Когда функция возвращает другую функцию, внутренняя помнит переменные внешней даже после того, как внешняя завершилась. Это называется замыканием (closure). На замыканиях держатся каррирование и мемоизация, поэтому разберём на счётчике:

const createCounter = () => {
  let count = 0;           // живёт в замыкании
  return () => ++count;
};

const counter = createCounter();
counter(); // 1
counter(); // 2
counter(); // 3
createCounter()(); // 1 — у нового счётчика своя переменная

Снаружи до count не добраться, изменить его можно только через возвращённую функцию. Обратите внимание: counter не чистая — одинаковый вызов без аргументов возвращает разное. Замыкание — инструмент, а не гарантия чистоты. Подробнее о замыканиях и областях видимости — в учебнике learn.javascript.ru.
