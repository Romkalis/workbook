Command — Команда

Поведенческий паттерн. Одно действие редактора должно запускаться из кнопки, меню или истории. Нужно хранить запрос отдельно от элемента интерфейса и уметь отменять его.

Простыми словами

Официант записывает заказ на листок. Листок можно передать на кухню, отложить, отменить или повторить. Команда превращает действие в объект, и с ним можно делать то же самое: хранить, передавать, ставить в очередь, отменять.

Участники и направление вызовов

Command хранит операцию и параметры; Editor — получатель, который меняет текст. History — инициатор: вызывает execute и сохраняет выполненную команду. Undo использует снимок предыдущего значения.

Пример на TypeScript

interface Command { execute(): void; undo(): void }
class Editor { text = ""; }
class Append implements Command {
  private before: string | undefined;
  constructor(private editor: Editor, private part: string) {}
  execute(): void {
    this.before = this.editor.text;
    this.editor.text += this.part;
  }
  undo(): void {
    if (this.before === undefined) throw new Error("Команда ещё не выполнена");
    this.editor.text = this.before;
  }
}
class History {
  private done: Command[] = [];
  run(command: Command): void { command.execute(); this.done.push(command); }
  undo(): void { this.done.pop()?.undo(); }
}
const editor = new Editor();
const history = new History();
history.run(new Append(editor, "TS"));
history.run(new Append(editor, " Basic"));
console.log(editor.text); // TS Basic
history.undo();
console.log(editor.text); // TS

История сохранила объекты запросов, а не знания о кнопках. В последнем состоянии отменена только последняя добавка. Каждый запуск здесь получает новый экземпляр Append.

Когда применять и что учитывать

Подходит для истории, очередей и отложенного выполнения. Command не делает произвольное действие обратимым: отмену проектируют отдельно. Пример рассчитан на строго последовательные изменения через одну историю; внешние изменения текста и повторное использование экземпляра нарушат предположения. Отмена отправленного письма или платежа не равна возврату строки из снимка.

Источник: Command — Команда. Пример авторский, адаптирован для учебного каталога.

Разделите роли: Editor хранит текст, Append знает действие и снимок предыдущего текста, History хранит порядок выполненных команд. Undo берёт последнюю команду из истории и просит её восстановить предыдущее значение.
