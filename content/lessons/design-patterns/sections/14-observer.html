Observer — Наблюдатель

Поведенческий паттерн. После завершения урока нужно уведомить прогресс и статистику. Источник события не должен зависеть от каждого конкретного получателя.

Простыми словами

Подписка на канал: автор не знает каждого подписчика лично, он просто публикует видео, и все подписчики получают уведомление. Наблюдатель позволяет объекту оповещать список подписчиков, ничего о них не зная.

Участники и направление вызовов

Publisher хранит подписчиков общего контракта, здесь функций. Subscribe регистрирует обработчик и возвращает отписку. Emit уведомляет текущих слушателей. Каждый подписчик самостоятельно решает, что делать с данными.

Пример на TypeScript

class Publisher<T> {
  private listeners = new Set<(event: T) => void>();
  subscribe(listener: (event: T) => void): () => void {
    this.listeners.add(listener);
    return () => { this.listeners.delete(listener); };
  }
  emit(event: T): void {
    for (const listener of [...this.listeners]) listener(event);
  }
}
const completed = new Publisher<string>();
const log: string[] = [];
const stop = completed.subscribe(title => log.push(`progress:${title}`));
completed.subscribe(title => log.push(`stats:${title}`));
completed.emit("TS");
stop();
completed.emit("Patterns");
console.log(log.join(", ")); // progress:TS, stats:TS, stats:Patterns

После отписки progress больше не получает события, а stats продолжает. Копия множества задаёт правило текущей рассылки: изменение подписок внутри слушателя не меняет уже выбранный список.

Когда применять и что учитывать

Нужен для отношения «одно событие — несколько независимых реакций». Отписывайтесь при завершении жизненного цикла слушателя. В этом примере вызовы синхронные: исключение одного слушателя прервёт рассылку, а Promise не будет автоматически ожидаться. Дополнение из общих знаний: брокерный publish/subscribe может отделять стороны через общую шину; классический Observer связывает их механизмом подписки у издателя.

Источник: Observer — Наблюдатель. Пример авторский, адаптирован для учебного каталога.

Подписка означает регистрацию функции на будущие уведомления. Stop — обычная функция отписки, её нужно вызвать. Само получение stop не удаляет слушатель. В emit список слушателей копируется, после чего функции вызываются по очереди.
