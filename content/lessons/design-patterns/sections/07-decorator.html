Decorator — Декоратор

Структурный паттерн. Хотим комбинировать добавки к представлению заголовка без класса на каждое сочетание: сначала скобки, затем отметку избранного или наоборот.

Простыми словами

Чехол на телефон: телефон тот же, но появилась защита. Можно надеть ещё и кольцо-держатель — обёртки складываются. Декоратор оборачивает объект и добавляет ему поведение, не меняя сам объект.

Участники и направление вызовов

Компонент Label и его обёртки имеют один интерфейс text. Каждый декоратор хранит другой Label, делегирует ему вызов и добавляет собственное поведение. Клиент работает с самым внешним слоем.

Пример на TypeScript

interface Label { text(): string }
class TitleLabel implements Label {
  text(): string { return "TS"; }
}
class Brackets implements Label {
  constructor(private inner: Label) {}
  text(): string { return `[${this.inner.text()}]`; }
}
class Favorite implements Label {
  constructor(private inner: Label) {}
  text(): string { return `★ ${this.inner.text()}`; }
}
const first = new Favorite(new Brackets(new TitleLabel()));
const second = new Brackets(new Favorite(new TitleLabel()));
console.log(first.text(), second.text()); // ★ [TS] [★ TS]

Порядок слоёв изменил результат. В обоих случаях клиент вызывает один и тот же метод text, не зная всех внутренних обёрток.

Когда применять и что учитывать

Подходит для независимых комбинируемых возможностей. Следите за порядком, исключениями и вызовом внутреннего объекта ровно нужное число раз. Большая вложенность затрудняет отладку; одной функции форматирования иногда достаточно. GoF Decorator не равен синтаксису @decorator в TypeScript: механизм языка и паттерн проектирования — разные понятия.

Источник: Decorator — Декоратор. Пример авторский, адаптирован для учебного каталога.

Читайте вложенность изнутри: TitleLabel даёт TS, Brackets превращает его в [TS], Favorite добавляет звезду. Если переставить обёртки, скобки охватят и звезду. Одинаковое имя метода позволяет строить такую цепочку.
