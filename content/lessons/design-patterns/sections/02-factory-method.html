Factory Method — Фабричный метод

Порождающий паттерн. Сценарий экспорта один, но конкретный экспортёр зависит от разновидности приложения. Хотим сохранить общий сценарий, позволив наследнику выбрать продукт.

Простыми словами

Сеть кофеен работает по одному порядку: принять заказ, приготовить, выдать. Но что именно готовить, решает конкретная точка: в одной варят эспрессо, в другой — чай. Фабричный метод устроен так же: общий метод родителя описывает порядок работы и в нужный момент вызывает create...(), а какой объект там создать, решает наследник.

Участники и направление вызовов

Продукт задаёт контракт Exporter. Создатель ExportFlow содержит общий сценарий run и фабричный метод createExporter. Конкретные создатели переопределяют только выбор продукта. Клиент вызывает run, который работает через контракт продукта.

Пример на TypeScript

interface Exporter { encode(title: string): string }
class TextExporter implements Exporter {
  encode(title: string): string { return title; }
}
class JsonExporter implements Exporter {
  encode(title: string): string { return JSON.stringify({ title }); }
}
abstract class ExportFlow {
  protected abstract createExporter(): Exporter;
  run(title: string): string {
    const exporter = this.createExporter();
    return exporter.encode(title.trim());
  }
}
class TextFlow extends ExportFlow {
  protected createExporter(): Exporter { return new TextExporter(); }
}
class JsonFlow extends ExportFlow {
  protected createExporter(): Exporter { return new JsonExporter(); }
}
const textFlow = new TextFlow();
const jsonFlow = new JsonFlow();
console.log(textFlow.run(" TS "), jsonFlow.run(" TS "));

Получим TS и {"title":"TS"}. Общая подготовка строки осталась в run; способ создания экспортёра изменился через наследника.

Когда применять и что учитывать

Подходит, когда уже есть общий процесс и точка расширения через наследование. Цена — дополнительные классы создателей. Функция createExporter(kind) со switch тоже полезна, но сама по себе является простой фабрикой, а не классическим Factory Method. Если нужен только выбор по строке, простая фабрика часто достаточна.

Источник: Factory Method — Фабричный метод. Пример авторский, адаптирован для учебного каталога.

Проследите JsonFlow.run: общий метод убирает пробелы, вызывает createExporter у текущего наследника, получает JsonExporter и вызывает encode. Клиент выбрал вид сценария один раз, а общий метод не проверяет тип экспортёра через if.
