Chain of Responsibility — Цепочка обязанностей

Поведенческий паттерн. Поисковый запрос последовательно проверяется: пустой отклоняем сразу, слишком длинный — на следующем шаге, остальные передаём поиску. Состав и порядок проверок хочется менять отдельно.

Простыми словами

Звонок в поддержку: сначала бот, если не справился — оператор, потом инженер. Каждый либо решает вопрос, либо передаёт дальше. Цепочка обязанностей устроена так же: запрос идёт по очереди обработчиков, пока кто-то его не обработает.

Участники и направление вызовов

Обработчик получает запрос и ссылку на следующий шаг. Он решает, продолжать ли цепочку. В функциональном варианте next передаётся как функция, а завершающий обработчик формирует результат.

Пример на TypeScript

type Handler = (query: string) => string;
type Middleware = (query: string, next: Handler) => string;
const nonEmpty: Middleware = (query, next) =>
  query.trim() ? next(query.trim()) : "Пустой запрос";
const shortEnough: Middleware = (query, next) =>
  query.length <= 20 ? next(query) : "Слишком длинный запрос";
const finish: Handler = query => `Поиск: ${query}`;
const search: Handler = query =>
  nonEmpty(query, clean => shortEnough(clean, finish));
console.log(search(" TS ")); // Поиск: TS
console.log(search("  ")); // Пустой запрос

Пустой запрос не попал в следующие шаги. Здесь используется вариант «каждый шаг проверяет и пропускает дальше»; возможен вариант, где запрос забирает первый подходящий обработчик.

Когда применять и что учитывать

Нужна при настраиваемой последовательности обработчиков. Договоритесь о поведении при отсутствии подходящего шага, порядке и правилах вызова next. Next дважды может продублировать действие, а отсутствие вызова может потерять запрос. Один неизменный if не требует целой цепочки.

Источник: Chain of Responsibility — Цепочка обязанностей. Пример авторский, адаптирован для учебного каталога.

Middleware — промежуточный обработчик. В примере next — функция следующего шага. NonEmpty либо возвращает ошибку сразу, либо передаёт очищенную строку дальше. Поэтому порядок обработчиков влияет и на данные, и на то, какие шаги вообще выполнятся.
