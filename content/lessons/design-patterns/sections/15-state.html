State — Состояние

Поведенческий паттерн. Операция publish ведёт себя по-разному в черновике, на проверке и после публикации. Не хотим дублировать switch по состоянию в каждом методе.

Простыми словами

Кнопка «Play» в плеере делает разное: если музыка стоит — включает, если играет — ставит на паузу. Вместо большого if по состоянию каждое состояние становится отдельным объектом со своим поведением, а плеер просто переключается между ними.

Участники и направление вызовов

Контекст Article хранит текущее состояние и делегирует ему publish. Конкретные состояния реализуют общий контракт и определяют допустимые переходы. Состояние может заменить себя через контекст.

Пример на TypeScript

interface ArticleState {
  readonly name: string;
  publish(article: Article): void;
}
class Article {
  constructor(private state: ArticleState = new Draft()) {}
  get status(): string { return this.state.name; }
  transition(state: ArticleState): void { this.state = state; }
  publish(): void { this.state.publish(this); }
}
class Draft implements ArticleState {
  readonly name = "draft";
  publish(article: Article): void { article.transition(new Review()); }
}
class Review implements ArticleState {
  readonly name = "review";
  publish(article: Article): void { article.transition(new Published()); }
}
class Published implements ArticleState {
  readonly name = "published";
  publish(_article: Article): void { /* повторная публикация ничего не меняет */ }
}
const article = new Article();
const statuses = [article.status];
article.publish(); statuses.push(article.status);
article.publish(); statuses.push(article.status);
article.publish(); statuses.push(article.status);
console.log(statuses.join(" → ")); // draft → review → published → published

Один и тот же вызов переместил черновик на проверку, затем опубликовал, затем ничего не изменил. Это упрощённый учебный процесс без ролей пользователей и сетевых операций.

Когда применять и что учитывать

Удобен при нескольких состояниях с разным поведением и переходами. Явно опишите разрешённые переходы и ошибки; наличие строки status само по себе не означает State. Для пары простых состояний таблица переходов или switch может читаться лучше. В реальном процессе публикации отдельно проверяют права и согласуют состояние с сохранением данных.

Источник: State — Состояние. Пример авторский, адаптирован для учебного каталога.

Контекст — здесь Article, объект с меняющимся поведением. Draft, Review и Published — отдельные объекты состояния. При publish контекст передаёт действие текущему состоянию; то выбирает следующий переход либо оставляет состояние прежним.
