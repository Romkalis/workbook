Iterator — Итератор

Поведенческий паттерн. Клиент хочет поочерёдно читать элементы каталога, не зная, как они хранятся. Несколько обходов должны иметь независимые позиции.

Простыми словами

Кнопка «следующий трек» в плеере: вы листаете песни и не знаете, лежат они в массиве, в базе или приходят из сети. Итератор даёт один способ перебрать элементы по одному, скрывая, как они хранятся.

Участники и направление вызовов

Коллекция предоставляет новый итератор для каждого обхода. Итератор хранит позицию. В JavaScript iterable реализует Symbol.iterator, а iterator — next с результатом value/done; генератор помогает связать эти роли.

Пример на TypeScript

class ReadingList implements Iterable<string> {
  constructor(private titles: readonly string[]) {}
  *[Symbol.iterator](): IterableIterator<string> {
    for (const title of this.titles) yield title;
  }
}
const list = new ReadingList(["TS", "Patterns"]);
const first = list[Symbol.iterator]();
const second = list[Symbol.iterator]();
console.log(first.next().value, first.next().value); // TS Patterns
console.log(second.next().value); // TS
const exhausted = first.next();
console.log(exhausted.done, [...list].join(", ")); // true TS, Patterns

Первый обход закончился, второй остался на первом элементе. Для for...of и spread нужен iterable; наличие одного метода next ещё не гарантирует совместимость с ними.

Когда применять и что учитывать

Полезен, когда обход нужно отделить от представления или вычислять значения по мере запроса. Определите поведение при изменении коллекции во время обхода. Генератор — объект с состоянием: уже исчерпанный экземпляр сам не начнётся заново. Дополнение о протоколах JS сверено с MDN; сам паттерн разобран в материале модуля.

Источник: Iterator — Итератор. Пример авторский, адаптирован для учебного каталога.

Четыре слова, которые легко перепутать:

  • Iterable («перебираемое») — то, что можно перебрать в for...of: массив, строка, Map. Технически это объект с методом [Symbol.iterator]().
  • Iterator — «закладка» конкретного перебора. Помнит, где остановились, и по вызову next() выдаёт следующий элемент.
  • next() возвращает { value, done }: value — сам элемент, done: true — элементы кончились.
  • Генератор — функция со звёздочкой function*. Доходит до yield, отдаёт значение и замирает до следующего next(). Самый простой способ написать свой итератор.
const it = [10, 20][Symbol.iterator]();
it.next(); // { value: 10, done: false }
it.next(); // { value: 20, done: false }
it.next(); // { value: undefined, done: true }
