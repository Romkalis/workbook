Abstract Factory — Абстрактная фабрика

Порождающий паттерн. Нужно создавать согласованное семейство элементов оформления: заголовок и метку одной темы. Не хотим случайно смешивать части разных семейств.

Простыми словами

Мебельный гарнитур: стол, стул и шкаф одного стиля. Выбрали «фабрику» стиля «лофт» — и все предметы будут из лофта, случайно не попадётся стул в стиле барокко. Абстрактная фабрика создаёт целый набор согласованных объектов, а вы меняете набор целиком, подменив одну фабрику.

Участники и направление вызовов

Контракт ThemeFactory объявляет создание каждого вида продукта. LightTheme и DarkTheme — конкретные фабрики семейств. Preview зависит от фабрики и контрактов продуктов, не от их конкретных классов.

Пример на TypeScript

interface Title { render(): string }
interface Badge { render(): string }
interface ThemeFactory {
  createTitle(): Title;
  createBadge(): Badge;
}
class LightTheme implements ThemeFactory {
  createTitle(): Title { return { render: () => "light:title" }; }
  createBadge(): Badge { return { render: () => "light:badge" }; }
}
class DarkTheme implements ThemeFactory {
  createTitle(): Title { return { render: () => "dark:title" }; }
  createBadge(): Badge { return { render: () => "dark:badge" }; }
}
function preview(factory: ThemeFactory): string {
  return [factory.createTitle().render(), factory.createBadge().render()].join(" + ");
}
console.log(preview(new LightTheme()));
console.log(preview(new DarkTheme()));

Подмена фабрики меняет сразу оба продукта: получим light:title + light:badge либо dark:title + dark:badge. В примере продукты — объекты с методами; отдельный класс для каждого не обязателен.

Когда применять и что учитывать

Удобна, если важна совместимость нескольких продуктов. Новое семейство добавляется отдельной фабрикой; новый вид продукта потребует изменить контракт и все фабрики. Обещание «любые изменения без правок» неверно. Для одной изменяемой сущности Abstract Factory может быть избыточной.

Источник: Abstract Factory — Абстрактная фабрика. Пример авторский, адаптирован для учебного каталога.

У одной фабрики несколько методов создания. Передав DarkTheme в preview, мы получаем и заголовок, и метку тёмного семейства. Интерфейс фабрики описывает именно семейство: заменить один продукт и заменить всю фабрику — разные изменения.
