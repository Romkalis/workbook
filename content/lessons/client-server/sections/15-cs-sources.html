Источники

Программа модуля: RS School, Stage 1, Client-Server Interaction Overview. Все материалы ниже открыты и разобраны 14 ноября 2026 года.

Видео (по расшифровкам)

  • Вебинар RS School «Network Communication», часть 1 — OSI и TCP/IP, DNS и hosts, TCP-рукопожатие, задержка и RTT, структура HTTP, keep-alive и pipelining, свойства HTTP, сжатие, методы, коды, куки; демо промисов, fetch и async/await на GitHub Search API, Postman.
  • Вебинар RS School «Network Communication», часть 2 — сеансовые куки в Chrome, AJAX, HTTP/2 (демо со 180 картинками, мультиплексирование, Server Push, HPACK), HTTPS и TLS, локальный сертификат OpenSSL и HTTPS-сервер на Node.js, CORS на примере, шесть ограничений REST, SOAP, JWT.
  • Лекция RS School «HTTP» и слайды Дмитрия Цебрука — OSI, поток HTTP, сообщения, коды состояния, история версий, HTTPS, telnet, curl, Postman, Network, XHR, fetch, библиотеки, CORS и способы его обойти.
  • ByteByteGo: SSL, TLS, HTTPS Explained — шаги рукопожатия TLS 1.2, RSA, переход к симметричному шифрованию, отличия TLS 1.3 и Диффи — Хеллман.

Расшифровки получены автоматическими субтитрами YouTube. В русских видео распознавание местами искажено (термины записаны на слух), поэтому смысл восстанавливался по контексту и слайдам. Найденные ошибки лекторов отмечены в тексте блоками «Поправка».

Статьи

  • MDN: An overview of HTTP — свойства протокола, поток, сообщения.
  • freeCodeCamp: HTTP vs HTTPS — сравнение, сертификаты, симметричное и асимметричное шифрование, бесплатные сертификаты.
  • MDN: Cross-Origin Resource Sharing — простые запросы, preflight, credentials, заголовки.
  • javascript.info: Fetch: Cross-Origin Requests — безопасные и небезопасные запросы, credentials, Access-Control-Expose-Headers.
  • MDN: How does the Internet work? и MDN: How the Web works.
  • Hackercool: OSI Model for Beginners и Simplilearn: TCP/IP Model.
  • MDN: Evolution of HTTP.
  • Auth0: Encoding, Encryption and Hashing.
  • Jake Archibald: How to win at CORS — история same-origin policy, origin и site, preflight, credentials.
  • Smashing Magazine: HTTP/3 From A To Z и Cloudflare: The Road to QUIC — QUIC, head-of-line blocking, миграция соединения, QPACK.

Не удалось разобрать

  • Cloudflare: What Is HTTPS — страница отдаёт проверку «Enable JavaScript and cookies» вместо статьи. Тема покрыта freeCodeCamp и видео ByteByteGo.
  • Arkose Labs: What is SSL Encryption? — адрес теперь ведёт на рекламную страницу компании, статьи там нет.

Из общих знаний (не из материалов модуля): идемпотентность и безопасность методов, коды 202/409/429/502–504 в деталях, атрибут SameSite, RFC 6648 о префиксе X-, судьба Server Push и <meta set-cookie>, AbortController, Let's Encrypt и mkcert, прямая секретность, соглашения REST-адресов, GraphQL и gRPC. Все примеры кода запущены в Node.js 22.23: fetch с проверкой статуса против локального сервера, поиск по GitHub API, CORS-сервер (проверен curl), HTTPS-сервер с самоподписанным сертификатом, замер сжатия gzip и Brotli.
