Словарь

Клиент / сервер
Программа, которая отправляет запрос / программа, которая его обрабатывает и отвечает.
Протокол
Набор правил обмена данными.
IP-адрес
Адрес устройства в сети, например 140.82.121.6 (IPv4) или 2606:4700::6810:84e5 (IPv6).
Порт
Номер программы-получателя на устройстве: 80 — HTTP, 443 — HTTPS.
TCP / UDP
Транспортные протоколы: надёжный с установкой соединения / быстрый без гарантий доставки.
QUIC
Транспорт поверх UDP с встроенными надёжностью, потоками и TLS 1.3; основа HTTP/3.
Latency / RTT
Задержка в одну сторону / время туда и обратно.
DNS
Система, превращающая доменные имена в IP-адреса.
URL
Адрес ресурса: схема, хост, порт, путь, query string, фрагмент.
Origin
Схема + хост + порт.
HTTP
Прикладной протокол «запрос — ответ» без состояния.
Метод
Действие над ресурсом: GET, POST, PUT, PATCH, DELETE, OPTIONS, HEAD.
Идемпотентность
Свойство метода давать одинаковый итог при повторе.
Код состояния
Трёхзначный результат запроса: 2xx успех, 3xx перенаправление, 4xx ошибка клиента, 5xx ошибка сервера.
Заголовок
Метаданные сообщения в виде Имя: значение.
Кука
Пара «имя=значение», которую браузер хранит для сайта и автоматически отправляет с запросами.
ETag
Отпечаток версии ресурса для условных запросов и ответа 304.
AJAX
Фоновые запросы из JavaScript без перезагрузки страницы.
Промис
Объект результата асинхронной операции: pending, fulfilled или rejected.
Keep-alive
Переиспользование одного TCP-соединения для нескольких запросов.
Мультиплексирование
Параллельная передача многих потоков в одном соединении (HTTP/2, HTTP/3).
Head-of-line blocking
Задержка всей очереди из-за одного застрявшего элемента.
TLS / SSL
Протокол шифрования канала / его устаревший предшественник.
Сертификат
Подписанный центром сертификации документ, связывающий домен с открытым ключом.
CA
Центр сертификации, которому доверяют браузеры.
Same-origin policy
Правило браузера: скрипт читает ответы только своего origin.
CORS
Механизм, через который сервер разрешает другим origin читать ответы.
Preflight
Предварительный OPTIONS-запрос перед «непростым» кросс-доменным запросом.
API
Интерфейс, через который программы обмениваются данными.
REST
Архитектурный стиль API с шестью ограничениями.
