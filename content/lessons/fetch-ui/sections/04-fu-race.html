Устаревшие ответы

Пользователь печатает «к», «ко», «код». Если запрос уходит на каждую букву, ответы могут прийти в другом порядке, и на экране окажутся результаты для «к» при тексте «код» в поле. Лечение из двух частей:

  • Задержка (debounce): запрос уходит, когда пользователь перестал печатать (как сделать).
  • Отмена: перед новым запросом старый отменяется через AbortController, а отменённый запрос не показывается как ошибка.
export function latestOnly<A, R>(fn: (args: A, signal: AbortSignal) => Promise<R>) {
  let controller: AbortController | undefined;
  return async (args: A): Promise<{ ok: true; value: R } | { ok: false; aborted: boolean; error?: unknown }> => {
    controller?.abort();
    controller = new AbortController();
    const { signal } = controller;
    try {
      const value = await fn(args, signal);
      return signal.aborted ? { ok: false, aborted: true } : { ok: true, value };
    } catch (error) {
      return { ok: false, aborted: signal.aborted, error };
    }
  };
}

Проверка signal.aborted после await закрывает тонкую дыру: ответ мог успеть прийти ровно в момент отмены. Подробный разбор гонки с тестом, который её воспроизводит, — в Country Search.

Задача 10. Только последний ответ ★★☆ практика

Используя latestOnly из раздела, сделайте функцию createLoader(fetchProducts, onState) с методом load(query): каждый вызов отменяет предыдущий запрос; отменённые результаты не попадают в onState; ошибки (кроме отмены) дают состояние error.

export function latestOnly<A, R>(fn: (args: A, signal: AbortSignal) => Promise<R>) {

Зачем: обёртка решает гонку один раз для любого запроса, а загрузчик только переводит результат в состояния. Две маленькие функции с ясными ролями проще проверить, чем одна большая с флагами.

Решение и разбор
// loader.ts
import { latestOnly } from './latest.js';

type State<T> = { status: 'loading' } | { status: 'success'; data: T } | { status: 'error'; message: string };

export function createLoader<T>(fetchProducts: (q: string, signal: AbortSignal) => Promise<T>, onState: (s: State<T>) => void) {
  const run = latestOnly(fetchProducts);
  return {
    async load(query: string): Promise<void> {
      onState({ status: 'loading' });
      const result = await run(query);
      if (result.ok) onState({ status: 'success', data: result.value });
      else if (!result.aborted) {
        onState({ status: 'error', message: result.error instanceof Error ? result.error.message : 'Ошибка' });
      }
    },
  };
}

Отменённый вызов просто ничего не сообщает: на экране уже «загрузка» для нового запроса. Тест проверяет главный сценарий гонки: первый запрос отвечает последним, но его результат не показывается.
