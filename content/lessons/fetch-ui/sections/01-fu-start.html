Где мы и что строим

В уроке Express на TypeScript вы собрали API магазина: список товаров с фильтрами и расчёт корзины. В прошлых уроках этого раздела — карточки из данных, события, стор. Теперь соединим: страница загружает товары с сервера, показывает загрузку и ошибки, ищет без гонки ответов и считает корзину на сервере.

Запуск двух частей рядом: API на http://localhost:3000 (папка starters/shop-api/06-done), фронтенд на Vite — http://localhost:5173. Это разные origin, поэтому сервер разрешает запросы фронтенда через CORS (как это устроено). Если в консоли браузера ошибка про Access-Control-Allow-Origin, проверьте CLIENT_ORIGIN на сервере.

Что разберём

  • Слой API-клиента: адрес, fetch, статус, проверка формы ответа.
  • Четыре состояния данных: ещё не грузили, грузим, есть данные, ошибка.
  • Гонка запросов: отмена устаревших через AbortController.
  • Отправка данных: POST с JSON, блокировка кнопки, кто прав — клиент или сервер.
  • Переменные окружения Vite и прокси.

Основы fetch (статусы, response.ok, AbortController, таймаут) подробно разобраны в Country Search и уроке Клиент-серверное взаимодействие. Здесь мы собираем их в архитектуру приложения.
