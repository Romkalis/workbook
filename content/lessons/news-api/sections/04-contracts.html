Этап 3. Описываем данные до переноса методов

Разделите три сущности: издатель из списка источников, статья и конверт ответа API. Объект source внутри статьи может содержать лишь id и name; не назначайте ему интерфейс полного издателя с обязательными country и category.

Контракты внешних данных

Сверьте Sources и Everything с ответами в Network. Выпишите используемые поля, а для отсутствующих значений предусмотрите null. Внутреннюю модель можно сделать уже ответа сервера, но не выдавайте её за полное описание API.

Разместите общие контракты в отдельном модуле типов. Опишите успешный ответ источников, успешный ответ новостей и ошибку с code и message. Объедините их по литеральному status: после проверки status компилятор должен понимать, доступны ли articles, sources или сообщение ошибки.

Небольшая модель и полезные преобразования

Пример ниже — авторская внутренняя модель карточки, а не полный DTO News API. Он объединяет enum, interface, union, function type и три обязательных utility types. В следующих двух примерах используются эти объявления; проверяйте все три блока в одном TS-модуле.

enum LoadPhase {
  Idle = "idle",
  Loading = "loading",
  Ready = "ready",
  Failed = "failed",
}

interface Article {
  title: string;
  url: string;
  description: string | null;
}

type Card = Readonly<Pick<Article, "title" | "url">>;
interface Filters { source: string; query: string }
type FilterPatch = Partial<Filters>;
type OnArticles = (articles: readonly Article[]) => void;
type LoadState =
  | { phase: LoadPhase.Idle }
  | { phase: LoadPhase.Loading }
  | { phase: LoadPhase.Ready; articles: readonly Article[] }
  | { phase: LoadPhase.Failed; message: string };

const filters: Filters = { source: "bbc-news", query: "" };
const patch: FilterPatch = { query: "typescript" };
const nextFilters: Filters = { ...filters, ...patch };
const card: Card = { title: "Новость", url: "https://example.org/" };
const onArticles: OnArticles = (articles) => {
  console.log(articles.length);
};
const state: LoadState = { phase: LoadPhase.Ready, articles: [] };
onArticles(state.articles);
console.log(nextFilters.query, card.title);

Pick оставляет поля для карточки, Readonly запрещает их менять через этот тип, Partial описывает частичное обновление фильтров. Это статические ограничения: Readonly не замораживает объект в runtime. Объявления должны использоваться в приложении, а не лежать отдельным файлом ради баллов. Повторить: utility types и enum.

Готово, когда: формы данных согласованы между загрузчиком, контроллером и представлением, а null не спрятан утверждением типа.
