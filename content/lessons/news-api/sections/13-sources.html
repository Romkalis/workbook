Источники и границы урока

Основа — присланный пользователем текст задания News API: обязательные технологии, ограничения, критерии и порядок сдачи сохранены в уроке. План работы, минимальные примеры и сценарии проверки — авторские дополнения из общих знаний. Три TS-примера проверены совместно строгим компилятором и запущены; запрос загрузчика проверен с подменой fetch, без обращения к реальному API.

  • Исходное приложение — страница репозитория открыта, содержимое исходных файлов и конкретная архитектура не разобраны; raw package.json получить не удалось.
  • News API Documentation, Everything, Sources — разобраны назначение, конверты и поля ответов. Минимальная модель урока не заменяет полный контракт API.
  • Webpack: TypeScript — разобрана связка компилятора, загрузчика и сборки.
  • typescript-eslint: Quickstart — разобран современный flat config. no-explicit-any и TSConfig Reference — дополнительные справочные ссылки из задания, в этой работе отдельно не разобраны.
  • TypeScript: Narrowing и Utility Types — сверены проверки значений и преобразования типов.
  • Git convention — разобраны формат, типы сообщений и пояснение об init. Требования к PR — старая ссылка возвращала 404. Действующая страница Pull Request Requirements разобрана: обязательные поля описания и состав изменений PR.
  • Учебный proxy — доступность не подтверждена; маршруты mocks приведены по присланному условию. Живые запросы с API-ключом не проверялись.
  • Cross-check, Responsive и Adaptive Design — дополнительные ссылки из задания, отдельно не разобраны.
  • ESLint 10: переход на новую версию и Configuration Migration Guide — разобраны отказ от .eslintrc, flat config и перенос настроек.
  • Legacy ESLint Setup и Legacy Configuration Files — разобраны старый формат, parser, plugin и режим совместимости ESLint 9. Полные примеры обоих форматов находятся в TypeScript Advanced.

Настройки инструментов подробно объяснены в TypeScript Advanced; здесь они даны как шаги миграции существующего приложения. Проверяйте совместимость версий перед установкой пакетов.
