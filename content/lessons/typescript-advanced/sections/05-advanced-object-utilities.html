Utility types для объектов

Utility types — встроенные вспомогательные типы. Они позволяют получить новый тип из существующего, например сделать поля профиля необязательными для формы редактирования. Они меняют статический контракт, не копируют, не фильтруют и не замораживают реальные объекты. Формулы этих типов можно прочитать в lib.es5.d.ts установленного компилятора.

Partial, Required и Readonly

interface Profile { id: string; name: string; bio?: string }
const patch: Partial<Profile> = { name: "Анна" };
const full: Required<Profile> = { id: "u1", name: "Анна", bio: "Учусь" };
const view: Readonly<Profile> = full;
console.log(patch.name, view.bio);
if (false) {
  // @ts-expect-error: readonly запрещает запись через view
  view.name = "Лев";
}

В примере patch — частичное обновление профиля: менять имя можно, передавать все остальные поля не требуется. Full — полностью заполненный профиль. View ссылается на тот же объект, но его тип разрешает только чтение. Partial делает свойства необязательными, Required убирает знак ?, Readonly запрещает присваивание через этот тип. Они работают на первом уровне: Readonly<{ meta: { title: string } }> не делает meta.title неизменяемым. Для обновления профиля безопаснее Partial<Pick<Profile, "name" | "bio">>, чтобы не разрешать менять id.

Pick, Omit и Record

interface Article { id: string; title: string; secret: string }
type Card = Pick<Article, "id" | "title">;
type PublicArticle = Omit<Article, "secret">;
const original: Article = { id: "a1", title: "TS", secret: "hidden" };
const typed: PublicArticle = original; // ссылка всё ещё содержит secret
const card: Card = { id: original.id, title: original.title };
const labels: Record<"loading" | "ready", string> = {
  loading: "Загрузка", ready: "Готово"
};
console.log("secret" in typed, "secret" in card, labels.ready); // true false Готово

Pick выбирает ключи, Omit исключает, Record описывает значения по набору ключей. Omit не удалил secret во время выполнения; для публичного ответа сформируйте новый объект из нужных полей. Record с конечным union требует все перечисленные ключи; произвольный строковый словарь не гарантирует существование каждого ключа.

ТипКогда полезен
Partial<T>Частичное обновление разрешённых полей
Required<T>Полная конфигурация после заполнения пропусков
Readonly<T>Контракт чтения без присваиваний
Pick<T, K>Узкое представление с выбранными полями
Omit<T, K>Контракт без перечисленных полей
Record<K, V>Словарь значений V по ключам K
