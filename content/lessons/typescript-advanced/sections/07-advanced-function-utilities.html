Типы из функций, конструкторов и Promise

Parameters, ReturnType и Awaited

Допустим, функция load уже описана, а рядом нужен тип её аргументов или результата. Чтобы не переписывать эти типы вручную, возьмём их из самой функции. typeof load здесь означает «тип функции load», а не строку, возвращаемую оператором typeof в JavaScript.

function load(id: string, limit = 10): Promise<{ id: string; count: number }> {
  return Promise.resolve({ id, count: limit });
}
type Args = Parameters<typeof load>;
type Pending = ReturnType<typeof load>;
type Data = Awaited<Pending>;
const args: Args = ["a1", 2];
const data: Data = { id: "a1", count: 2 };
console.log(args[0], data.count);
void load(...args).then(result => console.log(result.count));

Разберём результат по строкам: Args — кортеж [id: string, limit?: number]; Pending — Promise<{ id: string; count: number }>; Data — объект { id: string; count: number } после успешного ожидания Promise. Проще говоря, Parameters отвечает «что функция принимает», ReturnType — «что возвращает», Awaited — «что получится после await». Awaited умеет раскрывать также вложенные Promise и объединения типов. Это помогает не дублировать сигнатуры. У перегруженной функции извлечение обычно ориентируется на последнюю сигнатуру, а не выбирает перегрузку по будущим аргументам.

ConstructorParameters и InstanceType

class Article {
  constructor(readonly title: string, readonly minutes: number) {}
}
type Args = ConstructorParameters<typeof Article>;
type Item = InstanceType<typeof Article>;
const args: Args = ["TS", 8];
const item: Item = new Article(...args);
console.log(item.title, item.minutes);

Для этих типов передают тип конструктора typeof Article, а не тип экземпляра Article. У обычного класса экземпляр можно назвать напрямую; утилиты полезнее в обобщённых фабриках и обёртках.

Дополнительно: утилиты для this

В heading первый параметр this описывает объект, с которым вызывают функцию; отдельным аргументом JavaScript он не передаётся. Вызов bind создаёт функцию, у которой этот объект уже закреплён. Поэтому bound при вызове принимает только prefix.

function heading(this: { title: string }, prefix: string): string {
  return prefix + this.title;
}
type Context = ThisParameterType<typeof heading>;
const context: Context = { title: "TS" };
const bound: OmitThisParameter<typeof heading> = heading.bind(context);
console.log(bound("Урок: "));

ThisParameterType извлекает явно объявленный this, OmitThisParameter убирает его из сигнатуры. Есть также ThisType: он подсказывает тип this внутри методов объектного литерала. Это более редкий приём, к которому можно вернуться позже; сам ThisType не создаёт объект и не закрепляет this при вызове. Uppercase, Lowercase, Capitalize и Uncapitalize преобразуют строковые литеральные типы — к ним перейдём в разделе шаблонных строк.
