Самостоятельные задачи с критериями

Задача 1. Получите типы без дублирования

Объявите Article с id, title, tags и необязательным description. Получите тип карточки только с id и title, тип частичного обновления title и description, объединение допустимых ключей и тип одного элемента tags. Напишите mapped type, превращающий поля в необязательные функции чтения. Проверьте, что id нельзя передать в патч.

Что должно получиться?

Карточка использует Pick, патч — Partial вместе с Pick, keyof даёт ключи, индексный доступ Article["tags"][number] — элемент массива. В mapped type нужны [K in keyof T]?: () => T[K]. Необязательность свойства description и необязательность самой функции — разные уровни.

Задача 2. Валидатор ответа

Получите unknown. Примите только объект с полем articles — массивом элементов, у каждого из которых строковые title и url, а description — строка или null. Некорректные значения должны отклоняться целиком, а не исчезать после filter. Проверьте null, объект без массива, некорректный элемент и пустой массив.

Критерии

Проверка объекта исключает null и массив на верхнем уровне; Array.isArray подтверждает articles; every проверяет каждый элемент. Корректный пустой массив допустим. Обещанный тип включает null для description. В решении нет any, двойных as и необоснованного !.

Задача 3. Проверка сборочного конвейера

Соберите минимальный Webpack-проект из урока. Замените аргумент double(21) на строку и убедитесь, что typecheck и build сообщают ошибку. Верните число. Затем добавьте в учебный файл явно написанный any и проверьте, что ESLint отклоняет его. Исправьте код и повторите все три проверки.

Что считать успехом?

Ошибки действительно обнаружены нужным инструментом; после исправления сборка проходит и bundle выводит 42. Проверка с правильным кодом показывает, что проект собирается. Намеренная ошибка нужна, чтобы дополнительно убедиться: инструменты действительно обнаруживают нарушение, а не просто завершаются без проверки исходников.

План примерно на 8 часов

Рабочий план из общих знаний: 1 час на guards, 1 час на generics, 1,5 часа на utility types, 1,5 часа на преобразования типов, 1,5 часа на конфигурацию и сборку, 1,5 часа на задачи и повторение. Курсы и самостоятельная миграция могут потребовать дополнительного времени.
