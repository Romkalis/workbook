Mapped types: преобразование каждого свойства

Mapped type, или отображаемый тип, описывает преобразование каждого свойства. Запись [K in keyof T] читается как «для каждого ключа K исходного типа T». Это цикл на уровне типов, а не выполнение JS. Partial и Readonly построены на такой идее.

Изменение readonly и необязательных свойств

У Settings два ключа — title и enabled. Тип Flags заменит типы обоих свойств на boolean. Тип Editable сохранит типы string и boolean, но разрешит запись в title и потребует обязательное enabled.

type Flags<T> = { [K in keyof T]: boolean };
type Editable<T> = { -readonly [K in keyof T]-?: T[K] };
interface Settings { readonly title: string; enabled?: boolean }
const flags: Flags<Settings> = { title: true, enabled: false };
const editable: Editable<Settings> = { title: "TS", enabled: true };
editable.title = "Patterns";
console.log(flags.title, editable.title);

Минус перед readonly или ? снимает модификатор, плюс добавляет; без знака добавление является обычным поведением. Простое отображение по keyof сохраняет существующие модификаторы, если явно не поменять их.

Переименовывать ключи тоже можно. К этому примеру с getTitle и getId перейдём после условных типов и шаблонных строк: сначала разберём все части его записи.
