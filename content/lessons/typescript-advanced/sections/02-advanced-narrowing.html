Встроенные type guards и анализ потока

Type guard, или проверка типа, помогает уточнить, какое значение перед нами. Например, переменная имеет тип string | number. После проверки typeof value === "string" внутри этой ветки можно вызывать строковые методы. Такое уточнение называется сужением типа (narrowing). Компилятор учитывает условия, выход из функции через return и новые присваивания.

typeof и равенство

function text(value: string | number | null): string {
  if (value === null) return "нет значения";
  return typeof value === "number" ? value.toFixed(1) : value.toUpperCase();
}
function common(a: string | number, b: string | boolean): string {
  if (a === b) return a.toUpperCase(); // общий возможный тип — string
  return "разные";
}
console.log(text(2), text(null), common("ts", "ts"));

В text(2) выбирается числовая ветка и получается "2.0"; для null функция сразу возвращает "нет значения". Теперь common. a бывает строкой или числом, b — строкой или boolean. Если a === b, значения одинаковые, а значит, и типы одинаковые. Общий тип у них только один — string. TypeScript делает тот же вывод, поэтому внутри if у a можно вызвать toUpperCase(). typeof полезен для примитивов, но typeof null равно "object"; для объекта сначала исключайте null. Проверка value != null намеренно исключает и null, и undefined; строгое сравнение исключает только указанное значение.

Проверка if (value): пустое значение тоже может быть данными

function length(value: string | undefined): number | undefined {
  if (value === undefined) return undefined;
  return value.length;
}
console.log(length(""), length(undefined)); // 0 undefined

JavaScript преобразует условие if в boolean. Такая проверка называется truthiness — проверкой того, считается ли значение истинным. Условие if (value) отсекает не только отсутствие, но и пустую строку, ноль, false и другие falsy-значения. Выбирайте проверку по смыслу данных. Для пустого текста длина 0 может быть корректным результатом.

instanceof, in и размеченный union

class Video { constructor(readonly minutes: number) {} }
function duration(value: Video | { words: number }): number {
  if (value instanceof Video) return value.minutes;
  return Math.ceil(value.words / 200);
}
type Result = { kind: "ok"; title: string } | { kind: "error"; message: string };
function render(result: Result): string {
  if ("message" in result) return result.message;
  return result.title;
}
console.log(duration(new Video(5)), render({ kind: "ok", title: "TS" }));

instanceof использует существующий конструктор, а не interface: интерфейсы стираются. In проверяет наличие свойства, но ещё не его содержимое; если свойство необязательное, его наличие не всегда позволяет однозначно выбрать один вариант объединения. Для сложных состояний удобно общее поле kind с литеральными значениями.

В примере duration(new Video(5)) возвращает 5. В render проверка "message" in result выбирает вариант ошибки; вместо неё здесь можно проверить result.kind === "error". Общее поле kind называется дискриминантом: его конкретное значение показывает, с каким вариантом мы работаем.
