Проверка готовности и словарь

  • Объясняю narrowing через typeof, instanceof, equality, truthiness, in и дискриминант.
  • Пишу честный type predicate и assertion function для unknown.
  • Сохраняю связи generic-параметров, применяю ограничения параметров типа и keyof.
  • Выбираю utility type по задаче и понимаю, что runtime-объект не меняется.
  • Читаю mapped types, модификаторы и remapping ключей.
  • Объясняю conditional types, infer и распределение union.
  • Строю допустимые имена через literal и template literal types.
  • Различаю target, lib, module и moduleResolution.
  • Проверяю фактическую конфигурацию и список файлов.
  • Собираю TS через Webpack и не путаю трансформацию с typecheck.
  • Понимаю план News API и ограничения any; запускаю ESLint отдельно.
Runtime
Время выполнения JavaScript: типы TypeScript к этому моменту в основном уже удалены.
Typecheck
Проверка соответствия кода описанным типам без обязательного запуска программы.
Контракт
Договорённость о допустимых данных, аргументах и результате.
Narrowing
Уточнение типа после проверки: например, переход от string | number к string в выбранной ветке.
Патч
Частичное обновление: объект только с теми полями, которые нужно изменить.
Alias
Псевдоним пути, который сокращает запись импорта.
DTO
Описание данных на границе обмена, которое ещё требует проверки полученного значения.
Type predicate
Контракт проверки вида value is T.
Mapped type
Преобразование свойств через перебор ключей типа.
Conditional type
Выбор типа по отношению совместимости.
Infer
Извлечение части типа в условии.
Distribution
Распределение условного типа по вариантам union.
Emit
Выпуск выходных файлов компилятором.
Bundle
Результат сборки модулей и их зависимостей бандлером.
Declaration
Описание контракта без реализации JavaScript.
