Классы и объектыИсточники: oop-overview, freeCodeCamp, MDN, Eloquent JavaScript

Класс это шаблон: он описывает, какие данные будут у объектов и что они смогут делать. Объект (экземпляр) это конкретная «штуковина», созданная по шаблону, со своими значениями. Аналогия простая: чертёж дома и дома на улице. Чертёж один, домов много, и в каждом свой номер и цвет стен.

class Person {
  constructor(name, age) {
    this.name = name;
    this.age = age;
  }
  sayHi() {
    return `Привет, я ${this.name}`;
  }
}

const anna = new Person('Анна', 30);
const oleg = new Person('Олег', 25);
anna.sayHi();  // 'Привет, я Анна'
oleg.sayHi();  // 'Привет, я Олег'

Из чего состоит класс

  • Конструктор (constructor) вызывается при new и задаёт начальное состояние. Если не написать его, JavaScript добавит конструктор по умолчанию: у базового класса он пустой, а у наследника передаёт аргументы родителю.
  • Поля (свойства) хранят данные экземпляра.
  • Методы описывают поведение. Внутри метода this указывает на объект, у которого метод вызвали.
  • Статические члены (static) принадлежат самому классу, а не экземплярам: Temperature.fromFahrenheit(212), а не obj.fromFahrenheit().
  • Геттеры и сеттеры выглядят как поля, но выполняют код. Это удобная точка для проверок.
class Temperature {
  #celsius = 0;
  constructor(c) { this.celsius = c; }
  get celsius() { return this.#celsius; }
  set celsius(v) {
    if (typeof v !== 'number' || Number.isNaN(v)) {
      throw new TypeError('нужно число');
    }
    this.#celsius = v;
  }
  get fahrenheit() { return this.#celsius * 1.8 + 32; }
  static fromFahrenheit(f) {
    return new Temperature((f - 32) / 1.8);
  }
}
new Temperature(100).fahrenheit;       // 212
Temperature.fromFahrenheit(212).celsius; // 100

Статические члены подробнее

Поля экземпляра хранятся в конкретном объекте: у двух Person могут быть разные name. Обычный метод, объявленный в теле класса, хранится в Person.prototype и доступен обоим объектам через цепочку прототипов. Член с static находится на самом классе: его вызывают как Person.method(), а не через экземпляр.

class Counter {
  static created = 0;          // одно значение на весь класс
  static LIMIT = 3;            // константа, общая для всех

  constructor() {
    Counter.created++;         // обращаемся через имя класса
  }
  static isFull() {            // метод класса, не объекта
    return Counter.created >= Counter.LIMIT;
  }
}

new Counter(); new Counter();
Counter.created;      // 2
Counter.isFull();     // false
new Counter().created; // undefined — у экземпляра этого поля нет

Внутри статического метода this указывает на сам класс, а не на объект, поэтому полей экземпляра (this.name) там нет. Зато можно спокойно вызывать другие статические члены.

Статику используют в трёх случаях:

  • Константы класса: границы, значения по умолчанию, которые одинаковы для всех экземпляров.
  • Общая вспомогательная логика: проверки и расчёты, которым не нужны данные конкретного объекта.
  • Фабрики: альтернативные способы создать объект, как Temperature.fromFahrenheit выше.

К статическим членам тоже можно добавить #: static #MIN = 100 и static #validate(ms) доступны только внутри тела этого класса, снаружи их не видно. Обращаться к ним нужно по-прежнему через имя класса: Timer.#MIN. Именно так устроен пример с таймером в разделе про инкапсуляцию.

Класс без new не вызвать

Вызов Person() без new бросит TypeError: Class constructor Person cannot be invoked without 'new'. Это отличает классы от старых функций-конструкторов, которые молча работали бы не так, как задумано.

Когда написано person.sayHi(), внутри обычного метода this равен person. Если передать метод отдельно как функцию, эта связь сама не сохранится. Геттер выполняет код при чтении свойства, сеттер — при присваивании; это позволяет добавить проверку, сохранив привычную запись доступа.
