ПолиморфизмИсточники: oop-overview, BMC (polymorphism), TechTarget, MDN

Слово означает «много форм». Суть: один и тот же вызов ведёт себя по-разному в зависимости от того, какой объект его получил, а вызывающий код об этом не знает и знать не обязан. Вы пишете transport.move() и не проверяете, машина это, самолёт или корабль.

class Transport {
  constructor(model) {
    if (new.target === Transport) {
      throw new TypeError('Transport нельзя создать напрямую');
    }
    this.model = model;
  }
  move() { throw new Error('move() нужно реализовать'); }
}
class Car extends Transport {
  move() { return `${this.model} едет по дороге`; }
}
class Plane extends Transport {
  move() { return `${this.model} летит по небу`; }
}
class Ship extends Transport {
  move() { return `${this.model} плывёт по воде`; }
}

for (const v of [new Car('Kia'), new Plane('Airbus'), new Ship('Титан')]) {
  console.log(v.move());   // одна и та же строка кода
}

Класс Transport здесь играет роль абстрактного класса: он задаёт контракт («у любого транспорта есть move»), но создать его напрямую нельзя. В JavaScript нет ключевого слова abstract, поэтому это имитируют проверкой new.target и методами, которые бросают ошибку. В TypeScript есть и abstract class, и interface, которые проверяются ещё при компиляции.

Виды полиморфизма

ВидИдеяПример
Подтипов (динамический)Метод выбирается по реальному типу объекта во время выполнения.Пример с Transport выше. Главный вид в ООП.
ПараметрическийОдин код работает с любым типом данных.Дженерики в TypeScript: function first<T>(a: T[]): T | undefined.
Ad hoc (перегрузка)Одно имя, разные реализации для разных типов.Оператор + складывает числа и склеивает строки. Перегрузки методов в JS нет.
Приведение типовЗначение неявно превращается в нужный тип.1 + '2' даёт '12'.

Утиная типизация

JavaScript не требует общего родителя. Если у объекта есть нужный метод или свойство, он подойдёт. «Если оно ходит как утка и крякает как утка, то это утка».

const describe = (x) => `длина: ${x.length}`;
describe('abc');          // 'длина: 3'
describe([1, 2]);         // 'длина: 2'
describe({ length: 7 });  // 'длина: 7'

Удобно, но компилятор не подскажет, что вы передали не то. Поэтому в больших проектах поверх JS берут TypeScript.

Признак того, что полиморфизма не хватает

Цепочка if (x instanceof Car) ... else if (x instanceof Plane) ... в каждом месте, где нужно поведение. Лучше положить это поведение в методы классов, а вызывающему коду оставить один вызов.
