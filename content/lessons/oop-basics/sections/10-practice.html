Практика и тест в RS-AppЗадание модуля

Практическая часть модуля это тест «[St1] OOP Test» в RS-App, раздел Auto Test. Вопросов этого теста у нас нет, поэтому гадать не будем. Но, судя по целям модуля, проверяться будут понятия и умение прочитать короткий код, а не зубрёжка определений. Разумный план подготовки:

  1. Пройдите тест в конце этой страницы. Те вопросы, где ошиблись, это ваши слабые места.
  2. Для каждого принципа сформулируйте вслух одной фразой, что он даёт и чем отличается от соседнего (абстракция и инкапсуляция путаются чаще всего).
  3. Сами напишите по памяти: класс с приватным полем и геттером, наследника с super, три класса с общим методом. Проверьте запуском.
  4. Нарисуйте UML-диаграмму класса для своего примера и убедитесь, что понимаете каждый знак.

Две мини-задачи для самопроверки

Банковский счёт: нельзя уйти в минус и внести отрицательную сумму

Баланс закрыт, наружу торчат операции с проверками.

class BankAccount {
  #balance = 0;
  deposit(x) {
    if (x <= 0) throw new RangeError('сумма должна быть положительной');
    this.#balance += x;
  }
  withdraw(x) {
    if (x > this.#balance) throw new RangeError('недостаточно средств');
    this.#balance -= x;
  }
  get balance() { return this.#balance; }
}
const acc = new BankAccount();
acc.deposit(100);
acc.withdraw(30);
acc.balance; // 70

Решение смотрите в разделе «Абстракция»: базовый класс Shape с area(), два наследника и reduce. Попробуйте сначала написать без подсказки, потом добавьте третий класс (Triangle) и убедитесь, что функцию суммирования менять не нужно.
