АбстракцияИсточники: oop-overview, Wikipedia (Abstraction), TechTarget

Абстракция это выбор: что в сущности важно для задачи, а что нет. Вы строите упрощённую модель и пользуетесь ею, не заглядывая вглубь. Когда вы вызываете account.withdraw(30), вам не нужно знать, как хранятся деньги, как проходят транзакции и где физически лежит база.

Два вида абстракции

  • Абстракция управления (процедурная): сложную последовательность действий прячут за одним именем. Функция, метод, цикл for и есть такие абстракции.
  • Абстракция данных: описывается, что можно делать с данными, а не как они хранятся. Стек с операциями push и pop можно реализовать на массиве или на связном списке, пользователь этого не заметит. Такое описание называют абстрактным типом данных (ADT).

Как абстракция выглядит в коде

Интерфейс (или абстрактный класс) фиксирует, что умеет объект. Конкретные классы решают, как.

class Shape {
  area() { throw new Error('не реализовано'); }
}
class Circle extends Shape {
  constructor(r) { super(); this.r = r; }
  area() { return Math.PI * this.r ** 2; }
}
class Rect extends Shape {
  constructor(w, h) { super(); this.w = w; this.h = h; }
  area() { return this.w * this.h; }
}
const total = [new Circle(1), new Rect(2, 3)]
  .reduce((sum, f) => sum + f.area(), 0);
total.toFixed(2); // '9.14'

Функция, считающая суммарную площадь, ничего не знает про круги и прямоугольники. Она работает с абстракцией «фигура, у которой есть площадь».

Абстракция и инкапсуляция: в чём разница

Их часто путают, потому что на практике они работают вместе. Абстракция решает, что показать (дизайн интерфейса, уровень детализации). Инкапсуляция решает, как закрыть внутреннее (приватные поля, ограничение доступа). Абстракция это про модель, инкапсуляция про защиту.

Дырявые абстракции

Любая абстракция скрывает детали, но иногда они всё равно просачиваются: библиотека работы с базой данных (ORM) прячет язык запросов SQL, пока запрос не начинает тормозить, и тогда без знания SQL не обойтись. Поэтому абстракция не отменяет необходимости понимать, что внизу. Она позволяет не думать об этом большую часть времени. Другая крайность, чрезмерная абстракция: десять слоёв классов ради одной операции. Если уровень ничего не упрощает, он лишний.
