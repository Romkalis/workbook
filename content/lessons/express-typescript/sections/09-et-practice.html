Практика, вопросы и словарь

Упражнения

  1. Добавьте GET /api/categories: уникальные категории из PRODUCTS. Типизируйте ответ как Response<string[]> и напишите тест.
  2. Добавьте параметр sort=price-asc|price-desc. Неизвестное значение должно давать 400. Подсказка: union-тип 'price-asc' | 'price-desc' и функция-проверка.
  3. Сделайте так, чтобы minPrice > maxPrice возвращал 400. Сначала напишите падающий тест (TDD).
  4. Напишите тест, который доказывает, что цена из тела запроса игнорируется: отправьте price: 1 и проверьте сумму.
  5. Уберите err.status ?? 500 из обработчика ошибок и посмотрите, какой тест упадёт. Верните строку.

Вопросы

Почему req.body as QuoteBody не защищает сервер?

as существует только для компилятора и исчезает при сборке. Во время работы в req.body лежит то, что прислал клиент, и никто это не проверил. Защищает только проверка во время выполнения: type guard или схема.

tsx запустил сервер, хотя в коде ошибка типов. Это баг?

Нет. tsx отбрасывает типы и не проверяет их, ради скорости. Проверяет tsc --noEmit, поэтому его запускают отдельно: в CI или в хуке перед коммитом.

Зачем писать .js в импортах .ts-файлов?

С module: nodenext TypeScript не переписывает пути при сборке. В dist окажутся файлы .js, и Node найдёт их по этим путям. Без расширения ES-модули в Node не работают.

Почему app и server — разные файлы?

Чтобы тесты могли создать приложение без listen и не занимать порт. Заодно в server.ts собраны все зависимости от окружения.

Клиент прислал битый JSON. Какой статус правильный и откуда он берётся?

400: ошибка на стороне клиента. Его ставит express.json() в поле status ошибки, а наш обработчик должен его уважать, а не превращать всё в 500.

Словарь

@types/*
Пакеты с описаниями типов для библиотек, написанных на JavaScript.
tsx
Утилита, которая запускает TypeScript без отдельной сборки и перезапускает сервер при изменениях. Типы не проверяет.
type stripping
Удаление аннотаций типов без проверки и без генерации кода. Так работает встроенная поддержка .ts в Node 22.18+.
type guard
Функция, которая проверяет значение во время работы и сообщает компилятору его тип (x is T).
supertest
Библиотека для HTTP-тестов приложения Express без ручного запуска сервера.
origin
Схема, домен и порт адреса. localhost:5173 и localhost:3000 — разные origin.
