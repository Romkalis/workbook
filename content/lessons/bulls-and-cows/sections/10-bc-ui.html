Шаг 9. Интерфейс без innerHTML

Требования к разметке строгие: body в index.html пустой, кроме скрипта, вся разметка создаётся кодом, и никаких innerHTML и insertAdjacentHTML.

  <head>
    <meta charset="utf-8" />
    <meta name="viewport" content="width=device-width, initial-scale=1" />
    <title>Bulls and Cows</title>
    <link rel="stylesheet" href="style.css" />
  </head>
  <body>
    <script type="module" src="dist/main.js"></script>
  </body>
</html>

Хелпер для элементов

Чтобы не писать по пять строк createElement на каждую кнопку, заведите одну функцию. Текст выставляется через textContent — это и безопасно, и удовлетворяет запрету на innerHTML.

// src/dom.ts
type Props = Partial<{ className: string; text: string; type: string; disabled: boolean }>;

export const el = <K extends keyof HTMLElementTagNameMap>(
  tag: K,
  { className, text, ...attrs }: Props = {},
  children: Node[] = [],
): HTMLElementTagNameMap[K] => {
  const node = document.createElement(tag);
  if (className) node.className = className;
  if (text !== undefined) node.textContent = text;
  Object.assign(node, attrs);
  node.append(...children);
  return node;
};

Экраны и перерисовка

Удобная схема: в main.ts лежит одна переменная с текущим состоянием и функция render, которая по состоянию строит нужный экран и заменяет содержимое корня через root.replaceChildren(...). Экранов три: настройки, игра, победа. Таблица рекордов показывается на экране настроек и после победы.

// src/main.ts (скелет)
type Screen = { kind: 'settings' } | { kind: 'game'; game: GameState };

let screen: Screen = { kind: 'settings' };
const root = el('main');
document.body.append(root);

const setScreen = (next: Screen): void => {
  screen = next;
  root.replaceChildren(screen.kind === 'settings' ? renderSettings() : renderGame(screen.game));
};

setScreen(screen);

Изменяемая переменная screen здесь допустима: это оболочка, «нечистый» край программы. Ядро в game.ts и state.ts про DOM ничего не знает.

Настройки

Два select: длина 2–6 и система счисления. Длина не может быть больше числа цифр системы, а в двоичной цифр всего две, поэтому при base = 2 все длины, кроме 2, получают disabled. Если игрок выбрал длину 4, а потом переключил систему на bin, сбросьте длину на 2, иначе выбранным останется недоступный вариант.

const BASES = [
  { label: 'bin', value: 2 },
  { label: 'oct', value: 8 },
  { label: 'dec', value: 10 },
  { label: 'hex', value: 16 },
];
const LENGTHS = [2, 3, 4, 5, 6];

const syncLengthOptions = (lengthSelect: HTMLSelectElement, base: number): void => {
  [...lengthSelect.options].forEach((option) => {
    option.disabled = Number(option.value) > base;
  });
  if (Number(lengthSelect.value) > base) lengthSelect.value = String(Math.min(base, 6));
};

Рядом с настройками удобно показать countPossibleSecrets(length, base): «вариантов: 5040». Функция вызывается при каждом изменении настроек — ради этого её и мемоизировали. Кнопка «Старт» вызывает startGame(settings, generateSecret(length, base), Date.now()). Экрана настроек на игровом экране просто нет, поэтому поменять их посреди раунда нельзя. Если оставляете селекты видимыми, ставьте им disabled.

Ввод попытки

Второе место использования createDigitValidator — фильтрация ввода. Событие beforeinput срабатывает до изменения поля и его можно отменить:

const isDigit = createDigitValidator(game.settings.base);
const input = el('input', { type: 'text' });
input.maxLength = game.settings.length;
input.autocomplete = 'off';

input.addEventListener('beforeinput', (event) => {
  const { data } = event;
  if (data && ![...data].every(isDigit)) event.preventDefault();
});

data равен null при удалении символов, такие события пропускаем. Вставка из буфера тоже проходит через beforeinput с вставляемым текстом в data, поэтому мусор не вставится целиком. Для подстраховки можно дополнительно чистить значение в обработчике input (из общих знаний: некоторые мобильные клавиатуры с автоподстановкой ведут себя непредсказуемо).

На отправке формы проверяем isValidGuess и, если всё в порядке, вызываем applyGuess. Если состояние вернулось той же ссылкой (next === game), значит попытка уже была — покажите сообщение вместо новой строки истории.

form.addEventListener('submit', (event) => {
  event.preventDefault();
  const { length, base } = game.settings;
  if (!isValidGuess(input.value, length, base)) {
    showError(`Нужно ${length} разных цифр`);
    return;
  }
  const next = applyGuess(game, input.value, Date.now());
  if (next === game) {
    showError('Такая попытка уже была');
    return;
  }
  if (next.status === 'won') saveWin(next);
  setScreen({ kind: 'game', game: next });
});

История, победа и новая игра

История — ol, где каждая попытка — li с текстом вида 0123 — 1 бык, 2 коровы. Её удобно строить через map по game.history. При победе saveWin собирает RecordEntry (attempts: history.length, timeMs: finishedAt − startedAt), прогоняет через addRecord и сохраняет. Кнопка «Новая игра» вызывает setScreen({ kind: 'settings' }) — без location.reload().

Для выигрыша время удобно показывать как мм:сс. Форматирование — тоже чистая функция: formatTime(ms). Ещё одно естественное место для теста.
