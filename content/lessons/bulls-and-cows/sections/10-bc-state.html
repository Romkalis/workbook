Шаг 8. Иммутабельное состояние и рекорды

Состояние раунда — один объект: настройки, секрет, история попыток, статус и время. Мы его никогда не меняем (иммутабельность). Каждое действие игрока — это чистая функция «старое состояние + действие → новое состояние». Такая функция легко тестируется без браузера, а интерфейс просто хранит ссылку на текущее состояние и перерисовывается по нему. Эти функции не входят в обязательные пять, но тесты на них стоит написать тем же порядком: тест, потом код.

Типы и создание раунда

// src/state.ts
import { evaluateGuess, type Score } from './game.js';

export type Settings = Readonly<{ length: number; base: number }>;
export type Attempt = Readonly<{ guess: string; score: Score }>;
export type GameState = Readonly<{
  settings: Settings;
  secret: string;
  history: readonly Attempt[];
  status: 'playing' | 'won';
  startedAt: number;
  finishedAt: number | null;
}>;

export const startGame = (settings: Settings, secret: string, now: number): GameState => ({
  settings,
  secret,
  history: [],
  status: 'playing',
  startedAt: now,
  finishedAt: null,
});

Readonly и readonly Attempt[] — подсказка компилятору: если где-то случайно написать state.history.push(...), TypeScript выдаст ошибку. Время now приходит параметром по той же причине, что и random: Date.now() внутри сделал бы функцию непредсказуемой.

Ход игрока

export const applyGuess = (state: GameState, rawGuess: string, now: number): GameState => {
  const guess = rawGuess.toLowerCase();
  if (state.status !== 'playing') return state;
  if (state.history.some((attempt) => attempt.guess === guess)) return state;

  const score = evaluateGuess(state.secret, guess);
  const won = score.bulls === state.settings.length;

  return {
    ...state,
    history: [...state.history, { guess, score }],
    status: won ? 'won' : 'playing',
    finishedAt: won ? now : null,
  };
};

Здесь закрыты сразу три пункта чек-листа. История растёт через [...history, entry], старые записи не трогаются. Повтор уже введённой попытки возвращает то же состояние без новой записи — интерфейс может показать подсказку «уже было». Победа фиксирует время, и число попыток равно history.length.

it('does not mutate the previous state', () => {
  const s0 = startGame({ length: 2, base: 10 }, '12', 1000);
  const s1 = applyGuess(s0, '13', 2000);
  expect(s0.history).toHaveLength(0);
  expect(s1.history).toHaveLength(1);
  expect(applyGuess(s1, '13', 2500)).toBe(s1);
});

it('finishes the game on all bulls', () => {
  const s0 = startGame({ length: 2, base: 10 }, '12', 1000);
  const won = applyGuess(applyGuess(s0, '13', 2000), '12', 5000);
  expect(won.status).toBe('won');
  expect(won.finishedAt! - won.startedAt).toBe(4000);
});

Таблица рекордов

Рекорд — запись с числом попыток, временем и настройками. Сортировка: меньше попыток лучше, при равенстве меньше время. Трюк с ||: если разница попыток равна нулю (ложь), сравнение переходит к времени.

export type RecordEntry = Readonly<{
  attempts: number;
  timeMs: number;
  length: number;
  base: number;
  date: number;
}>;

export const compareRecords = (a: RecordEntry, b: RecordEntry): number =>
  a.attempts - b.attempts || a.timeMs - b.timeMs;

export const addRecord = (
  records: readonly RecordEntry[],
  entry: RecordEntry,
  limit = 10,
): RecordEntry[] => [...records, entry].sort(compareRecords).slice(0, limit);

sort меняет массив на месте, но здесь он сортирует свежую копию из [...records, entry], так что исходный массив цел. В новых браузерах есть toSorted, который сразу возвращает копию.

Задание разрешает два варианта: отдельная таблица на каждую пару длина/система или один список с бейджем настроек у каждой записи. Второй проще — в записи уже есть length и base, их достаточно вывести рядом с результатом.

Работа с localStorage — это побочный эффект, поэтому она живёт отдельно от ядра, в маленьком модуле:

// src/storage.ts
import type { RecordEntry } from './state.js';

const KEY = 'bulls-and-cows:records';

export const loadRecords = (): RecordEntry[] => {
  try {
    const parsed: unknown = JSON.parse(localStorage.getItem(KEY) ?? '[]');
    return Array.isArray(parsed) ? parsed : [];
  } catch {
    return [];
  }
};

export const saveRecords = (records: readonly RecordEntry[]): void => {
  localStorage.setItem(KEY, JSON.stringify(records));
};

try/catch нужен на случай испорченного JSON в хранилище: без него игра упадёт при загрузке, а за неработающее приложение штраф −50.
