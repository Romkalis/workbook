Шаг 4. isValidGuess: три условия

Попытка корректна, если совпадает длина, каждый символ — допустимая цифра и цифры не повторяются. Эти три условия и превращаются в три группы тестов.

Тесты

describe('isValidGuess', () => {
  it('accepts a correct guess, including a leading zero', () => {
    expect(isValidGuess('0123', 4, 10)).toBe(true);
  });

  it('rejects a wrong length', () => {
    expect(isValidGuess('012', 4, 10)).toBe(false);
    expect(isValidGuess('01234', 4, 10)).toBe(false);
  });

  it('rejects digits outside the base', () => {
    expect(isValidGuess('18', 2, 8)).toBe(false);
    expect(isValidGuess('1g', 2, 16)).toBe(false);
  });

  it('rejects repeated digits', () => {
    expect(isValidGuess('0113', 4, 10)).toBe(false);
  });

  it('treats a and A as the same hex digit', () => {
    expect(isValidGuess('aB', 2, 16)).toBe(true);
    expect(isValidGuess('aA', 2, 16)).toBe(false);
  });
});

Реализация

const normalize = (value: string): string[] => [...value.toLowerCase()];

export const isValidGuess = (guess: string, length: number, base: number): boolean => {
  const isDigit = createDigitValidator(base);
  const chars = normalize(guess);
  return (
    chars.length === length &&
    chars.every(isDigit) &&
    new Set(chars).size === chars.length
  );
};

Повторы ловит Set: он хранит только уникальные значения, и если его размер меньше длины массива, значит какая-то цифра встретилась дважды. Приведение к нижнему регистру делается до Set, иначе 'aA' прошла бы как две разные цифры. chars.every(isDigit) — первое из двух мест, где работает каррированный валидатор: в every передаётся готовый предикат.
