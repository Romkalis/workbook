Шаг 6. generateSecret: случайность как параметр

Функция с Math.random() внутри не чистая: на одинаковых аргументах она возвращает разные результаты, и тест на конкретное значение написать невозможно. Приём из задания простой: источник случайности приходит третьим параметром со значением по умолчанию Math.random. В игре его не передают, а в тестах передают функцию, которая всегда возвращает известные числа.

Алгоритм: берём алфавит системы ('0123456789' для dec), выбираем случайный индекс, забираем этот символ и повторяем на оставшихся символах. Так цифры никогда не повторятся. Повторение «на оставшихся» естественно записывается рекурсией, а «оставшиеся» получаются через filter — новый массив без выбранного элемента, без splice.

Тесты

describe('generateSecret', () => {
  it('takes the first free digit each time when random returns 0', () => {
    expect(generateSecret(4, 10, () => 0)).toBe('0123');
  });

  it('takes the last free digit each time when random is close to 1', () => {
    expect(generateSecret(3, 16, () => 0.999)).toBe('fed');
  });

  it('follows a scripted sequence of random values', () => {
    const values = [0.5, 0, 0.99];
    let call = 0;
    const random = () => values[call++] ?? 0;
    expect(generateSecret(3, 10, random)).toBe('509');
  });

  it('always returns a valid secret', () => {
    const secret = generateSecret(6, 16, () => 0.3);
    expect(isValidGuess(secret, 6, 16)).toBe(true);
  });
});

Разберём третий тест. Пул 0–9, 0.5 × 10 = 5 → берём 5. Пул из девяти цифр без пятёрки, 0 × 9 = 0 → 0. Пул из восьми цифр 1,2,3,4,6,7,8,9, floor(0.99 × 8) = 7 → 9. Итог '509'. Счётчик call живёт внутри теста, поэтому тесты не зависят друг от друга.

Реализация

export const generateSecret = (
  length: number,
  base: number,
  random: () => number = Math.random,
): string => {
  const pick = (pool: readonly string[], left: number): string[] => {
    if (left === 0) return [];
    const index = Math.floor(random() * pool.length);
    const rest = pool.filter((_, i) => i !== index);
    return [pool[index] as string, ...pick(rest, left - 1)];
  };
  return pick([...ALPHABET.slice(0, base)], length).join('');
};

Секрет хранится строкой, а не числом: число 0123 превратилось бы в 123 и потеряло ведущий ноль. Строка также естественна для hex.

Строго говоря, функция с Math.random по умолчанию остаётся нечистой, когда её вызывают без третьего аргумента. Чистой она становится при переданном детерминированном random. Эффект не исчез, его вынесли на край программы — туда, где игра стартует раунд. Об этом стоит честно написать в DESIGN.md.
