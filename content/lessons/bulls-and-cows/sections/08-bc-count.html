Шаг 7. countPossibleSecrets: рекурсия и мемоизация

Сколько существует секретов длины length в системе base? Это число размещений без повторений: на первое место подходит любая из base цифр, на второе — любая из оставшихся base − 1, и так далее. Ведущий ноль разрешён, поэтому ничего вычитать не нужно. Для 4 цифр в dec: 10 × 9 × 8 × 7 = 5040.

Рекурсивная запись прямо следует из этого рассуждения: count(length, base) = base × count(length − 1, base − 1). Базовый случай: count(0, base) = 1 — пустое число можно составить одним способом.

Тесты

describe('countPossibleSecrets', () => {
  it('counts permutations without repetition', () => {
    expect(countPossibleSecrets(4, 10)).toBe(5040);
    expect(countPossibleSecrets(2, 2)).toBe(2);
    expect(countPossibleSecrets(6, 16)).toBe(5765760);
  });

  it('returns 1 for zero length', () => {
    expect(countPossibleSecrets(0, 10)).toBe(1);
  });

  it('returns 0 when length is greater than base', () => {
    expect(countPossibleSecrets(3, 2)).toBe(0);
  });
});

Реализация

Мемоизацию лучше написать отдельной функцией высшего порядка: она принимает функцию и возвращает её версию с кэшем. Ключ кэша — аргументы, сериализованные в строку.

export const memoize = <A extends unknown[], R>(fn: (...args: A) => R) => {
  const cache = new Map<string, R>();
  return (...args: A): R => {
    const key = JSON.stringify(args);
    if (!cache.has(key)) cache.set(key, fn(...args));
    return cache.get(key) as R;
  };
};

export const countPossibleSecrets: (length: number, base: number) => number = memoize(
  (length: number, base: number): number => {
    if (length > base) return 0;
    if (length === 0) return 1;
    return base * countPossibleSecrets(length - 1, base - 1);
  },
);

Обратите внимание: рекурсивный вызов идёт к мемоизированной countPossibleSecrets, а не к внутренней функции. Поэтому в кэш попадают и промежуточные результаты: после count(4, 10) там уже лежат count(3, 9), count(2, 8) и так далее. Аннотация типа у константы нужна, потому что TypeScript не может вывести тип переменной, которая ссылается на себя в собственном инициализаторе.

Кэш внутри memoize — изменяемое состояние, но оно скрыто в замыкании и не влияет на результат: снаружи функция по-прежнему чистая, одинаковые аргументы дают одинаковый ответ. Честно говоря, для чисел до 16 мемоизация здесь — учебное упражнение, вычисление и так занимает микросекунды. Задание это понимает и просит именно приём.
