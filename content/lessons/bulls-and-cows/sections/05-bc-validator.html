Шаг 3. createDigitValidator: каррированная фабрика

Функция принимает систему счисления и возвращает другую функцию — предикат «этот символ допустимая цифра?». Это и есть каррирование: вместо isDigit(base, char) мы пишем createDigitValidator(base)(char). Выгода практическая: систему счисления фиксируем один раз при старте раунда, а получившийся isHexDigit отдаём туда, где нужен только символ — в every внутри isValidGuess и в обработчик ввода. Критерий так и звучит: фабрика используется минимум в двух местах.

Тесты (красный коммит)

// src/game.test.ts
import { describe, it, expect } from 'vitest';
import { createDigitValidator } from './game.js';

describe('createDigitValidator', () => {
  it('returns a function', () => {
    expect(typeof createDigitValidator(10)).toBe('function');
  });

  it('accepts only 0 and 1 in binary', () => {
    const isBin = createDigitValidator(2);
    expect(isBin('0')).toBe(true);
    expect(isBin('1')).toBe(true);
    expect(isBin('2')).toBe(false);
  });

  it('rejects 8 and 9 in octal', () => {
    const isOct = createDigitValidator(8);
    expect(isOct('7')).toBe(true);
    expect(isOct('8')).toBe(false);
  });

  it('treats hex letters case-insensitively', () => {
    const isHex = createDigitValidator(16);
    expect(isHex('a')).toBe(true);
    expect(isHex('F')).toBe(true);
    expect(isHex('g')).toBe(false);
  });

  it('rejects empty strings and several characters', () => {
    const isDec = createDigitValidator(10);
    expect(isDec('')).toBe(false);
    expect(isDec('12')).toBe(false);
  });
});

Последний тест не для галочки. Если проверять через alphabet.includes(char) без проверки длины, то пустая строка и '01' окажутся «цифрами»: '0123'.includes('') и '0123'.includes('01') равны true.

Реализация (зелёный коммит)

// src/game.ts
export const ALPHABET = '0123456789abcdef';

export const createDigitValidator =
  (base: number) =>
  (char: string): boolean =>
    char.length === 1 && ALPHABET.slice(0, base).includes(char.toLowerCase());

Одна строка ALPHABET обслуживает все четыре системы: для base = 2 берём '01', для 8 — '01234567', для 16 — всю строку. Регистр приводится через toLowerCase, поэтому A и a — одна цифра, как требует задание.
