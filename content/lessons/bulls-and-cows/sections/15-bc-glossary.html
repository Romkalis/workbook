Словарь

Быки и коровы
Бык — цифра угадана и стоит на своём месте. Корова — цифра есть в секрете, но в другом месте.
Система счисления (base)
Сколько разных цифр используется: bin — 2 (0–1), oct — 8 (0–7), dec — 10, hex — 16 (0–9 и a–f).
Чистая функция
Одинаковые аргументы — одинаковый результат, без побочных эффектов. Подробно — «Основы ФП».
Иммутабельное обновление
Создание нового объекта или массива вместо изменения старого: [...history, entry].
Каррированная фабрика
Функция, которая по первому аргументу возвращает готовую функцию для второго: createDigitValidator(16)('a').
Предикат
Функция, возвращающая true или false.
Мемоизация
Кэширование результатов функции по аргументам.
Размещения без повторений
Число способов выбрать по порядку n разных элементов из b: b × (b − 1) × … — всего n множителей.
TDD, красный и зелёный коммит
Сначала коммит с падающими тестами, затем коммит с кодом, после которого тесты проходят.
Заглушка
Временная реализация, которая только бросает ошибку Not implemented, чтобы тесты падали по делу.
Git-хук
Скрипт, который git запускает перед коммитом или отправкой. Husky хранит их в репозитории.
lint-staged
Запускает линтер и форматтер только для файлов, добавленных в коммит.
Деплой
Публикация сайта на хостинге, чтобы его можно было открыть по ссылке.
Pull Request (PR)
Запрос на слияние ветки; в этом задании — форма сдачи, его не мержат.
Кросс-чек
Проверка работы другими студентами по критериям задания.
