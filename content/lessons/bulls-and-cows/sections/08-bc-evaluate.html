Шаг 5. evaluateGuess: быки и коровы через filter

Задание запрещает ручные циклы со счётчиками и требует методы массивов — функции высшего порядка filter, map, reduce. Самый короткий путь — посчитать две величины:

  • быки — сколько позиций совпадает: символ попытки равен символу секрета с тем же индексом;
  • общие цифры — сколько цифр попытки вообще есть в секрете, неважно где.

Тогда коровы — это общие цифры минус быки. Формула верна только потому, что цифры в секрете и попытке уникальны: каждая цифра попытки может совпасть максимум с одной цифрой секрета. В классической игре с повторами так считать нельзя.

Тесты

describe('evaluateGuess', () => {
  it('counts bulls and cows', () => {
    expect(evaluateGuess('1234', '1243')).toEqual({ bulls: 2, cows: 2 });
  });

  it('returns zeros when nothing matches', () => {
    expect(evaluateGuess('0123', '4567')).toEqual({ bulls: 0, cows: 0 });
  });

  it('returns only bulls for the exact secret', () => {
    expect(evaluateGuess('1234', '1234')).toEqual({ bulls: 4, cows: 0 });
  });

  it('ignores the case of hex digits', () => {
    expect(evaluateGuess('ab', 'BA')).toEqual({ bulls: 0, cows: 2 });
  });
});

Реализация

export type Score = Readonly<{ bulls: number; cows: number }>;

export const evaluateGuess = (secret: string, guess: string): Score => {
  const secretChars = normalize(secret);
  const guessChars = normalize(guess);
  const secretDigits = new Set(secretChars);

  const bulls = guessChars.filter((ch, i) => ch === secretChars[i]).length;
  const common = guessChars.filter((ch) => secretDigits.has(ch)).length;

  return { bulls, cows: common - bulls };
};

filter возвращает новый массив только из тех элементов, для которых колбэк вернул true; .length этого массива и есть счётчик. Второй аргумент колбэка i — индекс элемента, по нему сравниваем позиции. Set — коллекция уникальных значений с быстрой проверкой has (см. Object, Map и Set).

Set из цифр секрета превращает проверку «есть ли цифра в секрете» в O(1) вместо прохода по строке. При длине до 6 разницы не заметить, но в DESIGN.md это хороший аргумент: функция линейная, O(n). Можно написать то же через один reduce, который возвращает объект { bulls, cows }, но два filter читаются проще.
