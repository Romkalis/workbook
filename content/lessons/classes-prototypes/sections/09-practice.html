В RS-App модуль предлагает пройти автоматический тест «[St1] Classes & Prototypes». Точные вопросы теста здесь не воспроизводятся; конспект готовит к понятиям и чтению кода из целей модуля.

  1. Сначала пройдите тест в конце этой страницы и отметьте темы, в которых ошиблись.
  2. Нарисуйте цепочку поиска для объекта, созданного через Object.create, и отдельно для экземпляра класса-наследника.
  3. Напишите один пример наследования функциями-конструкторами ES5 и перепишите его с class.
  4. Для общего поведения реализуйте примесь, затем сравните её с композицией отдельного объекта.
  5. Проверьте примеры в консоли: отдельно выведите typeof, instanceof и Object.getPrototypeOf.

Мини-задача: найти метод

Не запуская код, ответьте: откуда вызовется pet.speak() и чему равен this.name?

const animal = {
  name: 'животное',
  speak() { return this.name; },
};
const pet = Object.create(animal);
pet.name = 'кот';
pet.speak();
Ответ: метод найден в прототипе, но this — pet

В самом pet нет speak, поэтому поиск продолжается в animal. Но метод вызван как pet.speak(), значит this равен pet и результат — 'кот'.
