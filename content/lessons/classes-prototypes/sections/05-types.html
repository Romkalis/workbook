typeof и instanceofИсточники: MDN, JavaScript.info

Для выбора проверки сначала сформулируйте вопрос. «Это строка?» — typeof. «Это массив?» — Array.isArray. «Есть ли прототип данного конструктора в цепочке объекта?» — instanceof. «Это null?» — прямое сравнение с null. Одной универсальной проверки на все случаи здесь нет.

Операторы отвечают на разные вопросы. typeof возвращает строку с категорией значения, а instanceof проверяет, встречается ли прототип конкретного конструктора в цепочке прототипов объекта.

  class User {}

  typeof 42;                         // 'number'
typeof 'текст';                    // 'string'
typeof function () {};             // 'function'
typeof {};                         // 'object'
typeof null;                       // 'object' — историческая особенность
typeof User;                       // 'function' для объявления class User

const user = new User();
user instanceof User;              // true
user instanceof Object;            // true

instanceof возвращает логическое значение true или false. Для примитивов он не определяет тип: например, 42 instanceof Number вернёт false. Оператор предназначен прежде всего для объектов и проверки их прототипной цепочки. Не путайте его с typeof, который работает и с примитивами, и всегда возвращает строку.

Object.prototype.toString()

У объектов есть унаследованный метод toString, который возвращает строку. Вызов Object.prototype.toString.call(value) позволяет применить именно этот метод к разным значениям и получить метку вроде [object Number] или [object Array]. Для проверки массива всё же используйте Array.isArray: строки с метками не всегда надёжны для определения типа.

Object.prototype.toString.call(42); // '[object Number]'
Object.prototype.toString.call([]); // '[object Array]'
Object.prototype.toString.call(null); // '[object Null]'

Ограничения typeof

typeof null возвращает 'object' по исторической причине — это не значит, что null является объектом. Для проверки на null сравнивайте значение напрямую: value === null. Массивы тоже дают 'object'; для них используйте Array.isArray(value).

Как работает instanceof

В обычном случае value instanceof Constructor проверяет, находится ли Constructor.prototype в цепочке прототипов у value. Это проверка цепочки, а не «точного типа».

class Animal {}
class Rabbit extends Animal {}
const rabbit = new Rabbit();

rabbit instanceof Rabbit; // true
rabbit instanceof Animal; // true

У instanceof есть ограничения: например, экземпляры из другого окна браузера могут принадлежать другому конструктору Array, поэтому проверка с локальным Array не сработает. Если нужно определить именно массив, надёжнее Array.isArray.
