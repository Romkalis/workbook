Объекты и свойстваИсточники: JavaScript.info, MDN

Различайте три действия: создать объект, записать в него собственное свойство и найти свойство при чтении. Если Object.hasOwn(obj, "name") даёт false, свойство name всё ещё может быть доступно через прототип. Оператор in учитывает и собственные, и унаследованные свойства.

Объект — это набор свойств. У свойства есть ключ и значение: ключом обычно служит строка или символ, а значением может быть любой тип, в том числе функция. Когда функция хранится в объекте и вызывается через него, её обычно называют методом.

const user = {
  name: 'Лена',
  'favorite color': 'синий',
  greet() {
    return `Привет, я ${this.name}`;
  },
};

user.name;                  // 'Лена'
user['favorite color'];     // 'синий'
user.greet();               // 'Привет, я Лена'
Object.hasOwn(user, 'name'); // true

Свойства могут быть собственными — записанными прямо в объекте — или унаследованными от его прототипа. Оператор in проверяет оба случая, а Object.hasOwn — только собственные свойства.

const animal = { eats: true };
const rabbit = Object.create(animal);
rabbit.jumps = true;

Object.hasOwn(rabbit, 'jumps'); // true
Object.hasOwn(rabbit, 'eats');  // false
'eats' in rabbit;               // true

Ключи и значения

Для обычных строковых ключей подходят точечная и квадратная нотация. Квадратные скобки нужны, если имя содержит пробел или хранится в переменной. Проверяйте собственность свойства явно, если важно отличить его от унаследованного.

Откуда берётся this

В вызове user.greet() значение this — объект слева от точки, то есть user. Если отделить метод от объекта, связь теряется:

'use strict';
const user = {
  name: 'Лена',
  greet() { return `Привет, я ${this.name}`; },
};
const greet = user.greet;
greet(); // TypeError: в строгом режиме this будет undefined

Чтобы сохранить контекст, передайте функцию-обёртку () => user.greet() или заранее привяжите его через user.greet.bind(user).
