extends, переопределение и superИсточники: JavaScript.info, MDN

При объявлении class Child extends Parent настраиваются две связи: экземпляры-потомки ищут методы через Child.prototype → Parent.prototype, а сам класс-потомок наследует статические члены от класса-родителя.

class Animal {
  static category() {
    return 'животное';
  }
  speak() {
    return 'звук';
  }
}
class Dog extends Animal {
  speak() {
    return `${super.speak()}: гав`;
  }
}

const dog = new Dog();
dog.speak(); // 'звук: гав'
Dog.category(); // 'животное'
Object.getPrototypeOf(Dog.prototype) === Animal.prototype; // true
Object.getPrototypeOf(Dog) === Animal; // true

Переопределение метода

Если метод определён в потомке, поиск остановится на нём и версия родителя будет затенена. Вызов super.speak() позволяет расширить поведение родителя, не копируя его реализацию. Ключевое слово super не является отдельным объектом; это специальная форма доступа к родительской реализации. Когда разные классы по-разному отвечают на один и тот же вызов speak(), это пример полиморфизма.

Почему стрелка может использовать super

Стрелочная функция не создаёт собственный this и не имеет собственного доступа к super: она берёт их из окружающего метода класса. Поэтому стрелка, созданная внутри метода, может вызвать родительский метод. Обычная вложенная функция не наследует такой доступ к super.

class Parent {
  greet() { return 'Привет'; }
}
class Child extends Parent {
  makeCallback() {
    return () => super.greet();
  }
}

new Child().makeCallback()(); // 'Привет'

Когда наследование не нужно

Не создавайте наследование только ради повторного использования пары методов. Наследник должен корректно подходить везде, где ожидается базовый класс. Если отношение скорее «имеет», чем «является», часто лучше композиция: объект хранит другой объект и передаёт ему работу.

class Logger {
  log(message) {
    return `[app] ${message}`;
  }
}
class Service {
  constructor(logger) {
    this.logger = logger;
  }
  start() {
    return this.logger.log('сервис запущен');
  }
}

new Service(new Logger()).start(); // '[app] сервис запущен'
