Во всех трёх подходах отслеживайте две разные операции: кто записал начальные поля объекта и где затем ищутся методы. Object.create связывает объекты, вызов конструктора заполняет поля. В синтаксисе классов эти обязанности выражены через extends и super.

Прототипное наследование означает, что объект использует свойства другого объекта через цепочку поиска. Исторически в JavaScript для этого применяли несколько способов. Сравним делегирование через Object.create («способ Крокфорда»), функцию-конструктор ES5 и синтаксис классов ES2015.

Способ Крокфорда: делегирование объекту

Идея этого подхода — создать новый объект на основе существующего прототипа, не вызывая классический конструктор. Иногда этот вариант связывают с функцией beget; в современном коде ту же задачу решает Object.create.

const person = {
  init(name) {
    this.name = name;
    return this;
  },
  greet() {
    return `Привет, я ${this.name}`;
  },
};

const student = Object.create(person).init('Миша');
student.course = 2;
student.greet(); // 'Привет, я Миша'
Object.getPrototypeOf(student) === person; // true

Здесь student делегирует поиск методов объекту person. Поле name записывается в сам student, потому что внутри метода this — объект перед точкой.

ES5: функции-конструкторы

До class конструктор был обычной функцией, вызываемой с new. Методы размещали в её свойстве prototype. Для наследования экземпляров создавали прототип потомка через Object.create, а конструктор родителя вызывали с нужным this через Parent.call.

function Person(name) {
  this.name = name;
}
Person.prototype.greet = function () {
  return `Привет, я ${this.name}`;
};

function Student(name, course) {
  Person.call(this, name); // инициализация данных родителя
  this.course = course;
}
Student.prototype = Object.create(Person.prototype);
Student.prototype.constructor = Student;
Student.prototype.introduce = function () {
  return `${this.greet()}, курс ${this.course}`;
};

new Student('Миша', 2).introduce(); // 'Привет, я Миша, курс 2'

Здесь две отдельные задачи, и каждую решает своя строка.

  • Object.create(Person.prototype) даёт студенту доступ к методам Person: связывает прототипы. Конструктор Person при этом не вызывается.
  • Person.call(this, name) записывает в новый объект поле name: вызывает конструктор родителя для нашего объекта. Это то, что в классах делает super(name).

Строка Student.prototype.constructor = Student возвращает свойство constructor: после замены прототипа оно указывало бы на Person. На наследование оно не влияет, но по нему иногда узнают, каким конструктором создан объект.

ES2015: class и extends

Современная запись делает обе операции явными: extends связывает прототипы, а super(...args) вызывает конструктор родителя.

class Person {
  constructor(name) {
    this.name = name;
  }
  greet() {
    return `Привет, я ${this.name}`;
  }
}

class Student extends Person {
  constructor(name, course) {
    super(name); // до этого вызова this использовать нельзя
    this.course = course;
  }
  introduce() {
    return `${super.greet()}, курс ${this.course}`;
  }
}

new Student('Миша', 2).introduce(); // 'Привет, я Миша, курс 2'

В конструкторе производного класса super() обязателен, если конструктор объявлен. Он должен выполниться до обращения к this. super.method() вызывает реализацию метода из родительского класса.
