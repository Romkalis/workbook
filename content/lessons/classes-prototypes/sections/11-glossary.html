Глоссарий

Класс
Синтаксис для описания создания объектов, их полей и поведения.
Полиморфизм
Возможность объектов разных типов отвечать на один и тот же вызов по-разному, например реализовывать собственный метод speak().
Объект
Набор свойств; значение свойства может быть любого типа.
Экземпляр
Объект, созданный по классу или функции-конструктору.
Конструктор
Функция или метод constructor, инициализирующий новый экземпляр.
Свойство
Пара «ключ — значение», принадлежащая объекту или доступная через его прототип.
Собственное свойство
Свойство, записанное непосредственно в объекте, а не найденное в цепочке.
[[Prototype]]
Внутренняя ссылка объекта на другой объект или null.
Constructor.prototype
Свойство конструктора, используемое как прототип его экземпляров.
Цепочка прототипов
Последовательность объектов, по которой JavaScript ищет свойство.
Делегирование
Использование свойств и методов другого объекта через прототипную цепочку.
Функция-конструктор
Функция, предназначенная для создания объектов вызовом с new.
Статический метод
Метод класса, вызываемый через сам класс, а не через экземпляр.
Polyfill (полифилл)
Реализация возможности из стандарта JavaScript для среды, в которой эта возможность ещё не поддерживается.
Приватный член
Поле или метод класса с префиксом #, доступный только внутри объявившего его класса.
Защищённый член
В JavaScript отдельного уровня protected нет; подчёркивание в начале имени — лишь соглашение.
Примитив
Значение базового типа, например число, строка, логическое значение, null или undefined; оно не является объектом.
Строгий режим
Режим JavaScript с более строгими правилами; например, у обычного вызова функции без объекта перед точкой значение this равно undefined.
Стрелочная функция
Функция, записанная через =>; она берёт this и доступ к super из внешнего метода, а не создаёт собственные.
Геттер / сеттер
Методы класса или объекта, которые вызываются при чтении или записи свойства.
Переопределение
Определение в потомке метода с именем унаследованного метода.
Примесь (mixin)
Приём добавления независимого поведения классу или объекту без множественного наследования классов.
typeof
Оператор, возвращающий строковую категорию значения.
instanceof
Оператор проверки прототипной цепочки относительно конструктора.
