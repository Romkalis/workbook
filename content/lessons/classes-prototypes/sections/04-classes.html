Классы в JavaScriptИсточники: JavaScript.info, MDN

В примерах сначала смотрите на new: конструктор получает аргументы и записывает поля экземпляра. Затем найдите вызов метода и прочитайте this как объект перед точкой. Static-член ищите отдельно — на самом классе. Так вы не смешаете данные конкретного пользователя и общие возможности класса.

Класс описывает, как создавать объекты и какое поведение им дать. Вызов new создаёт экземпляр, а конструктор инициализирует его данные. Методы класса обычно общие для всех экземпляров и хранятся в ClassName.prototype.

class User {
  constructor(name) {
    this.name = name;
  }

  sayHi() {
    return `Привет, ${this.name}`;
  }
}

const user = new User('Оля');
user.sayHi(); // 'Привет, Оля'
Object.getPrototypeOf(user) === User.prototype; // true
Object.hasOwn(user, 'sayHi'); // false

Конструктор и поля

Метод constructor вызывается при создании экземпляра через new. Если он не указан, JavaScript добавит конструктор по умолчанию: пустой у базового класса и передающий аргументы родителю у наследника. Поля экземпляра принадлежат конкретному объекту; методы класса хранятся в прототипе, а не копируются в каждый экземпляр.

class Lamp {
  isOn = false; // отдельное поле каждого экземпляра
  constructor(color) {
    this.color = color;
  }
  toggle() {
    this.isOn = !this.isOn;
    return this.isOn;
  }
}

const deskLamp = new Lamp('зелёный');
deskLamp.toggle(); // true

Статические методы

Метод или поле с ключевым словом static принадлежит самому классу, а не его экземплярам. Он подходит для операций и значений, которым не нужны данные конкретного объекта, например для фабрики или константы.

class Temperature {
  constructor(celsius) {
    this.celsius = celsius;
  }
  static fromFahrenheit(value) {
    return new Temperature((value - 32) * 5 / 9);
  }
}

Temperature.fromFahrenheit(68).celsius; // 20
// new Temperature(20).fromFahrenheit(68); // TypeError

Статические свойства и методы наследуются классом-потомком через цепочку самих классов. Они не копируются в потомка: доступ к свойству родителя продолжается по прототипной цепочке конструктора.

class Animal {
  static category = 'животное';
  static describe() { return this.category; }
}
class Cat extends Animal {}

Cat.category; // 'животное'
Cat.describe(); // 'животное'
Object.hasOwn(Cat, 'category'); // false

Объявление класса и выражение класса

Класс можно объявить по имени или создать как выражение и сохранить в переменную. Фигурные скобки в примере — тело класса, а запятые между методами не ставятся.

const User = class {
  greet() {
    return 'Привет';
  }
};

new User().greet(); // 'Привет'

Один конструктор или конструктор по умолчанию

В классе может быть не более одного метода constructor; второй приведёт к синтаксической ошибке. Если конструктор не написан, JavaScript создаёт его автоматически. Для базового класса он пустой, а для потомка передаёт аргументы конструктору родителя через super(...args).

class Base {
  constructor(value) { this.value = value; }
}
class Child extends Base {}

new Child(42).value; // 42 — конструктор по умолчанию вызвал super(42)

Публичные, приватные и «защищённые» члены

Публичные поля и методы доступны снаружи и наследуются обычным образом. Приватные поля и методы с префиксом # — настоящая языковая возможность: обращаться к ним можно только из тела класса, где они объявлены. Потомок не может напрямую прочитать приватное поле родителя.

class Account {
  #balance = 0;
  balance = 'публичное поле с тем же коротким именем';

    #validate(amount) {
      if (amount <= 0) throw new RangeError('сумма должна быть положительной');
  }
    deposit(amount) {
      this.#validate(amount);
      this.#balance += amount;
    }
  getBalance() {
    return this.#balance;
  }
}

const account = new Account();
account.balance; // 'публичное поле с тем же коротким именем'
account.getBalance(); // 0
// account.#balance; // SyntaxError: приватный идентификатор недоступен снаружи

#balance и balance — разные поля, поэтому у одного класса могут быть оба. Приватные методы тоже объявляются с #, например #validate выше. Такой префикс — часть синтаксиса и реальная защита языка, а не просто договорённость. Имя с подчёркиванием, например _balance, — лишь общепринятое соглашение о «защищённом» члене. В JavaScript нет отдельного уровня доступа protected: такое свойство остаётся публичным. Обычный метод родителя наследуется потомком; приватный идентификатор родителя напрямую потомку недоступен.

Чем класс отличается от функции-конструктора

  • Класс нельзя вызвать как обычную функцию: без new будет TypeError.
  • Код внутри тела класса всегда работает в строгом режиме.
  • Объявление класса нельзя использовать до строки объявления: попытка обратиться к нему раньше приведёт к ReferenceError.
  • Методы класса неперечисляемы при обычном перечислении свойств прототипа.

Класс может наследоваться от встроенного класса, например Array или Map, если нужен специализированный тип. Синтаксис классов появился в ES2015. Объявление класса создаёт специальную функцию-конструктор — поэтому typeof User возвращает 'function', хотя сам класс нельзя вызвать без new. Класс не является отдельным примитивным типом или интерфейсом; наследование экземпляров по-прежнему опирается на цепочки прототипов.

class UserList extends Array {}
const users = new UserList('Аня', 'Миша');
users.length; // 2
users[0]; // 'Аня'
