Примеси (mixins)Источники: JavaScript.info, MDN

Проверьте отличие от прототипа: копирование метода добавляет свойство в выбранный объект, а прототип задаёт, где продолжить поиск отсутствующего свойства. Поэтому изменение исходной примеси после копирования не заменяет уже скопированное значение автоматически.

У объекта только один [[Prototype]], а класс может иметь только один непосредственный родитель. Множественного наследования классов в JavaScript нет. Если независимое поведение нужно нескольким классам, его можно переиспользовать через примесь (mixin). Это приём, а не встроенная языковая конструкция и не другое название наследования.

Примесь через копирование методов

Один простой вариант — скопировать методы из объекта прямо в экземпляр или в прототип класса. Это добавляет свойства, а не устанавливает прототип источника. Object.assign копирует собственные перечисляемые свойства и при совпадении ключей перезаписывает значение в целевом объекте. Поэтому следите за конфликтами имён.

const canLog = {
  log(message) {
    return `${this.name}: ${message}`;
  },
};

class Service {
  constructor(name) {
    this.name = name;
  }
}
Object.assign(Service.prototype, canLog);

new Service('Поиск').log('готов'); // 'Поиск: готов'

Метод копируется в Service.prototype; экземпляр не начинает наследовать сам объект canLog. Копируются только собственные перечисляемые свойства, поэтому приватные поля класса и методы, объявленные через class, таким способом автоматически не переносятся.

Можно скопировать примесь и прямо в один объект, не создавая наследование от класса или объекта-примеси:

const canRun = {
  run() { return `${this.name} работает`; },
};
const task = { name: 'Задача' };
Object.assign(task, canRun);
task.run(); // 'Задача работает'

Фабрика примесей для классов

Фабрика может принимать базовый класс и возвращать новый класс с дополнительным поведением. Так примесь участвует в цепочке наследования, а не копирует методы.

  const withId = (Base) => {
    let nextId = 0;
    return class extends Base {
      constructor(...args) {
        super(...args);
        this.id = ++nextId;
      }
    };
  };

class User {
  constructor(name) {
    this.name = name;
  }
}
class IdentifiedUser extends withId(User) {}

const user = new IdentifiedUser('Аня');
user.name; // 'Аня'
typeof user.id; // 'number'
Что выбрать

Фабрика примесей может сама использовать наследование от переданного класса, но это не добавляет языку множественное наследование: базовый класс всё равно один. Если классы действительно образуют отношение «является», подойдёт extends. Если объект использует сервис или составную часть — композиция. Если нужно переиспользовать независимый набор методов, рассмотрите небольшую примесь и проверьте, нет ли конфликтов.
