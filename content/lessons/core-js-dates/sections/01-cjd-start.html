Задание и правила

core-js-dates — 14 функций в файле src/core-js-dates-tasks.js. Запуск и сдача такие же, как в core-js-functions: форк, npm install, решение, npm test (сначала ESLint, потом Mocha), Submit в RS App. Любая ошибка линтера — 0 баллов за всё задание.

Тесты проверяют ещё одно правило: в теле функции не должно быть комментариев. Проверка читает текст функции через toString() и ищет // или */. Она срабатывает и на строку с // внутри, например 'https://...'. Перед сдачей удалите комментарии из решений и не вставляйте адреса в код функций.

Справка — MDN: Date и Intl, ссылки на них есть в шапке файла задания.
