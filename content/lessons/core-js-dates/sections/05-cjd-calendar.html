Календарные правила

10. getWeekNumberByDate — номер недели по ISO 8601

Date(2024, 0, 3) => 1
Date(2024, 1, 23) => 8

По ISO 8601 неделя начинается в понедельник, а первая неделя года — та, в которую попал первый четверг. Отсюда алгоритм: сдвигаемся к четвергу текущей недели, берём его год и считаем, какая это по счёту неделя от 1 января того же года.

function getWeekNumberByDate(date) {
  const DAY = 24 * 60 * 60 * 1000;
  const d = new Date(
    Date.UTC(date.getFullYear(), date.getMonth(), date.getDate())
  );
  const isoDay = d.getUTCDay() || 7;
  d.setUTCDate(d.getUTCDate() + 4 - isoDay);
  const yearStart = Date.UTC(d.getUTCFullYear(), 0, 1);
  return Math.ceil(((d - yearStart) / DAY + 1) / 7);
}

Шаг за шагом для 3 января 2024 (среда):

  1. Копия той же календарной даты в UTC — чтобы дальнейшая арифметика не зависела от пояса и перехода на летнее время.
  2. День недели по ISO: воскресенье — 7, а не 0 (|| 7).
  3. Сдвиг к четвергу этой недели: + 4 - 3 — 4 января.
  4. Дней от 1 января до 4 января — 3, плюс 1, делить на 7 с округлением вверх — неделя 1.

Почему четверг: он гарантирует, что неделя отнесена к тому году, в котором лежит большая её часть. 1 января 2021 года (пятница) по ISO — 53-я неделя 2020 года.

11. getNextFridayThe13th — ближайшая пятница, 13-е

Date(2024, 0, 1) => Date(2024, 8, 13)

Тринадцатое бывает раз в месяц, поэтому перебираем месяцы и проверяем, пятница ли.

function getNextFridayThe13th(date) {
  let year = date.getFullYear();
  let month = date.getMonth();
  let candidate = new Date(year, month, 13);
  while (candidate < date || candidate.getDay() !== 5) {
    month += 1;
    if (month === 12) {
      month = 0;
      year += 1;
    }
    candidate = new Date(year, month, 13);
  }
  return candidate;
}

Условие не уточняет, считать ли саму дату, если она — пятница, 13-е. Здесь она считается (candidate < date пропускает только прошедшие); тесты этот случай не проверяют. Цикл гарантированно конечен: пятница, 13-е, бывает каждый год, от одного до трёх раз (из общих знаний).

12. getQuarter — квартал

Date(2024, 1, 13) => 1
Date(2024, 10, 10) => 4

Месяцы 0–2 — первый квартал, 3–5 — второй и так далее.

function getQuarter(date) {
  return Math.floor(date.getMonth() / 3) + 1;
}

Тест подаёт и new Date(2024, 12, 10) — это январь 2025 года, первый квартал. Переполнение месяца обработал сам Date.

13. getWorkSchedule — график смен

{ start: '01-01-2024', end: '15-01-2024' }, 1, 3 => ['01-01-2024', '05-01-2024', '09-01-2024', '13-01-2024']

Формат DD-MM-YYYY Date не понимает, поэтому разбираем строку сами. Дальше каждый день периода получает номер i, и рабочий он, если i % (рабочие + выходные) < рабочие.

function getWorkSchedule(period, countWorkDays, countOffDays) {
  const DAY = 24 * 60 * 60 * 1000;
  const parse = (s) => {
    const [d, m, y] = s.split('-').map(Number);
    return Date.UTC(y, m - 1, d);
  };
  const format = (t) => {
    const d = new Date(t);
    const pad = (n) => String(n).padStart(2, '0');
    return `${pad(d.getUTCDate())}-${pad(d.getUTCMonth() + 1)}-${d.getUTCFullYear()}`;
  };
  const start = parse(period.start);
  const length = Math.round((parse(period.end) - start) / DAY) + 1;
  const cycle = countWorkDays + countOffDays;
  return Array.from({ length }, (_, i) => i)
    .filter((i) => i % cycle < countWorkDays)
    .map((i) => format(start + i * DAY));
}

Дни считаются в UTC и шагом ровно в сутки: в UTC нет переходов на летнее время, так что start + i * DAY всегда полночь нужного дня. В местном времени после перехода тот же шаг давал бы 23:00 предыдущего дня.

14. isLeapYear — високосный год

Date(2024, 2, 1) => true
Date(2022, 2, 1) => false

Правило из условия переводится в код дословно.

function isLeapYear(date) {
  const year = date.getFullYear();
  return (year % 4 === 0 && year % 100 !== 0) || year % 400 === 0;
}

Альтернатива без формулы — спросить у Date, есть ли 29 февраля: new Date(year, 1, 29).getDate() === 29. 1900 год не високосный (делится на 100), 2000 — високосный (делится на 400).
