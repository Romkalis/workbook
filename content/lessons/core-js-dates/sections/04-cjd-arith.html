Арифметика дат

4. getNextFriday — следующая пятница

Date('2024-02-03T00:00:00Z') => Date('2024-02-09T00:00:00Z')
Date('2024-02-16T00:00:00Z') => Date('2024-02-23T00:00:00Z')  (из пятницы — следующая)

Пятница — день 5. Сколько дней до неё: (5 - день + 7) % 7. Ноль означает «сегодня пятница», а нужна следующая, поэтому ноль заменяем на 7.

function getNextFriday(date) {
  const result = new Date(date);
  const daysToFriday = (5 - result.getUTCDay() + 7) % 7 || 7;
  result.setUTCDate(result.getUTCDate() + daysToFriday);
  return result;
}

Копия new Date(date) обязательна: setUTCDate меняет объект на месте, и без копии функция испортила бы дату вызывающего. setUTCDate с числом больше дней в месяце сам переносит дату в следующий месяц.

5. getCountDaysInMonth — дней в месяце

1, 2024 => 31
2, 2024 => 29

Приём: день 0 следующего месяца — это последний день нужного. Месяц в задаче нумеруется с 1, а в Date с 0, поэтому month (с единицы) как раз указывает на следующий месяц.

function getCountDaysInMonth(month, year) {
  return new Date(Date.UTC(year, month, 0)).getUTCDate();
}

Високосность учитывается сама: в феврале 2024 года 29 дней, и никаких формул не нужно.

6. getCountDaysOnPeriod — дней в периоде включительно

'2024-02-01T00:00:00.000Z', '2024-02-12T00:00:00.000Z' => 12

Разница timestamp в днях плюс один, потому что оба конца входят.

function getCountDaysOnPeriod(dateStart, dateEnd) {
  const DAY = 24 * 60 * 60 * 1000;
  return Math.round((Date.parse(dateEnd) - Date.parse(dateStart)) / DAY) + 1;
}

Math.round вместо простого деления — защита от перехода на летнее время. В местном времени, где такой переход есть, между полуночами 1 и 15 марта не ровно 14 суток: в Лос-Анджелесе получается 13,958, потому что одни сутки длятся 23 часа. Строки здесь в UTC, и там переходов нет, но привычка округлять спасает в соседних задачах.

7. isDateInPeriod — дата внутри периода

'2024-02-02', { start: '2024-02-02', end: '2024-03-02' } => true

Сравниваем timestamp. Строки только с датой разбираются как UTC все одинаково, поэтому сравнение честное.

function isDateInPeriod(date, period) {
  const time = Date.parse(date);
  return Date.parse(period.start) <= time && time <= Date.parse(period.end);
}

Любопытно, что строки YYYY-MM-DD можно сравнивать и напрямую: '2024-02-02' <= '2024-02-10' — true, потому что ISO-формат идёт от старшего разряда к младшему и дополнен нулями. Но это работает только при одинаковом формате у всех трёх строк, а Date.parse надёжнее.

9. getCountWeekendsInMonth — выходные в месяце

5, 2022 => 9
1, 2024 => 8

Создаём массив дней месяца, для каждого берём день недели и считаем субботы (6) и воскресенья (0). Количество дней берём из функции задачи 5.

function getCountWeekendsInMonth(month, year) {
  const days = getCountDaysInMonth(month, year);
  return Array.from({ length: days }, (_, i) =>
    new Date(Date.UTC(year, month - 1, i + 1)).getUTCDay()
  ).filter((day) => day === 0 || day === 6).length;
}

Считаем в UTC, чтобы на результат не влиял пояс компьютера. Аналитическое решение без перебора возможно — по дню недели первого числа и длине месяца, — но 31 итерация ничего не стоит, а перебор очевидно правилен.
