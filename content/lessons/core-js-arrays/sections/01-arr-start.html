Задание и правила

core-js-arrays — набор из 33 функций, которые нужно реализовать в файле src/arrays-tasks.js. Цель — научиться работать с методами массивов. Условие каждой задачи — в комментарии над функцией, примеры — в разделе @example, а если формулировка непонятна, загляните в тесты: test/arrays-tests.js.

Как запустить и сдать

  1. Сделать форк репозитория на GitHub и склонировать свой форк.
  2. npm install — поставить зависимости (Mocha для тестов, ESLint с правилами airbnb и Prettier). Нужен Node.js, лучше 22-й версии: методы, которых нет в Node.js 22, проверяющая система не засчитает.
  3. В функции раскомментировать параметры, удалить строку throw new Error('Not implemented') и написать решение.
  4. npm test — сначала запускается линтер, потом тесты. Нерешённые задачи показываются как pending, решённые — зелёными.
  5. Закоммитить и запушить в свой форк, в RS App на странице сдачи выбрать задание и нажать Submit.
Ограничения, за которые снимают баллы
  • Любая ошибка или предупреждение ESLint — 0 баллов за всё задание. Перед сдачей запускайте npm run lint, автоисправление — npm run lint:fix (урок «Линтеры, форматтеры и Husky»). На Windows частая причина ошибок — переводы строк CRLF; README советует настроить Git на «Checkout as-is, commit as-is» и поставить плагин EditorConfig.
  • Циклы запрещены. Тест проверяет текст каждой функции и падает, если находит for (, while ( или .forEach(. Всё решается методами массивов.
  • Для части задач нужен конкретный метод. Тесты «optimal implementation» ищут в коде функции слово: from, indexOf, filter, map, reduce, every, some, splice, slice, concat, join, Set, fill, flat, flatMap. Решение, которое работает, но обходится без нужного метода, не пройдёт этот тест.
  • Каждый тест должен уложиться в 30 секунд.
  • Пул-реквест с ответами в оригинальный репозиторий открывать нельзя — только свой форк.
