Числовые задачи

Здесь пригодятся сортировка с компаратором и приёмы с map/filter.

23. generateOdds — первые нечётные числа

   generateOdds(0) => []
   generateOdds(1) => [ 1 ]
   generateOdds(2) => [ 1, 3 ]
   generateOdds(5) => [ 1, 3, 5, 7, 9 ]

n-е нечётное число (с нуля) — 2n + 1: 1, 3, 5, 7…

function generateOdds(len) {
  return Array.from({ length: len }, (_, i) => 2 * i + 1);
}

24. getIndicesOfOddNumbers — индексы нечётных

   getIndicesOfOddNumbers([1, 2, 3, 4, 5]) => [0, 2, 4]
   getIndicesOfOddNumbers([2, 4, 6, 8, 10]) => []
   getIndicesOfOddNumbers([11, 22, 33, 44, 55]) => [0, 2, 4]

Сначала map превращает каждый элемент в его индекс, если число нечётное, иначе в −1; затем filter убирает −1. Проверка n % 2 !== 0, а не === 1: у отрицательных нечётных остаток −1.

function getIndicesOfOddNumbers(numbers) {
  return numbers
    .map((n, index) => (n % 2 !== 0 ? index : -1))
    .filter((index) => index !== -1);
}

25. getHexRGBValues — числа в цвета #RRGGBB

   getHexRGBValues([ 0, 255, 16777215]) => [ '#000000', '#0000FF', '#FFFFFF' ]
   getHexRGBValues([]) => []

toString(16) переводит число в шестнадцатеричную запись: 255 → «ff». toUpperCase даёт «FF», а padStart(6, '0') дополняет нулями слева до шести символов: «0000FF». Без padStart 0 превратился бы в «#0».

function getHexRGBValues(arr) {
  return arr.map((n) => `#${n.toString(16).toUpperCase().padStart(6, '0')}`);
}

26. getMaxItems — n наибольших

  getMaxItems([], 5) => []
  getMaxItems([ 1, 2 ], 1) => [ 2]
  getMaxItems([ 2, 3, 1 ], 2) => [ 3, 2]
  getMaxItems([ 10, 2, 7, 5, 3, -5 ], 3) => [ 10, 7, 5 ]
  getMaxItems([ 10, 10, 10, 10 ], 3) => [ 10, 10, 10 ]

Сортируем по убыванию и берём первые n. Два важных момента. 1) Без компаратора sort сравнивает элементы как строки, и 10 окажется меньше 2. Компаратор — функция сравнения двух элементов: отрицательный результат ставит a раньше, положительный — позже. (a, b) => b - a даёт убывание. 2) sort меняет массив на месте, поэтому сортируем копию [...arr]. В Node.js 20+ есть arr.toSorted(...), который сразу возвращает копию.

function getMaxItems(arr, n) {
  return [...arr].sort((a, b) => b - a).slice(0, n);
}

27. findCommonElements — общие элементы

   findCommonElements([1, 2, 3], [2, 3, 4]) => [ 2, 3 ]
   findCommonElements(['a', 'b', 'c'], ['b', 'c', 'd']) => [ 'b', 'c' ]
   findCommonElements([1, 2, 3], ['a', 'b', 'c']) => []

Оставляем элементы первого массива, которые есть во втором. includes внутри filter — это O(n·m); для больших массивов быстрее заранее сделать new Set(arr2) и проверять set.has(item).

function findCommonElements(arr1, arr2) {
  return arr1.filter((item) => arr2.includes(item));
}

28. findLongestIncreasingSubsequence — самая длинная возрастающая серия

   findLongestIncreasingSubsequence([10, 22, 9, 33, 21, 50, 41, 60, 80]) => longest is [41, 60, 80] => 3
   findLongestIncreasingSubsequence([3, 10, 2, 1, 20]) => longest is [3, 10] and [1, 20] => 2
   findLongestIncreasingSubsequence([50, 3, 10, 7, 40, 80]) => longest is [7, 40, 80] => 3

Название обманчиво: ищется не «подпоследовательность» из классической задачи, а непрерывный отрезок подряд идущих возрастающих чисел («uninterrupted»). Идём одним reduce и храним два числа: длину текущей серии и лучшую длину. Если число больше предыдущего — серия растёт, иначе начинается заново с 1. Циклы запрещены условием, поэтому состояние передаётся объектом-аккумулятором.

function findLongestIncreasingSubsequence(nums) {
  return nums.reduce(
    (acc, n, i) => {
      const current = i > 0 && n > nums[i - 1] ? acc.current + 1 : 1;
      return { current, best: Math.max(acc.best, current) };
    },
    { current: 0, best: 0 }
  ).best;
}
