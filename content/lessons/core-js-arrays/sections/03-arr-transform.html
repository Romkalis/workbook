Преобразование и проверки

Здесь работают «трансформирующие» методы: map (каждый элемент → новое значение), reduce (все элементы → одно значение), every и some (проверка условия для всех или хотя бы одного).

6. getStringsLength — длины строк

   getStringsLength([ '', 'a', 'bc', 'def', 'ghij' ]) => [ 0, 1, 2, 3, 4 ]
   getStringsLength([ 'angular', 'react', 'ember' ]) => [ 7, 5, 5 ]

map заменяет каждую строку её длиной; длина нового массива та же.

function getStringsLength(arr) {
  return arr.map((str) => str.length);
}

7. getAverage — среднее с округлением

  getAverage([]) => 0
  getAverage([ 1, 2, 3 ]) => 2
  getAverage([ -1, 1, -1, 1 ]) => 0
  getAverage([ 1, 10, 100, 1000 ])  => 277,75
  getAverage([ 2, 3, 3 ])  => 2,67

Сумму считает reduce с начальным значением 0 — без него на пустом массиве была бы ошибка. Но пустой массив обрабатываем раньше: иначе получилось бы 0 / 0 = NaN, а нужно 0. toFixed(2) округляет до двух знаков, но возвращает строку '2.67', поэтому оборачиваем в Number. В условии написано «277,75» с запятой — это просто запись, ожидается число 277.75.

function getAverage(arr) {
  if (arr.length === 0) return 0;
  const sum = arr.reduce((acc, n) => acc + n, 0);
  return Number((sum / arr.length).toFixed(2));
}

8. isSameLength — одинаковой ли длины строки

   isSameLength(['orange', 'banana', 'cherry']) => true
   isSameLength(['cat', 'dog', 'elephant']) => false

every возвращает true, если условие верно для всех элементов. Сравниваем каждую строку с длиной первой. На пустом массиве every сразу даёт true («нет ни одного нарушителя»), и arr[0] даже не читается.

function isSameLength(arr) {
  return arr.every((str) => str.length === arr[0].length);
}

9. isValueEqualsIndex — есть ли значение, равное индексу

   isValueEqualsIndex([0, 1, 2, 3, 4]) => true
   isValueEqualsIndex([2, 1, 0, 4, 5]) => true
   isValueEqualsIndex([10, 20, 30, 40, 50]) => false

some останавливается на первом элементе, для которого условие верно. Колбэк получает и значение, и индекс — их и сравниваем.

function isValueEqualsIndex(arr) {
  return arr.some((value, index) => value === index);
}

10. calculateBalance — итоговый баланс

  calculateBalance([ [ 10, 8 ], [ 5, 1 ] ]) => (10 - 8) + (5 - 1) = 2 + 4 = 6
  calculateBalance([ [ 10, 8 ], [ 1, 5 ] ])  => (10 - 8) + (1 - 5) = 2 + -4 = -2
  calculateBalance([]) => 0

Каждый элемент — пара [доход, расход]. Деструктуризация в параметрах колбэка ([income, expense]) сразу раскладывает пару на две переменные, а reduce копит разницу. Начальное значение 0 даёт правильный ответ для пустого массива.

function calculateBalance(arr) {
  return arr.reduce(
    (balance, [income, expense]) => balance + income - expense,
    0
  );
}

11. getFalsyValuesCount — сколько ложных значений

 getFalsyValuesCount([]) => 0
 getFalsyValuesCount([ 1, '', 3 ]) => 1
 getFalsyValuesCount([ -1, 'false', null, 0 ]) => 2
 getFalsyValuesCount([ null, undefined, NaN, false, 0, '' ]) => 6

Обратная задача к removeFalsyValues: оставляем элементы, для которых !value истинно, и берём длину.

function getFalsyValuesCount(arr) {
  return arr.filter((value) => !value).length;
}
