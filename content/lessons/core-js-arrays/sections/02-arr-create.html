Создание массивов и поиск

Первая группа — создать массив нужной длины и найти в нём элемент. Главный инструмент — Array.from: он создаёт массив из «похожего на массив» объекта и сразу пропускает каждый элемент через функцию.

1. getIntervalArray — числа от start до end

   getIntervalArray(1, 5)  => [ 1, 2, 3, 4, 5 ]
   getIntervalArray(-2, 2)  => [ -2, -1, 0, 1, 2 ]
   getIntervalArray(0, 100) => [ 0, 1, 2, ..., 100 ]
   getIntervalArray(3, 3) => [ 3 ]

Длина интервала включительно — end - start + 1. Array.from({ length }) создаёт массив такой длины, а второй аргумент получает индекс i и превращает его в число start + i. Объект { length: 5 } — «похожий на массив»: у него есть длина, но нет элементов, поэтому первый параметр функции (значение) не нужен, его называют _. Тест «оптимальной реализации» проверяет, что в коде есть from.

function getIntervalArray(start, end) {
  return Array.from({ length: end - start + 1 }, (_, i) => start + i);
}

2. sumArrays — поэлементная сумма двух массивов

   sumArrays([1, 2, 3], [4, 5, 6]) => [5, 7, 9]
   sumArrays([10, 20, 30], [5, 10, 15]) => [15, 30, 45]
   sumArrays([-1, 0, 1], [1, 2, 3, 4]) => [0, 2, 4, 4]

Массивы бывают разной длины, поэтому длина результата — большая из двух. Когда в коротком массиве элемента нет, arr[i] даёт undefined, и оператор ?? подставляет 0. ?? заменяет только null и undefined, а настоящий 0 оставляет как есть — в отличие от ||, который здесь тоже сработал бы, но в других задачах заменил бы и 0.

function sumArrays(arr1, arr2) {
  const length = Math.max(arr1.length, arr2.length);
  return Array.from({ length }, (_, i) => (arr1[i] ?? 0) + (arr2[i] ?? 0));
}

3. findElement — индекс элемента

   findElement(['Ace', 10, true], 10) => 1
   findElement(['Array', 'Number', 'string'], 'Date') => -1
   findElement([0, 1, 2, 3, 4, 5], 5) => 5

Ровно то, что делает indexOf: возвращает индекс первого совпадения или −1. Сравнение строгое (===), поэтому 10 и '10' — разные значения.

function findElement(arr, value) {
  return arr.indexOf(value);
}

4. findAllOccurrences — сколько раз встречается

   findAllOccurrences([ 0, 0, 1, 1, 1, 2 ], 1) => 3
   findAllOccurrences([ 1, 2, 3, 4, 5 ], 0) => 0
   findAllOccurrences([ 'a','b','c','c' ], 'c') => 2
   findAllOccurrences([ null, undefined, null ], null) => 2
   findAllOccurrences([ true, 0, 1, 'true' ], true) => 1

filter оставляет только совпадающие элементы, длина результата — их число. Строгое сравнение важно: в примере [true, 0, 1, 'true'] с true совпадает только сам true. Альтернатива без лишнего массива — reduce со счётчиком.

function findAllOccurrences(arr, item) {
  return arr.filter((el) => el === item).length;
}

5. removeFalsyValues — убрать ложные значения

   removeFalsyValues([ 0, false, 'cat', NaN, true, '' ]) => [ 'cat', true ]
   removeFalsyValues([ 1, 2, 3, 4, 5, 'false' ]) => [ 1, 2, 3, 4, 5, 'false' ]
   removeFalsyValues([ false, 0, NaN, '', undefined ]) => [ ]

Ложные (falsy) значения — false, 0, '', null, undefined, NaN. filter(Boolean) передаёт каждый элемент в функцию Boolean, которая возвращает false ровно для них. Строка 'false' непустая, поэтому остаётся.

function removeFalsyValues(arr) {
  return arr.filter(Boolean);
}
