Условия

Первые задачи — на if, логические операторы и сравнения. В них нельзя пользоваться методами Math и Number там, где это оговорено, поэтому максимум, модуль числа и т. п. делаем сравнениями.

1. isPositive — положительное ли число

 10 => true
 0  => true
 -5 => false

Ноль по условию считается положительным, поэтому >=. Само сравнение уже даёт true или false — писать if (...) return true; else return false; не нужно.

function isPositive(number) {
  return number >= 0;
}

2. getMaxNumber — максимум из трёх без Math

 1, 2, 3       => 3
 -5, 0, 5      => 5
 -0.1, 0, 0.2  => 0.2

Считаем первое число максимумом и по очереди сравниваем с ним остальные. Тест проверяет, что в коде нет Math. и методов массивов, так что Math.max(a, b, c) не подходит.

function getMaxNumber(a, b, c) {
  let max = a;
  if (b > max) max = b;
  if (c > max) max = c;
  return max;
}

3. canQueenCaptureKing — бьёт ли ферзь короля

{x: 1, y: 1}, {x: 5, y: 5} => true
{x: 2, y: 1}, {x: 2, y: 8} => true
{x: 1, y: 1}, {x: 2, y: 8} => false
{x: 1, y: 1}, {x: 2, y: 8} => false

Ферзь ходит по вертикали, горизонтали и диагонали. Одна вертикаль — одинаковый x (dx === 0), одна горизонталь — одинаковый y. На одной диагонали разница по x равна разнице по y по модулю. Модуль без Math.abs получаем тернарным оператором: dx < 0 ? -dx : dx. Фигуры между ферзём и королём в задаче не учитываются.

function canQueenCaptureKing(queen, king) {
  const dx = queen.x - king.x;
  const dy = queen.y - king.y;
  const absX = dx < 0 ? -dx : dx;
  const absY = dy < 0 ? -dy : dy;
  return dx === 0 || dy === 0 || absX === absY;
}

4. isIsoscelesTriangle — равнобедренный ли треугольник

 1, 2, 3   => false
 3, 1, 2   => false
 2, 3, 2   => true
 3, 2, 2   => true
 2, 2, 3   => true
 2, 2, 5   => false
 3, 0, 3   => false

Две проверки. Сначала — существует ли треугольник вообще: стороны положительные, и каждая меньше суммы двух других (неравенство треугольника). Пример 2, 2, 5 — две стороны равны, но 2 + 2 < 5, такого треугольника нет. Затем — равны ли хотя бы две стороны.

function isIsoscelesTriangle(a, b, c) {
  if (a <= 0 || b <= 0 || c <= 0) return false;
  if (a + b <= c || a + c <= b || b + c <= a) return false;
  return a === b || b === c || a === c;
}
