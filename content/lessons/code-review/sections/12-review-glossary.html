Словарь

Pull request (PR)
Запрос на слияние ветки с описанием, diff и обсуждением. В GitLab это merge request.
Diff
Список изменённых строк между двумя версиями кода.
Approve
Решение рецензента: изменение можно сливать.
Request changes
Решение рецензента: без правок сливать нельзя.
Nit (nitpick)
Мелкое необязательное замечание. Помечается, чтобы автор не принял его за блокирующее.
Code smell
Признак кода, который будет трудно менять. Сам по себе не ошибка.
Линтер
Программа, которая находит подозрительные конструкции и нарушения правил, например ESLint.
Форматтер
Программа, которая приводит оформление к единому виду, например Prettier.
CI
Автоматический запуск сборки, линтера и тестов на каждый PR.
Ломающее изменение
Правка публичной части, после которой существующий код или данные перестают работать.
LGTM
«Looks good to me»: короткое одобрение. Без пояснений мало помогает автору.
