Источники и границы разбора

Проверено 2–3 ноября 2026 года. Программа и задание прочитаны через raw.githubusercontent.com: обычные страницы GitHub отдавали оболочку без текста файла.

  • RS School: Code Review — цели и состав модуля.
  • RS School: задание — Movie App, ветка, PR и порядок сдачи. Файл критериев не удалось прочитать; баллы не пересказываются.
  • Google: что искать — замысел, поведение, сложность и тесты; как писать комментарии — уважение и объяснение причин.
  • Google: небольшие изменения — законченный объём и связанные тесты.
  • GitHub: решения ревью — Comment, Approve, Request changes и правила доступа.
  • Gunnar Morling: The Code Review Pyramid — слои и вопросы взяты из SVG-версии схемы (CC BY-SA 4.0).
  • SmartBear: Best Practices for Peer Code Review — объём, темп, виды ревью; цифры из исследования компании на Cisco.
  • Michael Lynch: How to Do Code Reviews Like a Human — приёмы формулировок и темп. Вторая часть статьи не разбиралась.
  • Michaela Greiler: Code Review Best Practices — практики автора и рецензента, число рецензентов, предвзятость.
  • Atlassian: What are code reviews — разобрана 9 ноября 2026 года: пять шагов процесса, общие критерии (включая обработку ошибок и наблюдаемость), два одобрения, автоматизация до ревью.
  • Software Testing Help: Code Review Tools — разобрана 9 ноября 2026 года: четыре способа ревью, Gerrit, режимы Phabricator. Это рекламный обзор, сведения о судьбе инструментов — из общих знаний.

Не удалось разобрать: roadmap.sh (страница собирается скриптом и отдаёт только навигацию), страницу GitHub Code Review и видеолекцию. Списки запахов кода, фронтенд-примеры, сценарии и чек-листы — авторское объяснение из общих знаний. Все примеры JavaScript выполнены в Node.js 22, включая намеренно ошибочную версию; время в примере с Set — один замер на одной машине.
