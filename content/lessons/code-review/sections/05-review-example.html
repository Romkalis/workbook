Разбор: скидка в корзине

Из общих знаний: рассмотрим авторский пример. Требование: функция получает массив товаров с ценой в целых денежных единицах и процент скидки от 0 до 100 включительно. Она возвращает новую корзину, не меняя исходную; дробные результаты округляет вниз. Для нечисловой, бесконечной или выходящей за диапазон скидки бросает ошибку.

Сначала найдите наблюдаемую ошибку

Ниже намеренно ошибочная версия. Запускайте на копии учебных данных: она меняет переданные товары. Задача — связать замечание с требованием и воспроизводимым случаем.

function applyDiscount(cart, percent) {
  return cart.map(item => {
    item.price = Math.floor(item.price * (1 - percent / 100));
    return item;
  });
}
const cart = [{ name: 'Книга', price: 100 }];
const discounted = applyDiscount(cart, 10);
console.log(cart[0].price); // 90: исходная корзина изменилась
console.log(discounted[0] === cart[0]); // true

Здесь две независимые проблемы: map создаёт новый массив, но callback меняет исходные объекты; процент не проверяется. Например, 150 превращает цену в отрицательную. Оба замечания можно подтвердить входом и результатом.

Замечание, с которым можно работать

Нужно исправить: мутация корзины

При cart = [{ price: 100 }] после applyDiscount(cart, 10) исходная цена становится 90, хотя по контракту корзина должна сохраняться. Создай новый объект товара при расчёте и добавь проверку исходной цены после вызова. Иначе повторное применение скидки будет считать уже от уменьшенной суммы.

Отдельный комментарий: «При percent = 150 получаем отрицательную цену. По требованиям разрешён диапазон 0…100; добавь валидацию и проверки обеих границ и неверного ввода». Разделение замечаний упрощает обсуждение и повторную проверку.

Исправленная версия и её границы

function applyDiscount(cart, percent) {
  if (!Number.isFinite(percent) || percent < 0 || percent > 100) {
    throw new RangeError('Скидка должна быть числом от 0 до 100');
  }
  return cart.map(item => ({
    ...item,
    price: Math.floor(item.price * (1 - percent / 100))
  }));
}
const cart = [{ name: 'Книга', price: 100 }];
const discounted = applyDiscount(cart, 10);
console.log(discounted[0].price); // 90
console.log(cart[0].price); // 100
console.log(discounted[0] === cart[0]); // false

Копия объекта поверхностная: вложенные объекты остаются общими, но функция их не меняет. Цены и форма товаров считаются уже проверенными входными данными. Правила денег, округления и допустимых значений в реальном проекте нужно согласовать отдельно; это не универсальный финансовый расчёт.
