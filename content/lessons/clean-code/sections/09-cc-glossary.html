Словарь

DRY
Don't Repeat Yourself: каждое знание в системе записано в одном месте.
KISS
Keep It Simple, Stupid: из рабочих решений выбирайте самое простое.
YAGNI
You Aren't Gonna Need It: не делайте функциональность, о которой пока не просили.
Самодокументируемый код
Код, который понятен по именам и структуре без комментариев.
Рефакторинг
Изменение структуры кода без изменения поведения.
Style guide
Свод правил оформления, принятый в проекте или команде.
Conventional Commits
Формат сообщений коммита тип(область): описание.
БЭМ
Блок, Элемент, Модификатор: соглашение об именах CSS-классов.
Семантическая разметка
Теги по назначению: заголовок — h1–h6, ссылка — a, действие — button.
Линтер
Программа, находящая ошибки и нарушения правил в коде.
Форматтер
Программа, приводящая оформление кода к единому виду.
Trailing whitespace
Пробелы в конце строки: невидимы, но попадают в diff.
