HTML и CSS: начальный уровень гайда

Это правила, по которым проверяют задание S1E1: за каждое из 15 обязательных пунктов даётся 2 балла, если правило применено во всём проекте, а не в одном файле. Номера совпадают с файлом html-and-css.md, по ним удобно называть коммиты.

№ПравилоПлохо → хорошо
1.1Отступ — два пробела, без табов и без смешиваниятаб → ␣␣
1.2Всё в нижнем регистре: теги, атрибуты, значения, селекторы, свойства, цвета. Исключение — <!DOCTYPE html><HEAD>, #E5E5E5 → <head>, #e5e5e5
1.3Двойные кавычки в атрибутах HTML и значениях CSSclass='edit' → class="edit"
2.1Каждый блочный элемент, элемент списка и таблицы — с новой строки, вложенные — с отступом<ul><li>…</li></ul> в одну строку → лесенкой
2.2HTML5: первая строка <!DOCTYPE html>нет doctype → есть
2.3Не использовать именованные символы, кроме служебных (&lt;, &amp;, &nbsp;)&quest; → ?
2.4Без атрибута type у подключаемых CSS и JStype="text/css" → убрать
2.5Переносить длинные строки (необязательное правило)много атрибутов → по одному на строку
3.1Один стиль имён селекторов на проект: слова через дефис в нижнем регистре или БЭМ.more_inf, .demoimage → .more-info
3.2Имя по смыслу, а не по виду и не шифр.aaa, .button-green → .matrix, .button-primary
3.3Имя настолько короткое, насколько возможно, но понятное.centered-main-page-element → .main
3.4Не использовать селекторы тегов, кроме сброса стилейul#example, div.error → #example, .error
3.5Отступ внутри любых фигурных скобок, включая @mediaправило в @media без отступа → с отступом
3.6Один пробел после двоеточия, ни одного передfont-size :16px → font-size: 16px
3.7Точка с запятой после каждого свойства, включая последнееflex-grow: 1 → flex-grow: 1;
3.8Каждый селектор и каждое свойство — с новой строки.aaa { text-align: center; } в одну строку → разнести

Примеры в правом столбце, кроме общих, взяты из самого приложения задания: в нём нарушены почти все правила.

Где гайд спорный — из общих знаний

  • 3.4, «селекторы тегов медленнее». Гайд ссылается на статью Стива Саудерса 2009 года. Для современных браузеров разница в скорости ничтожна. Настоящая причина избегать тегов в селекторах — в том же правиле: заменили div на section, и стили отвалились. Ради баллов правило соблюдайте, но объясняйте его этой причиной.
  • 2.3, пример с евро. В гайде как «плохой» пример написано &eur;, но такой сущности нет, правильно &euro;. Сама идея верная: в UTF-8 символ можно писать напрямую.
  • 3.3, #navigation → #nav. Короче не всегда понятнее. nav — общепринятое сокращение, а вот .btn-prm вместо .button-primary уже шифр. Правило 3.2 (смысл) важнее правила 3.3 (краткость).
  • 1.1 и 1.3 — вкусовые соглашения. В другой команде будут четыре пробела или одинарные кавычки в JS. Важно не какое правило, а что оно одно на весь проект.
