Коммиты и pull request

Один коммит — одно законченное изменение

Коммит содержит одно из трёх: законченную функциональность или документацию, законченное исправление ошибки или законченный рефакторинг. Проверка простая: изменения коммита описываются одним предложением с одним сказуемым. Если в описании появилось «и», скорее всего, это два коммита.

Зачем это нужно. Ментор просматривает список коммитов и проверяет логику каждого отдельно, а не всё приложение разом. Если один коммит оказался ошибочным, его можно откатить (git revert), не задев остальное.

Сообщение коммита: Conventional Commits

Формат тип: описание, на английском, в повелительном наклонении и настоящем времени: add feature, а не added feature или adds feature. Удобная проверка: сообщение должно продолжать фразу «If applied, this commit will…».

ТипКогдаПример
initначало проекта или заданияinit: start clean-code task
featновая функциональностьfeat: add search box
fixисправление ошибкиfix: adjust social links for mobile
refactorструктура, форматирование, переименования без изменения поведенияrefactor: rename vars for better readability
docsREADME и документацияdocs: update readme

Тип init — соглашение RS School. В самой спецификации Conventional Commits обязательны только feat и fix, остальные типы команда выбирает сама. Часто встречаются ещё style, test, chore (из общих знаний).

У типа может быть область в скобках: fix(basic-2.2): add html5 doctype. В задании S1E1 так указывают номер правила гайда.

Описание pull request

PR — место для обсуждения кода, а не монолог студента или ментора. В описании RS School ждёт:

  1. ссылку на задание;
  2. скриншот результата, вставленный картинкой;
  3. ссылку на задеплоенную версию (gh-pages или Netlify; имя сайта на Netlify — логин-github-название-задания);
  4. дату выполнения и дедлайн;
  5. самооценку с баллами по пунктам критериев;
  6. желательно — ссылку на видео самопроверки.

В PR не должно быть закомментированного кода, лишних и сгенерированных файлов, папки node_modules. Для этого есть .gitignore.
