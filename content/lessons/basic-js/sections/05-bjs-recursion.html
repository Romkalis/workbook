Рекурсия и формулы

Рекурсия — это когда функция решает задачу, вызывая саму себя для задачи поменьше. В любой рекурсивной функции есть две части. Базовый случай — такой маленький вход, что ответ известен сразу. Рекурсивный шаг — свести вход к меньшему и вызвать себя. Если базового случая нет или шаг не уменьшает задачу, вызовы не кончатся, и движок упадёт с RangeError: Maximum call stack size exceeded.

Пример: сумма во вложенных массивах

Это не задача из basic-js, но приём тот же, что в recursive-depth. Массив может содержать числа и другие массивы, сколько угодно вложенных. Цикл не знает заранее, сколько уровней вложенности будет, а рекурсия знает: встретили массив — передаём его самой себе.

function sumNested(items) {
  let total = 0;
  for (const item of items) {
    total += Array.isArray(item) ? sumNested(item) : item;
  }
  return total;
}
console.log(sumNested([1, [2, [3, 4]], 5])); // 15

recursive-depth: важна мелочь с this

Глубина плоского массива — 1, пустого тоже 1, у [[[]]] — 3. Значит, глубина массива — это 1 плюс наибольшая глубина среди вложенных массивов (или просто 1, если их нет). Задание требует решить это рекурсивно. Метод живёт в классе, поэтому вызывать себя он должен как this.calculateDepth(...): просто calculateDepth внутри класса не определено. Тесты вызывают метод через bind (он создаёт копию функции с намертво привязанным this), так что this указывает на экземпляр — объект depthCalculator, который экспортирует файл. В тестах есть массивы глубиной 10 и смесь глубоких и пустых вложений, поэтому убедитесь, что пустой вложенный массив тоже добавляет уровень.

hanoi-tower: откуда формула

Решать головоломку не нужно, нужно посчитать минимальное число ходов. Рассуждение рекурсивное. Чтобы перенести башню из n дисков, надо: перенести верхние n − 1 дисков на вспомогательный стержень, переложить самый большой диск, затем снова перенести n − 1 дисков сверху на него. Ходов получается H(n) = H(n − 1) + 1 + H(n − 1).

Вторая половина задачи — перевести ходы в секунды. Скорость дана в ходах в час, а в часе 3600 секунд. Округление — вниз (Math.floor), как сказано в README. Пример из README позволяет проверить себя: 9 дисков и 4308 ходов в час дают 511 ходов и 427 секунд.

carbon-dating и sum-digits: формулы

В carbon-dating формула дана по ссылке в README: возраст = ln(современная активность / активность образца) / (0,693 / период полураспада). Число 0,693 — приближение натурального логарифма двух, ln 2. В JavaScript натуральный логарифм — Math.log. Результат округляется вверх (Math.ceil). README предупреждает, что ответ может немного отличаться: 22387 или 22392 в зависимости от того, взяли вы точный Math.LN2 или 0,693. Тесты принимают оба варианта.

В sum-digits цифры числа складываются, пока не останется одна цифра: 91 → 10 → 1. Здесь естественна та же рекурсия: базовый случай — число меньше 10, иначе сложить цифры и вызвать себя для суммы.
