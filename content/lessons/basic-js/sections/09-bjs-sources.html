  • AlreadyBored/basic-js — README, заготовки в src/, тесты в test/ и package.json прочитаны по клону репозитория. Все ловушки в уроке (пробелы в carbon-dating, поддельные даты, null в repeater, позиции и сброс в chain maker, адрес с двумя @) взяты из файлов тестов.

Урок сознательно не содержит решений задач. Все примеры кода решают соседние задачи (сумма во вложенных массивах, счётчик с цепочкой, сдвиг одной буквы) и выполнены в Node.js 22. Объяснение внутреннего слота даты и неустойчивости приведения строк к числу — из общих знаний, поведение проверено в Node.js 22. Тесты репозитория целиком не запускались: для этого нужны решения.
