Chain maker: цепочка вызовов

Цепочка вызовов (method chaining) — это когда методы пишут подряд через точку: chainMaker.addLink(1).addLink(2).finishChain(). Это работает, если метод возвращает тот самый объект, у которого его вызвали. Тогда следующий .addLink вызывается снова у него.

const counter = {
  value: 0,
  add(n) {
    this.value += n;
    return this; // вернуть сам объект — и можно продолжить цепочку
  },
};
console.log(counter.add(2).add(3).value); // 5

В задании chainMaker — обычный объект, а не класс. Цепочечными должны быть addLink, removeLink, reverseChain. getLength и finishChain возвращают число и строку, поэтому цепочку заканчивают.

Одно состояние на все тесты

Из этого следует главная ловушка. chainMaker существует в одном экземпляре, и все тесты пользуются им по очереди. Звенья, оставшиеся от прошлой цепочки, испортят следующую. README поэтому требует очищать цепочку в двух случаях: после finishChain и после ошибки в removeLink.

Позиции считаются с единицы

В примере README addLink(1).addLink(2).removeLink(1) оставляет звено 2. Значит, removeLink(1) удаляет первое звено, а не второе: позиции идут с 1, как у людей, а не с 0, как у индексов массива. Отсюда же правила для неверной позиции: 0, отрицательные, дробные, нечисловые ('2nd') и большие длины цепочки должны бросать Error с текстом You can't remove incorrect link!. Все эти варианты есть в тестах.

Формат звена — значение в круглых скобках с пробелами: '( 1 )', звенья соединены '~~'. addLink() без аргумента добавляет пустое звено '( )' с двумя пробелами. Значение в звене — строковое представление, поэтому addLink(null) даёт '( null )'.
