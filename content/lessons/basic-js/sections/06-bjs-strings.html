Строки

Больше половины задач — про строки. Общее правило: строки в JavaScript неизменяемы, любая «правка» создаёт новую строку. Поэтому длинный результат удобно собирать в массив частей и в конце склеивать через join.

extended-repeater: значения по умолчанию и null

Функция собирает строку из повторов: str плюс добавка addition, повторённая additionRepeatTimes раз через additionSeparator, и всё это ещё repeatTimes раз через separator. Сначала соберите один кусок (строка плюс добавки), потом повторите его. Array(n).fill(x).join(sep) даёт n копий через разделитель без лишнего разделителя в конце. Если число повторов не задано, README велит не повторять: строка (или добавка) входит в результат один раз.

Ловушка в значениях по умолчанию. Разделители по умолчанию '+' и '|', а вот добавка может прийти как null или false, и тесты ждут их в строке: 'null', 'false'.

const options = { addition: null };
console.log(options.addition ?? ''); // '' — null считается «нет значения», добавка потеряна
console.log(options.addition !== undefined); // true — значение передано, пусть и null
console.log(String(null), String(false)); // null false

Оператор ?? подставляет значение по умолчанию и для undefined, и для null. Здесь это неверно: null — переданное значение, а не пропуск. Проверяйте именно !== undefined (или 'addition' in options). Ещё хуже вариант options.addition || '': он потеряет и false, и 0, и пустую строку. Для превращения в строку используйте String(x) или шаблонную строку. В тестах есть объект со своим правилом приведения (Symbol.toPrimitive), и оба способа обработают его так, как ожидает тест.

vigenere-cipher: сдвиг по алфавиту

Шифр Виженера сдвигает каждую букву сообщения на номер соответствующей буквы ключа: A — сдвиг 0, B — 1, …, Z — 25. Ключ повторяется по кругу. После Z алфавит начинается снова с A — это остаток от деления на 26.

const A = 'A'.charCodeAt(0); // 65
function shiftLetter(letter, keyLetter) {
  const shift = keyLetter.charCodeAt(0) - A;
  return String.fromCharCode(((letter.charCodeAt(0) - A + shift) % 26) + A);
}
console.log(shiftLetter('T', 'L')); // E — 19 + 11 = 30, 30 % 26 = 4
console.log(shiftLetter('Z', 'C')); // B — после Z снова A

Остальные требования README: работать только с латиницей (другие символы оставлять как есть), возвращать заглавные буквы, бросать Error('Incorrect arguments!'), если нет сообщения или ключа. Обратная машина (new VigenereCipheringMachine(false)) делает то же самое, но разворачивает результат. Для расшифровки сдвиг вычитается. Остаток от отрицательного числа в JavaScript тоже отрицательный: -3 % 26 равно -3. Чтобы получить позицию в алфавите, добавьте 26: ((x % 26) + 26) % 26.

Короткие задачи (ST) на строки

encode-line
Сжатие повторов: 'aabbbc' → '2a3bc'. Идите по строке и считайте, сколько раз подряд повторился символ; единицу не пишут. Регулярное выражение /(.)\1*/g сразу режет строку на такие группы: (.) запоминает любой символ, \1* — сколько угодно его повторов подряд, флаг g ищет все такие куски. 'aaabcc'.match(/(.)\1*/g) даёт ['aaa', 'b', 'cc'].
common-character-count
Общие символы с учётом количества: у 'aabcc' и 'adcaa' общие две a и одна c — 3. Посчитайте символы одной строки в Map или объекте и «расходуйте» их, проходя по второй.
delete-digit
Удалить ровно одну цифру, чтобы число стало наибольшим. Цифр мало, поэтому можно честно перебрать все варианты удаления через строку и взять максимум.
get-email-domain
Домен — всё после последнего @. В тестах есть адрес 'very.unusual.@.unusual.com@usual.com', где @ два. Для поиска последнего символа подходит lastIndexOf.
mac-address
Шесть групп по две шестнадцатеричные цифры (0–9, A–F) через дефис. Разбейте строку по '-' и проверьте количество групп и каждую группу, или опишите формат одним регулярным выражением.
file-names
Повтор имени получает суффикс (k) с наименьшим свободным k. Храните уже выданные имена в Set. Учтите, что имя с суффиксом само может совпасть с чьим-то исходным: отсюда 'file(1)(1)' в примере.
dns-stats
Для 'code.yandex.ru' засчитываются '.ru', '.ru.yandex', '.ru.yandex.code'. Разбейте домен по точкам, разверните и накапливайте префиксы, считая их в объекте.
sum-digits
