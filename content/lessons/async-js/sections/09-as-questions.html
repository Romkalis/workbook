Вопросы и словарь

Что выведет код: console.log(1); setTimeout(() => console.log(2)); Promise.resolve().then(() => console.log(3)); console.log(4)?

1, 4, 3, 2. Сначала весь синхронный код, затем реакции промисов (микрозадачи), затем таймер. Почему микрозадачи раньше таймеров — в уроке Event Loop & Animation.

Почему try { setTimeout(() => { throw err }) } catch {} не ловит ошибку?

Колбэк выполнится позже, когда try уже давно закончился. Ловить нужно внутри колбэка или перейти на промисы.

Чем then(ok).catch(fail) отличается от then(ok, fail)?

Во втором варианте fail не поймает ошибку, брошенную в ok.

Что вернёт async function f() { return 5 }?

Промис, выполненный значением 5, а не число.

Отменяет ли Promise.race проигравшие операции?

Нет. Он только перестаёт ждать их результат. Сами запросы продолжатся, пока их не отменит AbortController.

Асинхронность
выполнение долгой операции без блокировки потока; результат приходит позже через колбэк или промис.
Промис
объект-представитель будущего результата с состояниями pending, fulfilled, rejected.
Executor
функция, переданная в new Promise; выполняется синхронно при создании.
Микрозадача
задача из очереди реакций промисов; выполняется сразу после текущего синхронного кода, раньше таймеров.
Unhandled rejection
отклонённый промис, у которого нет обработчика.
