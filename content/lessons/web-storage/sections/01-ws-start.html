Где браузер хранит данные

Переменные JavaScript живут, пока открыта страница: перезагрузка — и всё пропало. Чтобы сохранить корзину, тему оформления, черновик формы или данные для работы без сети, есть четыре встроенных хранилища:

localStoragesessionStoragecookieIndexedDB

APIсинхронныйсинхронныйстрока document.cookieасинхронный, транзакции

Все хранилища привязаны к источнику (origin): схема + домен + порт. https://shop.example не видит данные https://example.com и даже http://shop.example. Точные лимиты объёма зависят от браузера, цифры в таблице — ориентир.

Пользователь может очистить любое хранилище, а в приватном режиме они удаляются при закрытии окна. Браузер хранит ваши данные из вежливости, а не по договору: важное должно жить на сервере.
