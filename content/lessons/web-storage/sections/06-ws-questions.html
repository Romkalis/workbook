Вопросы и словарь

Что вернёт localStorage.getItem('missing')?

null.

Сработает ли событие storage во вкладке, которая сделала setItem?

Нет, только в других вкладках того же источника.

Почему после document.cookie = 'a=1' остальные cookie не пропали?

Присваивание добавляет или обновляет одну cookie, а не заменяет строку целиком.

Как удалить cookie, поставленную с path=/app?

Записать её с max-age=0 и тем же path=/app.

Почему после await fetch внутри транзакции IndexedDB следующий запрос падает?

Транзакция закрылась, пока ждали сеть: она живёт, только пока в ней есть запросы.

Origin (источник)
схема, домен и порт; все хранилища разделены по источникам.
Квота
предел объёма хранилища для источника; при превышении запись бросает QuotaExceededError.
Object store
хранилище объектов в IndexedDB, аналог таблицы.
Транзакция
группа операций, которые выполняются целиком или откатываются целиком.
Индекс
структура для быстрого поиска по полю, которое не является ключом.
