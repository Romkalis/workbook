Stack: стек на массиве

Стек работает по правилу LIFO: последним пришёл — первым ушёл. Добавляем и забираем элементы с одного конца, «верхушки». У массива для этого уже есть быстрые методы: push и pop работают с концом за O(1), так что почти вся работа сделана за нас.

class Stack {
  #items = [];

  push(value) {
    this.#items.push(value);
  }

  pop() {
    return this.#items.pop();
  }

  peek() {
    return this.#items[this.#items.length - 1];
  }
}

module.exports = { Stack };
  • #items — приватное поле. Снаружи нельзя случайно вызвать stack.#items.shift() и нарушить правило LIFO.
  • pop() на пустом массиве возвращает undefined, а тест ровно этого и ждёт. Отдельная проверка не нужна.
  • peek() читает последний элемент и не удаляет его. На пустом стеке this.#items[-1] тоже даёт undefined. Можно написать this.#items.at(-1), результат тот же.

Не используйте unshift/shift для «верхушки» в начале массива. Работать будет, но каждая операция сдвигает все элементы, и вместо O(1) получается O(n).
