Remove from list: удалить все k

Дан односвязный список и число k. Нужно убрать все узлы со значением k и вернуть голову нового списка. Удалить узел из списка — значит перекинуть ссылку предыдущего узла через него: prev.next = prev.next.next.

Приём «фиктивная голова»

Сложный случай — когда k стоит в начале: у первого узла нет предыдущего, и голова меняется. Чтобы не писать для этого отдельную ветку, ставим перед списком фиктивный узел dummy. Теперь у каждого настоящего узла есть предыдущий, а ответ — dummy.next.

function removeKFromList(l, k) {
  const dummy = { value: null, next: l };
  let current = dummy;
  while (current.next) {
    if (current.next.value === k) {
      current.next = current.next.next;
    } else {
      current = current.next;
    }
  }
  return dummy.next;
}

module.exports = { removeKFromList };

Две частые ошибки: сдвигать current сразу после удаления (тогда пропускается второе k подряд) и возвращать l вместо dummy.next (тогда возвращается удалённая голова). Время O(n), дополнительная память O(1). Список меняется на месте; тесты это допускают.
