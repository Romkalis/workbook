Проблема: правда, размазанная по странице

В прошлых уроках мы меняли страницу точечно: добавили товар — вставили строку, удалили — убрали, изменили количество — переписали число и итог. Пока действий три, это работает. Когда их двадцать, появляется вопрос: где правда? В массиве корзины, в строках таблицы, в бейдже в шапке, в итоговой сумме? Каждое действие должно обновить все эти места, и одно из них однажды забудут. Пользователь увидит в шапке «3 товара», а в корзине — два.

Решение, на котором построены все современные фреймворки: состояние (state) хранится в одном месте в виде обычных данных, а экран вычисляется из него. Изменение — это новое состояние, после которого страница перерисовывается. Коротко: UI = render(state).

Слова урока

Состояние
Все данные, от которых зависит экран: товары, корзина, фильтры, «идёт загрузка».
render
Функция, которая по состоянию приводит DOM к нужному виду.
Стор (store)
Объект, который хранит состояние, меняет его и сообщает подписчикам об изменениях.
Производные данные
То, что вычисляется из состояния (сумма корзины, отфильтрованный список) и потому не хранится отдельно.

Задача 1. Перенесите правду из DOM в данные ★☆☆ разминка

Счётчик лайков ниже хранит число в тексте кнопки и читает его оттуда. Перепишите на состояние: число в переменной, функция render() пишет текст «♥ N» и класс liked, клик меняет состояние и вызывает render. Повторный клик снимает лайк.

button.addEventListener('click', () => {
  const n = Number(button.textContent!.replace('♥ ', ''));
  if (button.classList.contains('liked')) {
    button.textContent = `♥ ${n - 1}`;
    button.classList.remove('liked');
  } else {
    button.textContent = `♥ ${n + 1}`;
    button.classList.add('liked');
  }
});

Зачем: код, который читает данные с экрана, ломается от любой правки вёрстки: поменяли «♥» на иконку — счётчик превратился в NaN. Состояние в переменных не зависит от того, как его показывают.

Решение и разбор
// like.ts
export function mountLike(button: HTMLButtonElement, initialCount: number): void {
  const state = { count: initialCount, liked: false };

  const render = () => {
    button.textContent = `♥ ${state.count}`;
    button.classList.toggle('liked', state.liked);
    button.setAttribute('aria-pressed', String(state.liked));
  };

  button.addEventListener('click', () => {
    state.liked = !state.liked;
    state.count += state.liked ? 1 : -1;
    render();
  });
  render();
}

Обработчик меняет только данные, а render переводит их на экран: класс, текст и попутно aria-pressed, который сообщает программе чтения с экрана, нажата ли кнопка-переключатель. Новое отображение (иконка, анимация) правится только в render, а логика не меняется.
