Функция render

export interface CartLine {
  id: string;
  title: string;
  price: number;
  quantity: number;
}

export interface CartState {
  lines: CartLine[];
}

export const cartTotal = (state: CartState) => state.lines.reduce((s, l) => s + l.price * l.quantity, 0);

export function renderCart(root: HTMLElement, state: CartState): void {
  const list = document.createElement('ul');
  list.append(
    ...state.lines.map((line) => {
      const li = document.createElement('li');
      li.dataset.id = line.id;
      li.textContent = `${line.title} × ${line.quantity}`;
      return li;
    }),
  );
  const total = document.createElement('p');
  total.textContent = state.lines.length === 0 ? 'Корзина пуста' : `Итого: ${(cartTotal(state) / 100).toFixed(2)} ₽`;
  root.replaceChildren(list, total);
}

renderCart не знает, что произошло — добавили товар или удалили. Она знает только, каким должен быть экран при таком состоянии. Поэтому в ней нет веток «если добавили, то...», и разойтись список и итог не могут: оба нарисованы из одних данных.

Полная перерисовка — самый простой вариант. Её цена: потеря фокуса и введённого текста внутри перерисованного блока и лишняя работа на больших списках. Когда это мешает, перерисовывают точечно или переиспользуют элементы по ключу, как в задаче «Обновить список, сохранив карточки». Именно это за вас делают виртуальный DOM React и шаблоны Vue.

Задача 2. render для списка задач ★☆☆ разминка

Напишите renderTodos(root, state) для состояния { todos: { id, title, done }[], filter: 'all' | 'active' | 'done' }. Рисует ul с видимыми по фильтру задачами (выполненные с классом done), а под ним строку «Осталось: N» — число невыполненных среди всех задач.

Зачем: render — чистое преобразование «данные → разметка». В нём не должно быть вопроса «что изменилось». Поэтому одна функция корректно рисует и первое открытие страницы, и любое следующее состояние.

Решение и разбор
// todos.ts
export interface Todo {
  id: string;
  title: string;
  done: boolean;
}
export interface TodoState {
  todos: Todo[];
  filter: 'all' | 'active' | 'done';
}

export const visibleTodos = (s: TodoState) =>
  s.filter === 'all' ? s.todos : s.todos.filter((t) => t.done === (s.filter === 'done'));

export function renderTodos(root: HTMLElement, state: TodoState): void {
  const list = document.createElement('ul');
  list.append(
    ...visibleTodos(state).map((t) => {
      const li = document.createElement('li');
      li.dataset.id = t.id;
      li.textContent = t.title;
      li.classList.toggle('done', t.done);
      return li;
    }),
  );
  const left = document.createElement('p');
  left.textContent = `Осталось: ${state.todos.filter((t) => !t.done).length}`;
  root.replaceChildren(list, left);
}

Фильтрация вынесена в селектор visibleTodos: это производные данные, и их удобно тестировать отдельно. Счётчик считается по всем задачам, а не по видимым, и это решение стоит записать в тест: при фильтре «выполненные» видно три задачи, а осталось две.
