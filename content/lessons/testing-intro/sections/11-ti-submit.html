Сдача задания

  1. Проверьте, что изменены только файлы в tests/catalog/ и src/cart.js: git status и git diff main --stat.
  2. Закоммитьте по конвенции, например: 
    git add tests/catalog
git commit -m "test: add tests for catalog functions"
git add src/cart.js
git commit -m "feat: implement cart functions"
git push -u origin testing-intro
  3. Запустите npm test и сделайте скриншот терминала со сводкой, где всё прошло.
  4. Запустите npm run test:coverage, откройте coverage/lcov-report/index.html и сделайте скриншот. Папку coverage/ коммитить не нужно — проверьте, что она в .gitignore.
  5. Откройте Pull Request из testing-intro в main своего форка (на GitHub при создании PR из форка по умолчанию выбирается исходный репозиторий (из общих знаний о GitHub) — поменяйте base repository на свой). Не мержите и не закрывайте его.
  6. Описание PR — по схеме RS School, плюс оба скриншота.
  7. В RS App → Cross-Check: Submit выберите Testing Intro, вставьте ссылку на PR в Solution URL и нажмите Submit. До дедлайна недели выдачи.

Деплой не нужен. На следующей неделе вы сами проверите чужие работы: склонировать, npm install, npm test, сверить Files changed с запретами и тесты каталога с таблицами задания.

Что дальше

Пройдите тест «[St2] Testing» в RS App → Auto Test. Затем переходите к уроку «Тестирование JavaScript»: асинхронные тесты, моки и подмены, параметризованные тесты, TDD на практике. Применить TDD самостоятельно предстоит в задании Bulls and Cows: там тесты нужно писать уже самим, раньше кода.
