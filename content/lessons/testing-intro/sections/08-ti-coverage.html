Покрытие кода (coverage)

Покрытие показывает, какие строки вашего кода хоть раз выполнились во время тестов. Jest считает его по флагу --coverage:

npx jest --coverage
# в задании для этого есть готовый скрипт:
npm run test:coverage

Jest напечатает таблицу в терминале и создаст папку coverage/. Откройте в браузере coverage/lcov-report/index.html: там список файлов, а внутри каждого — код с подсветкой. Зелёные строки выполнялись, красные — нет.

В таблице четыре колонки (из общих знаний о формате отчёта):

  • Statements — доля выполненных инструкций;
  • Branches — доля пройденных веток if/else, ? :, ||. Самая полезная колонка: показывает непроверенные условия;
  • Functions — доля вызванных функций;
  • Lines — доля выполненных строк.

100% покрытия не значит «без ошибок»

function calculateCartSubtotal(cart) {
  return cart.reduce((sum, item) => sum + item.price, 0); // забыли quantity!
}

test('считает сумму', () => {
  expect(calculateCartSubtotal([{ price: 100, quantity: 1 }])).toBe(100);
});

Покрытие 100%: каждая строка выполнилась. Но функция неправильная — количество не учитывается, а тест этого не заметил, потому что взял quantity: 1. Покрытие отвечает на вопрос «что выполнялось», а не «что проверено». Используйте его как подсказку, где тестов нет совсем, а не как цель.

В задании Testing Intro покрытие не влияет на оценку: нужен только скриншот отчёта в PR.
