Словарь

Автотест
Код, который вызывает проверяемый код с известными данными и сравнивает результат с ожидаемым.
Регрессия
Ошибка в том, что раньше работало, появившаяся после нового изменения.
assert
Проверка-утверждение: если условие ложно, тест падает.
actual / expected
Фактический результат (вернула функция) и ожидаемый (должен был получиться).
Тестовый фреймворк
Инструмент, который находит тесты, запускает их и показывает отчёт: Jest, Vitest, node:test.
describe / test (it)
Группа тестов и один тест в Jest.
Матчер
Метод после expect(...), задающий способ сравнения: toBe, toEqual, toThrow.
Глубокое сравнение
Сравнение объектов и массивов по содержимому, а не по ссылке (toEqual).
test.todo
Заметка о тесте, который ещё предстоит написать.
test.each
Запуск одного теста на нескольких наборах данных.
Граничный случай
Данные на краю допустимого: пусто, ноль, один, максимум.
AAA
Arrange — Act — Assert: подготовка, действие, проверка.
Модульный (unit) тест
Проверяет одну функцию или модуль отдельно.
Интеграционный тест
Проверяет совместную работу нескольких частей.
E2E-тест
Проходит сценарий пользователя в настоящем браузере.
Пирамида тестов
Совет: много модульных тестов, меньше интеграционных, мало E2E.
TDD
Разработка через тестирование: красный тест → код до зелёного → рефакторинг.
Рефакторинг
Улучшение кода без изменения поведения.
Заглушка
Временная реализация, которая ничего не делает или бросает ошибку.
Coverage (покрытие)
Доля кода, выполненного во время тестов.
dev-зависимость
Пакет, нужный только при разработке (npm install --save-dev).
Форк
Ваша копия чужого репозитория на GitHub.
