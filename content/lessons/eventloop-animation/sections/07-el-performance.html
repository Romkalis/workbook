Производительность и доступность анимации

Принудительная раскладка (layout thrashing)

Чтение геометрии (offsetHeight, getBoundingClientRect()) после записи стилей заставляет браузер посчитать раскладку прямо сейчас, синхронно. Если читать и писать по очереди в цикле, раскладка пересчитается на каждой итерации. Лечится группировкой: сначала все чтения, потом все записи.

// плохо: N пересчётов
for (const el of items) el.style.height = el.offsetHeight * 2 + 'px';
// хорошо: один пересчёт
const heights = items.map((el) => el.offsetHeight);
items.forEach((el, i) => (el.style.height = heights[i] * 2 + 'px'));

Задача 12. Сначала читаем, потом пишем ★★★ с подвохом

Функция выравнивает высоту карточек по самой высокой в каждой строке, но чередует чтение и запись. Перепишите так, чтобы все чтения offsetHeight шли до первой записи style.height. В тесте вместо DOM — объекты, которые записывают порядок операций.

interface Card { readonly offsetHeight: number; style: { height: string } }
export function equalize(rows: Card[][]) {
  for (const row of rows) {
    let max = 0;
    for (const c of row) max = Math.max(max, c.offsetHeight);
    for (const c of row) c.style.height = max + 'px';
  }
}

Зачем: здесь чтения и записи сгруппированы внутри строки, но строки идут по очереди: запись в первой строке и чтение во второй форсируют раскладку столько раз, сколько строк. Такая ошибка не видна при чтении кода, и найти её помогает правило «все чтения — до всех записей».

Решение и разбор
export interface Card {
  readonly offsetHeight: number;
  style: { height: string };
}

export function equalize(rows: Card[][]): void {
  const maxes = rows.map((row) => Math.max(0, ...row.map((c) => c.offsetHeight)));
  rows.forEach((row, i) => {
    for (const c of row) c.style.height = `${maxes[i]}px`;
  });
}

Первый проход только читает и сохраняет результаты, второй только пишет. Браузер посчитает раскладку один раз на первом чтении, а после записей — один раз перед отрисовкой. На самом деле эту задачу лучше решает CSS: grid или flex выравнивают высоту в строке без единой строчки JavaScript. Это хороший повод сначала спросить «а нужен ли тут JS».

will-change и слои

will-change: transform заранее просит браузер вынести элемент на отдельный слой. Это помогает, если анимация начинается рывком. Но каждый слой — это память видеокарты. Свойство ставят точечно, перед анимацией, а не на всё подряд.

Меньше движения

У части людей движение на экране вызывает головокружение и тошноту, поэтому в системе есть настройка «уменьшить движение». Сайт узнаёт о ней через медиазапрос prefers-reduced-motion: reduce: в CSS отключают или сокращают анимации, а в JavaScript проверяют matchMedia. Анимация не должна быть единственным носителем смысла: если сообщение появилось без движения, пользователь ничего не теряет.

@media (prefers-reduced-motion: reduce) {
  *, *::before, *::after { animation-duration: 0.01ms !important; transition-duration: 0.01ms !important; }
}

Задача 13. Анимация с уважением к настройке ★★☆ практика

Напишите motionDuration(ms, matchMedia = window.matchMedia): возвращает 0, если пользователь просил меньше движения, иначе ms. Затем scrollToTop(animateFn, setScroll, matchMedia): при нулевой длительности сразу ставит прокрутку в 0, без вызова анимации.

Зачем: CSS-медиазапрос не действует на анимации, которые делает JavaScript. Если забыть проверку в коде, настройка доступности работает наполовину: переходы в CSS отключены, а плавная прокрутка на JS по-прежнему укачивает.

Решение и разбор
type MatchMedia = (query: string) => { matches: boolean };

export function motionDuration(ms: number, matchMedia: MatchMedia = (q) => window.matchMedia(q)): number {
  return matchMedia('(prefers-reduced-motion: reduce)').matches ? 0 : ms;
}

export function scrollToTop(
  from: number,
  animateFn: (duration: number, draw: (p: number) => void) => void,
  setScroll: (y: number) => void,
  matchMedia?: MatchMedia,
): void {
  const duration = motionDuration(400, matchMedia);
  if (duration === 0) return setScroll(0);
  animateFn(duration, (p) => setScroll(Math.round(from * (1 - p))));
}

Тип MatchMedia описывает только то, что нужно, и в тесте подставляется заглушка. Значение по умолчанию — стрелка, а не window.matchMedia напрямую: обращение к window произойдёт только при вызове без параметра, и модуль можно импортировать в Node. Для прокрутки есть и встроенное window.scrollTo({ top: 0, behavior: 'smooth' }), но с ним проверка настройки ложится на вас: браузеры по-разному учитывают её для smooth (из общих знаний).
