Один поток и много дел

Движок JavaScript выполняет код в одном потоке. В браузере этот поток — главный: в нём же браузер считает стили, раскладку и отрисовку. Поэтому любая долгая функция замораживает не только скрипты, но и кнопки, прокрутку, анимацию. Три части системы:

  • Стек вызовов (call stack) — где сейчас выполняется код. Функция вызвана — кадр положили наверх, вернула значение — сняли.
  • Web API — то, что делает браузер, а не движок: таймеры, сеть, события DOM. Они работают параллельно с JavaScript, в других потоках браузера.
  • Очереди — когда Web API закончил работу (сработал таймер, пришёл ответ, пользователь кликнул), колбэк ставится в очередь и ждёт, пока стек опустеет.

Цикл событий (event loop) — правило, по которому движок берёт работу из очередей. Как главный поток делит время с отрисовкой, подробно разобрано в уроке Как работают браузеры; здесь — то, что нужно для собственного кода.
