CSS-анимация: переходы и ключевые кадры

transition: плавно из одного состояния в другое

transition анимирует изменение свойства между двумя значениями, например при наведении или смене класса. Указывают свойство, длительность, функцию времени и задержку:

.toast {
  transform: translateY(100%);
  opacity: 0;
  transition: transform 300ms ease-out, opacity 300ms ease-out;
}
.toast--visible {
  transform: translateY(0);
  opacity: 1;
}

JavaScript только переключает класс, а анимацию делает браузер. transition: all — плохая привычка: анимироваться начнут свойства, о которых вы не думали, в том числе дорогие.

Задача 5. Всплывающее уведомление ★☆☆ разминка

Сделайте уведомление, которое выезжает снизу и плавно появляется при добавлении класса toast--visible, а при удалении класса уезжает обратно. Анимируйте только дешёвые свойства. Для пользователей с настройкой «меньше движения» уберите сдвиг, но оставьте плавное появление. Напишите и функцию showToast(el, ms), которая показывает уведомление и прячет через ms миллисекунд.

Зачем: это самый частый вид анимации в интерфейсах. В нём сразу видны три навыка: анимация через класс, а не через стили из JS; только transform и opacity; бережное отношение к prefers-reduced-motion.

Решение и разбор
// toast.css
.toast {
  position: fixed;
  inset-inline: 1rem;
  bottom: 1rem;
  transform: translateY(calc(100% + 1rem));
  opacity: 0;
  transition: transform 250ms ease-out, opacity 250ms ease-out;
}
.toast--visible {
  transform: translateY(0);
  opacity: 1;
}
@media (prefers-reduced-motion: reduce) {
  .toast { transform: none; transition: opacity 150ms linear; }
}
// solution.ts
export function showToast(el: { classList: DOMTokenList }, ms = 3000): () => void {
  el.classList.add('toast--visible');
  const timer = setTimeout(() => el.classList.remove('toast--visible'), ms);
  return () => {
    clearTimeout(timer);
    el.classList.remove('toast--visible');
  };
}

JavaScript отвечает за состояние (показано или нет), а CSS — за движение. Поменять анимацию можно, не трогая код. Функция возвращает «закрыть сейчас» для кнопки-крестика, и таймер при этом отменяется. Для доступности у уведомления должна быть роль role="status": тогда экранная читалка произнесёт текст без движения.

animation и @keyframes: сценарий из нескольких шагов

Когда нужна анимация без смены состояния (индикатор загрузки, пульсация) или с промежуточными шагами, описывают ключевые кадры:

@keyframes spin {
  to { transform: rotate(1turn); }
}
.spinner { animation: spin 1s linear infinite; }

Основные свойства animation: имя, длительность, функция времени, задержка, число повторов (infinite), направление (alternate), fill-mode (оставить ли последний кадр после окончания). Событие animationend позволяет узнать в JavaScript, что анимация закончилась.

Задача 6. Индикатор загрузки ★☆☆ разминка

Сделайте круглый индикатор загрузки на @keyframes: бесконечное вращение за 0,8 с с равномерной скоростью. Добавьте разметку, понятную экранной читалке, и вариант для «меньше движения» (медленное мигание вместо вращения).

Зачем: бесконечная анимация — главный кандидат на раздражение и головокружение, поэтому именно на ней стоит отработать prefers-reduced-motion. Для незрячего пользователя крутящийся круг вообще ничего не значит, ему нужен текст.

Решение и разбор
// spinner.html
<div class="spinner" role="status">
  <span class="visually-hidden">Загрузка…</span>
</div>
// spinner.css
@keyframes spin { to { transform: rotate(1turn); } }
@keyframes pulse { 50% { opacity: 0.4; } }

.spinner {
  inline-size: 2rem;
  block-size: 2rem;
  border: 3px solid #ccc;
  border-block-start-color: #2563eb;
  border-radius: 50%;
  animation: spin 0.8s linear infinite;
}
@media (prefers-reduced-motion: reduce) {
  .spinner { animation: pulse 2s ease-in-out infinite; }
}

linear важен: с ease круг будет разгоняться и тормозить на каждом обороте. to без from означает «из текущего состояния», то есть из нуля. role="status" и скрытый текст сообщают читалке «идёт загрузка». Класс visually-hidden прячет текст с экрана, но оставляет его доступным (из общих знаний: стандартный набор свойств clip, position: absolute, размер 1 px).

transform: сдвиг, масштаб, поворот

transform меняет, как элемент нарисован, не меняя его места в раскладке: translate(x, y) сдвигает, scale(k) масштабирует, rotate(угол) поворачивает. Соседи об этом не узнают и не сдвинутся. Именно поэтому трансформации дешёвые.

Дешёвые и дорогие свойства

Изменение свойства запускает часть конвейера отрисовки (разбор стадий):

Что меняетсяСтадииПример
геометрияStyle → Layout → Paint → Compositewidth, height, top, left, margin, font-size
только видStyle → Paint → Compositecolor, background, box-shadow
слой целикомStyle → Compositetransform, opacity

Для плавной анимации анимируйте transform и opacity: их браузер может выполнить на отдельном слое, часто силами видеокарты, не пересчитывая раскладку. Сдвиг через left пересчитывает раскладку на каждом кадре. На слабом телефоне это рывки.

Задача 7. Перепишите дорогую анимацию ★★☆ практика

Боковое меню выезжает анимацией свойства left, а кнопка при наведении растёт через width и height. На телефоне всё дёргается. Перепишите на дешёвые свойства и объясните, какие стадии конвейера пропадут.

/* .menu { position: fixed; left: -300px; width: 300px; transition: left 300ms; }
   .menu--open { left: 0; }
   .btn { width: 120px; height: 40px; transition: width 200ms, height 200ms; }
   .btn:hover { width: 132px; height: 44px; } */

Зачем: left, width и height меняют геометрию: на каждом кадре браузер пересчитывает раскладку всей страницы и перерисовывает пиксели. Перевод на transform — самая выгодная оптимизация анимаций, и делается она за минуту.

Решение и разбор
// menu.css
.menu {
  position: fixed;
  inset-block: 0;
  left: 0;
  width: 300px;
  transform: translateX(-100%);
  transition: transform 300ms ease-out;
}
.menu--open { transform: translateX(0); }

.btn { transition: transform 200ms ease-out; }
.btn:hover { transform: scale(1.1); }

Было Style → Layout → Paint → Composite на каждом кадре, стало Style → Composite. translateX(-100%) считается от ширины самого элемента, так что «спрятать за край» работает для любой ширины меню. scale отличается от изменения размеров: текст внутри тоже масштабируется, а соседи не сдвигаются. Обычно это и нужно для эффекта наведения. Если элемент должен реально раздвинуть соседей, без раскладки не обойтись, и тогда стоит подумать, нужна ли анимация вообще.
