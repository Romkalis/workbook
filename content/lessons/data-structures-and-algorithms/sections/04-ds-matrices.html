Матрицы: строки и столбцы

Матрицу в JavaScript удобно представить массивом строк: matrix[row][col]. У массива массивов строки вообще могут иметь разную длину. Прямоугольность — условие задачи, а не свойство языка.

Обход по строкам и главная диагональ

В прямоугольнике r × c обработка каждой ячейки занимает Θ(r × c). В квадрате главная диагональ состоит из позиций, где row равен col: для её суммы нужен один цикл из n шагов.

function sumMatrix(matrix) {
  let sum = 0;
  for (const row of matrix) {
    for (const value of row) sum += value;
  }
  return sum;
}
function diagonalSum(square) {
  const n = square.length;
  if (!square.every(row => row.length === n)) {
    throw new Error('Нужна квадратная матрица');
  }
  let sum = 0;
  for (let i = 0; i < n; i++) sum += square[i][i];
  return sum;
}
console.log(sumMatrix([[1, 2], [3, 4]])); // 10
console.log(diagonalSum([[1, 2], [3, 4]])); // 5

У первого примера время пропорционально общему числу ячеек даже для строк разной длины. У второго проверка размеров и сумма занимают Θ(n), дополнительная память O(1).

Почему строки иногда меняются вместе

Из общих знаний: Array(3).fill([0, 0]) кладёт в три позиции одну и ту же ссылку. Изменение одной строки видно во всех. Создавайте каждую строку отдельно:

const matrix = Array.from({ length: 3 }, () => Array(2).fill(0));
matrix[0][0] = 7;
console.log(matrix[1][0]); // 0
Как пройти побочную диагональ квадрата?

Для строки i берите столбец n − 1 − i. В квадрате 3 × 3 это (0, 2), (1, 1), (2, 0). Если складываете обе диагонали, центральную ячейку нечётного квадрата обычно нужно учесть один раз — уточните условие.
