Сортировки: сравниваем идеи и реализации

Сортировка упорядочивает данные по правилу сравнения. Устойчивый алгоритм сохраняет взаимный порядок элементов с равными ключами. Сортировка на месте использует небольшую дополнительную память; рекурсивный стек при этом тоже надо учитывать.

Пузырьковая сортировка

Сравниваем соседей слева направо и меняем их местами, если они стоят неверно. После первого прохода максимум оказался справа. После каждого следующего прохода неупорядоченная часть сокращается. Если обменов не было, можно закончить раньше.

function bubbleSort(input) {
  const items = [...input];
  for (let end = items.length - 1; end > 0; end--) {
    let swapped = false;
    for (let i = 0; i < end; i++) {
      if (items[i] > items[i + 1]) {
        [items[i], items[i + 1]] = [items[i + 1], items[i]];
        swapped = true;
      }
    }
    if (!swapped) break;
  }
  return items;
}
console.log(bubbleSort([4, 1, 3, 1])); // [1, 1, 3, 4]

С флагом swapped лучший случай Θ(n), худший Θ(n²). В примере сделана копия: память O(n), хотя сами обмены требуют O(1). В версии из заметки RS School раннего выхода нет, поэтому даже отсортированный вход требует Θ(n²).

Сортировка слиянием

Делим массив до отрезков длины 0 или 1, затем сливаем отсортированные половины. При слиянии сравниваем первые ещё не взятые элементы. Берём меньший, а когда одна половина кончилась, дописываем остаток другой.

function mergeSort(input) {
  if (input.length <= 1) return [...input];
  const mid = Math.floor(input.length / 2);
  const left = mergeSort(input.slice(0, mid));
  const right = mergeSort(input.slice(mid));
  const result = [];
  let i = 0;
  let j = 0;
  while (i < left.length && j < right.length) {
    if (left[i] <= right[j]) result.push(left[i++]);
    else result.push(right[j++]);
  }
  while (i < left.length) result.push(left[i++]);
  while (j < right.length) result.push(right[j++]);
  return result;
}
console.log(mergeSort([7, 2, 5, 2])); // [2, 2, 5, 7]

Слияние одного уровня обрабатывает суммарно n элементов, уровней около log₂ n. Получаем Θ(n log n) времени и O(n) пиковой дополнительной памяти; стек имеет глубину O(log n). Суммарно за выполнение выделяется больше памяти, чем одновременно удерживается.

Уточнение к реализации модуля

В заметке слияние использует shift(). В обычной модели массива удаление первого элемента требует сдвига остальных, что портит линейную стоимость слияния. Здесь используются индексы, а при равенстве берётся левый элемент — это сохраняет устойчивость.

Быстрая сортировка и встроенный sort

Quick sort выбирает опорный элемент, разделяет значения относительно него и сортирует части. Опорный — не обязательно среднее арифметическое и не обязательно медиана. При удачных разбиениях время O(n log n), в худшем случае O(n²). Память зависит от реализации: версии с новыми массивами не являются сортировками на месте.

Из общих знаний: встроенный sort() без функции сравнения сортирует по строковому представлению, поэтому для чисел обычно передают (a, b) => a - b. Стандарт требует устойчивость, но не фиксирует конкретный алгоритм и его сложность. Для сохранения входа сортируйте копию.

const values = [10, 2, 1];
const sorted = [...values].sort((a, b) => a - b);
console.log(sorted); // [1, 2, 10]
console.log(values); // [10, 2, 1]
