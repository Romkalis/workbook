Практика: от условия к решению

Для каждой задачи сначала выпишите вход, выход, ограничения и три примера, включая пустой вход. Найдите простое решение, докажите его, оцените время и память. Только после этого ищите улучшение. Код, который быстро работает на одном примере, ещё не объясняет сложность.

Задачи для самостоятельной работы

  • Найдите минимум массива без сортировки. Решите, что вернуть для пустого входа.
  • Посчитайте суммы столбцов прямоугольной матрицы. Проверьте 0 строк и 1 столбец.
  • Расширьте проверку скобок на (), [] и {}. Вход ([)] должен быть отвергнут.
  • Удалите первый узел списка с заданным значением. Не забудьте замену head.
  • Найдите минимальное значение BST, затем объясните случай пустого дерева.
  • Измените бинарный поиск так, чтобы находить первое вхождение среди дубликатов.
Подсказки и критерии проверки

Минимум: один проход, O(n), без копии. Столбцы: результат длины c, O(r × c) времени. Разные скобки: стек открывающих и сравнение типа закрывающей. Удаление: отдельно обработайте head, затем ищите предшественника. Минимум BST: двигайтесь влево. Первое вхождение: при совпадении запомните индекс и продолжайте в левой части.

Как перейти к заданиям RS School

Модуль ссылается на basic-js-ds и basic-js. Читайте README выбранного репозитория, запускайте его проверки и решайте доступные задачи самостоятельно. Программа не требует решить абсолютно всё. Примеры учебника объясняют приёмы, но не являются готовой сдачей этих заданий.

После практики пройдите учебный тест ниже, затем тест Algorithms & Data structures в RS App по расписанию своего набора. Доступность, название и сроки проверяйте в школе.

Слова, которые нужно объяснить своими словами

Инвариант
Утверждение, которое сохраняется между шагами алгоритма.
Мутация
Изменение существующего объекта или массива.
Высота дерева
Длина самого длинного пути от корня к листу; здесь важен её порядок роста.
Устойчивость
Сохранение порядка элементов с равными ключами при сортировке.
Коллизия
Разные ключи попали в одну корзину хеш-таблицы.
