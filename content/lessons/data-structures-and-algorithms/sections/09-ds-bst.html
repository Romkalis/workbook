Дерево поиска: важна высота

У дерева есть корень, дочерние узлы и листья без детей. В бинарном дереве у узла не больше двух детей. BST, бинарное дерево поиска, добавляет правило: все ключи левого поддерева меньше ключа узла, все ключи правого — больше. Политику дубликатов выбирают отдельно.

Поиск по одной ветке

В дереве с корнем 8, левым ребёнком 3 и правым 10 число 6 ищем слева от 8, затем справа от 3. Пропущенные поддеревья проверять не нужно: правило BST исключает ответ в них.

const tree = {
  value: 8,
  left: {
    value: 3,
    left: null,
    right: { value: 6, left: null, right: null }
  },
  right: { value: 10, left: null, right: null }
};
function hasValue(node, target) {
  while (node !== null) {
    if (node.value === target) return true;
    node = target < node.value ? node.left : node.right;
  }
  return false;
}
function inOrder(node, result = []) {
  if (node === null) return result;
  inOrder(node.left, result);
  result.push(node.value);
  inOrder(node.right, result);
  return result;
}
console.log(hasValue(tree, 6)); // true
console.log(inOrder(tree)); // [3, 6, 8, 10]

Поиск и вставка проходят путь высоты h: O(h). Если дерево сбалансировано, h = O(log n). Если вставлять возрастающие ключи в обычное BST, может получиться цепочка высоты O(n). Итеративный поиск использует O(1) дополнительной памяти.

Уточнение к заметке модуля

Правило «меньше слева, больше справа» относится к BST, а не к любому бинарному дереву. И O(log n) не гарантировано для несбалансированного BST.

Обходы и изменение дерева

In-order: левое поддерево → узел → правое. Для BST получаем отсортированную последовательность. Pre-order посещает узел перед детьми, post-order — после детей. Все полные обходы занимают O(n) времени. Рекурсивный стек — O(h), а массив результата — O(n).

Чтобы вставить ключ, спускаемся по сравнениям до свободной ссылки и создаём лист. При удалении листа достаточно убрать ссылку. Узел с одним ребёнком заменяют этим ребёнком. При двух детях можно взять минимальный ключ правого поддерева, перенести его в удаляемый узел и затем удалить прежний узел этого минимума. Корень тоже может измениться.
