Источники и ограничения

Проверено 2 ноября 2026 года. Программа задаёт темы; примеры и упражнения написаны для учебника из общих знаний. Это не расшифровка всех внешних материалов модуля.

  • RS School: Testing — прочитан README через raw.githubusercontent.com. Указанные там тест в RS App и сроки проверяйте по своему набору.
  • Node.js: Test runner — базовые test и ожидание асинхронного завершения; примеры выполнены на Node.js 22.
  • Jest: matchers, асинхронность, подмены — терминология API. Примеры этого урока исполняются встроенным Node runner, а не Jest.
  • Vitest, Playwright, Testing Library — роли инструментов и ориентация на поведение пользователя.
  • The Practical Test Pyramid — ориентир по уровням и стоимости обратной связи.
  • Martin Fowler: TDD — цикл Red/Green/Refactor; Cucumber: BDD — совместное уточнение поведения на примерах.

Видео, статьи Testsigma, Testim, LogRocket, CircleCI, Wanago, подборка goldbergyoni и остальные внешние материалы из программы не разобраны. Страницу Agile in a Flash о FIRST открыть не удалось; FIRST изложен из общих знаний. Страница Dan North не вернула читаемый текст, для объяснения BDD использована документация Cucumber. Пример Red в TDD намеренно проверен как падающий; остальные исполняемые блоки проходят.
