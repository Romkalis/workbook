Первый тест: подготовить, выполнить, проверить

AAA означает Arrange, Act, Assert: подготовьте данные, вызовите действие и проверьте наблюдаемый результат. Название теста должно объяснять условие и ожидаемое поведение.

Проверяем итог корзины

Контракт примера: вход — массив уже проверенных товаров с неотрицательными числовыми price и целочисленными quantity. Сумма пустого массива равна 0. Здесь проверяем расчёт, а не валидацию входного JSON.

import test from 'node:test';
import assert from 'node:assert/strict';

function total(items) {
  return items.reduce((sum, item) => sum + item.price * item.quantity, 0);
}

test('два товара: сумма учитывает количество', () => {
  const items = [
    { price: 100, quantity: 2 },
    { price: 50, quantity: 1 }
  ]; // Arrange
  const actual = total(items); // Act
  assert.equal(actual, 250); // Assert
});

test('пустая корзина: итог равен нулю', () => {
  assert.equal(total([]), 0);
});

Если убрать умножение на quantity, первый тест должен упасть. Это полезная мысленная проверка силы утверждения. Для понятных коротких тестов подписывать каждую строку AAA необязательно.

Равенство, структура и исключение

В node:assert/strict equal сравнивает примитивные значения или идентичность объектов. Для структуры массива или объекта используйте deepEqual. Синхронное исключение проверяйте через throws(() => действие()): важно передать функцию, а не вызвать её до проверки.

import test from 'node:test';
import assert from 'node:assert/strict';

function parseQuantity(value) {
  const quantity = Number(value);
  if (value.trim() === '' || !Number.isInteger(quantity) || quantity < 1) {
    throw new RangeError('Нужно целое количество от 1');
  }
  return { quantity };
}
test('строка количества превращается в объект', () => {
  assert.deepEqual(parseQuantity('2'), { quantity: 2 });
});
test('нулевое количество отклоняется', () => {
  assert.throws(() => parseQuantity('0'), RangeError);
});

Вход этой функции — строка. Допустимость значений вроде «1e2» или «0x10» зависит от требований: Number понимает их как числа. Если разрешены только десятичные цифры, одного преобразования Number недостаточно.
