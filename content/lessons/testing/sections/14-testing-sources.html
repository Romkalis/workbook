Источники и ограничения

Проверено 2 ноября 2026 года. Программа задаёт темы; примеры и упражнения написаны для учебника из общих знаний. Это не расшифровка всех внешних материалов модуля.

  • RS School: Testing — прочитан README через raw.githubusercontent.com. Указанные там тест в RS App и сроки проверяйте по своему набору.
  • Node.js: Test runner — базовые test и ожидание асинхронного завершения; примеры выполнены на Node.js 22.
  • Jest: matchers, асинхронность, подмены — терминология API. Примеры этого урока исполняются встроенным Node runner, а не Jest.
  • Vitest, Playwright, Testing Library — роли инструментов и ориентация на поведение пользователя.
  • The Practical Test Pyramid — ориентир по уровням и стоимости обратной связи.
  • Martin Fowler: TDD — цикл Red/Green/Refactor; Cucumber: BDD — совместное уточнение поведения на примерах.

3 ноября 2026 года разобраны goldbergyoni/javascript-testing-best-practices (разделы 0–2 и начало 3; страница отдала текст не полностью) и CircleCI: Test Driven Development. Статья Atlassian о видах тестирования отдала только навигацию. Видео, статьи Testsigma, Testim, LogRocket, Wanago и остальные внешние материалы из программы не разобраны. Страницу Agile in a Flash о FIRST открыть не удалось; FIRST изложен из общих знаний. Страница Dan North не вернула читаемый текст, для объяснения BDD использована документация Cucumber. Пример Red в TDD намеренно проверен как падающий; остальные исполняемые блоки проходят.

9 ноября 2026 года добавлены скриншотные тесты, тесты безопасности во фронтенде, альтернативные названия свойств FIRST, чистые функции, todo и skip, инструменты E2E, формулы покрытия кода и требований, таблица AAA и цвета TDD. Перечень тем сверен с автотестом RS App по тестированию. Объяснения — из общих знаний; пример с чистой функцией и отчёт с todo и skip проверены во встроенном runner Node.js 22.
