Практика и вопросы

Упражнения

  1. Установите Node.js LTS через nvm. Откройте REPL, выполните process.version и process.platform.
  2. Напишите скрипт count.js, который получает имя файла из process.argv, читает его через fs/promises и выводит число строк. Если файла нет, печатает понятное сообщение и завершается с кодом 1.
  3. Создайте проект через npm init -y, поставьте Express, добавьте скрипт dev с node --watch. Посмотрите, что появилось в package.json и package-lock.json, и добавьте .gitignore.
  4. Соберите API задач из раздела про Express и проверьте каждый маршрут через curl, Postman или файл .http в редакторе. Добавьте маршрут PUT.
  5. Напишите middleware, которая измеряет время ответа и печатает «GET /api/todos — 3 мс». Подсказка: событие res.on('finish', ...).
  6. Подключите MongoDB (Docker или Atlas) и переведите API с массива на модель Todo. Проверьте ответы на несуществующий и некорректный id.
  7. Сделайте страницу на Vite, которая показывает и добавляет задачи через ваш API. Настройте CORS.

Вопросы

Почему в Node.js нет document и window?

Node.js выполняет JavaScript вне браузера: нет страницы, значит нет DOM. Зато есть то, чего нет в браузере: файлы, процесс, сервер.

Почему node_modules не добавляют в git, а package-lock.json добавляют?

node_modules огромна и восстанавливается командой npm install. Lock-файл фиксирует точные версии, чтобы у всех установилось одно и то же.

Как однопоточный Node.js обслуживает много запросов одновременно?

Пока ждёт базу, файлы и сеть, он не простаивает: операции ввода-вывода выполняются вне потока JavaScript, а поток берётся за следующий запрос. Готовые результаты обрабатывает цикл событий.

Что будет, если middleware не вызовет next() и не ответит?

Запрос повиснет: клиент будет ждать ответа, пока не сработает тайм-аут.

Почему req.params.id нужно превращать в число?

Параметры пути и query string всегда строки. '5' === 5 ложно, поэтому без Number поиск не найдёт задачу.

Как Express понимает, что middleware — обработчик ошибок?

По четырём параметрам: (err, req, res, next). Его подключают последним.
