Что такое Node.js

Node.js — среда выполнения JavaScript (runtime): программа, которая берёт ваш код и выполняет его. Внутри три главные части:

  • V8 — движок JavaScript из Chrome. Он понимает сам язык: переменные, функции, промисы.
  • libuv — библиотека на языке C, которая умеет работать с файлами, сетью и таймерами, не останавливая программу. Она обеспечивает асинхронность.
  • Встроенные модули — API для того, чего нет в браузере: файловая система, HTTP-сервер, процессы, криптография.

Язык тот же, а окружение другое. Сравнение:

БраузерNode.js
Глобальный объектwindowglobal (в обоих есть общее имя globalThis)
DOM, document, localStorageестьнет — нет страницы
Файлы на дискетолько через выбор пользователяполный доступ: модуль fs
Процесс, аргументы, окружениенетprocess
fetch, setTimeout, URL, consoleестьесть (fetch встроен с Node.js 18)
МодулиES-модулиCommonJS и ES-модули
Безопасностьпесочница: сайт не может навредить системекод имеет те же права, что и пользователь, запустивший его

Последняя строка важна: скрипт на Node.js может удалить файлы, прочитать ключи SSH (ими вы входите на серверы и в GitHub) и отправить их куда угодно. Поэтому чужие пакеты и скрипты нужно ставить осознанно.

Установка и версии

Node.js выпускается так: чётные версии (20, 22, 24) становятся LTS (long-term support) — получают исправления около 30 месяцев. Для работы берут актуальную LTS. Удобнее всего ставить через менеджер версий nvm (на Windows — nvm-windows или fnm): разные проекты требуют разных версий, и nvm переключает их одной командой.

nvm install 22      # поставить Node.js 22 (# — комментарий, вводить не нужно)
nvm use 22          # переключиться на него
node -v             # v22.23.2
npm -v              # 10.9.8 — npm ставится вместе с Node.js

Как запускать код

  • node без аргументов открывает REPL (read–eval–print loop) — интерактивную консоль, как в DevTools. Выход — .exit или Ctrl+D дважды.
  • node app.js выполняет файл. Программа завершается сама, когда делать больше нечего; сервер не завершается, потому что ждёт запросы. Остановить — Ctrl+C.
  • node -e "console.log(2 + 2)" выполняет строку кода.
  • node --watch app.js перезапускает программу при изменении файлов (встроено с Node.js 18; раньше для этого ставили пакет nodemon).
