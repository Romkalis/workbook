HTTP-сервер на чистом Node.js

Модуль http умеет принимать HTTP-запросы. Express построен поверх него, поэтому сначала посмотрим, что под капотом.

const http = require('node:http');

const server = http.createServer((req, res) => {
  if (req.method === 'GET' && req.url === '/') {
    res.writeHead(200, { 'Content-Type': 'text/plain; charset=utf-8' });
    res.end('Привет от Node.js');
    return;
  }
  res.writeHead(404, { 'Content-Type': 'application/json' });
  res.end(JSON.stringify({ error: 'Not Found' }));
});

server.listen(3001, () => console.log('http://localhost:3001'));
  • createServer принимает функцию, которая вызывается на каждый запрос.
  • req (request) — входящий запрос: req.method, req.url (путь вместе с query string), req.headers.
  • res (response) — ответ, который мы собираем: writeHead задаёт статус и заголовки, end отправляет тело и завершает ответ. Если забыть end, браузер будет ждать вечно.
  • listen(3001) начинает слушать порт. Если порт занят другой программой, будет ошибка EADDRINUSE.

Проверка curl: curl localhost:3001/ вернул «Привет от Node.js», а /x — HTTP/1.1 404 Not Found. Это тот же текстовый HTTP, что разобран в уроке о клиенте и сервере, только теперь мы на стороне сервера.

Писать на чистом http настоящий API неудобно: маршруты разбираются вручную через if, тело запроса приходит потоком кусков и его надо собирать и парсить самому, query string — разбирать через new URL(req.url, 'http://localhost'). Эту рутину берёт на себя Express.
