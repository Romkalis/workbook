Источники

Урок написан, чтобы закрыть пробел перед уроком «JWT-авторизация», и собран по официальной документации. Все страницы открыты и сверены 14 ноября 2026 года.

Node.js и npm

  • Introduction to Node.js — что такое Node.js и чем он отличается от браузера.
  • The Node.js Event Loop — фазы цикла событий, setImmediate и process.nextTick.
  • Документация API: CommonJS modules, ECMAScript modules, fs, path, events, http, параметры командной строки (--watch, --env-file).
  • How to read environment variables.
  • npm: package.json, Семантическое версионирование, nvm.
  • learn.javascript.ru: Модули, введение.

Express и MongoDB

  • Express: Hello world, Routing, Using middleware, Error handling, Migrating to Express 5.
  • MongoDB: Introduction to MongoDB, MongoDB Atlas.
  • Mongoose: Getting started, Validation.

Из общих знаний: сравнение с браузером, рекомендации по структуре проекта, worker threads, Docker-команда для MongoDB. Проверено в Node.js 22.23: модули CommonJS и ESM, fs/promises, path, --env-file, EventEmitter, порядок nextTick, промисов, таймеров; HTTP-сервер и API на Express 5.3 с CRUD, middleware, 404 и обработчиком ошибок (каждый маршрут — запросом curl); схема Mongoose 8.24 и валидация без подключения к базе. Работа с настоящей MongoDB (connect, find и другие запросы) при подготовке урока не запускалась.
