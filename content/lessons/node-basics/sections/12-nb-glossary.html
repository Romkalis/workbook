Словарь

Node.js
Среда выполнения JavaScript вне браузера: V8 + libuv + встроенные модули.
V8
Движок JavaScript из Chrome.
libuv
Библиотека асинхронного ввода-вывода внутри Node.js.
LTS
Версия с долгой поддержкой; её ставят для работы.
REPL
Интерактивная консоль: ввёл выражение — увидел результат.
CommonJS
Система модулей Node.js: require и module.exports.
ES-модули (ESM)
Стандартные модули: import и export.
npm
Менеджер пакетов и реестр библиотек.
package.json
Описание проекта: зависимости, скрипты, тип модулей.
package-lock.json
Точные версии всего дерева зависимостей.
Семантическое версионирование
Номер версии МАЖОРНАЯ.МИНОРНАЯ.ПАТЧ и правила их увеличения.
Переменная окружения
Настройка, переданная программе снаружи; в Node.js — process.env.
Цикл событий
Механизм, который выполняет готовые колбэки, когда поток освобождается.
Блокировка цикла событий
Долгий синхронный код, из-за которого сервер никому не отвечает.
EventEmitter
Объект, который сообщает о событиях подписчикам (on, emit).
Express
Веб-фреймворк для Node.js: маршруты, req/res, middleware.
Маршрут
Сочетание метода и пути с обработчиком: app.get('/api/todos', ...).
Middleware
Функция (req, res, next) в цепочке обработки запроса.
MongoDB
Документная база данных: базы, коллекции, документы.
ObjectId
Уникальный идентификатор документа MongoDB, 24 шестнадцатеричных символа.
Mongoose
Библиотека для MongoDB со схемами, моделями и валидацией.
Схема / модель
Описание полей документа / класс для работы с коллекцией.
