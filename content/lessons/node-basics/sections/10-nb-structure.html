Структура проекта и путь к JWT

Пока всё в одном файле, проект легко читать. Когда маршрутов и моделей становится больше, код раскладывают по папкам по ролям. Единого стандарта нет, частый вариант:

todo-api/
  .env              секреты, не в git
  .env.example      список переменных без значений
  .gitignore        node_modules, .env
  package.json
  src/
    server.js       подключиться к базе и запустить app.listen
    app.js          создать app, подключить middleware и роутеры
    routes/         какие URL есть (todos.js, auth.js)
    controllers/    что делать на каждый URL
    models/         схемы Mongoose (Todo.js, User.js)
    middleware/     свои middleware (requireAuth.js, errorHandler.js)

Разделение app.js и server.js полезно для тестов: приложение можно импортировать и проверять запросами, не запуская сервер на порту.

// src/server.js
require('dotenv').config();
const mongoose = require('mongoose');
const app = require('./app');

const PORT = Number(process.env.PORT) || 3000;

async function start() {
  try {
    await mongoose.connect(process.env.MONGO_URI);
    app.listen(PORT, () => console.log(`http://localhost:${PORT}`));
  } catch (error) {
    console.error('Не удалось запустить сервер', error);
    process.exit(1);
  }
}

start();

Сервер сначала подключается к базе и только потом начинает принимать запросы. Если база недоступна, процесс завершается с кодом 1, а не работает «наполовину».

Как фронтенд обращается к своему серверу

Фронтенд на Vite (localhost:5173) и сервер (localhost:3000) — разные origin, поэтому браузер применит CORS. Два решения из урока о клиенте и сервере: подключить на сервере пакет cors с вашим origin (app.use(cors({ origin: 'http://localhost:5173' }))) или настроить прокси в dev-сервере Vite.

Что дальше

Теперь в уроке «JWT-авторизация» знакомо всё, на что он опирается: require, npm и .env, Express-маршруты и middleware, модели Mongoose. К этому добавятся модель пользователя с хешем пароля, выдача токена при входе и middleware, которое проверяет токен перед защищёнными маршрутами.
