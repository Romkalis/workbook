npm и package.json

npm (node package manager) — менеджер пакетов: он скачивает чужие библиотеки из реестра npmjs.com и следит за их версиями. Альтернативы с теми же идеями — pnpm и yarn.

package.json

Паспорт проекта. Создаётся командой npm init -y (-y — согласиться со всеми вопросами). Основные поля (документация):

{
  "name": "todo-api",
  "version": "1.0.0",
  "type": "module",
  "scripts": {
    "dev": "node --watch --env-file=.env src/server.js",
    "start": "node src/server.js",
    "test": "node --test"
  },
  "dependencies": {
    "express": "^5.3.0",
    "mongoose": "^8.24.9"
  },
  "devDependencies": {
    "eslint": "^9.0.0"
  }
}
  • dependencies — то, что нужно программе для работы (Express, Mongoose). Ставятся: npm install express.
  • devDependencies — только для разработки: линтеры, тесты, сборщики. Ставятся: npm install -D eslint.
  • scripts — команды проекта. Запуск: npm run dev. Для start и test слово run можно опустить: npm start, npm test.

Версии: что значат ^ и ~

Версии пакетов записывают по правилам семантического версионирования: МАЖОРНАЯ.МИНОРНАЯ.ПАТЧ. Патч — исправления ошибок, минорная — новые возможности без поломок, мажорная — изменения, которые могут сломать ваш код (Express 4 → 5).

  • ^5.3.0 — любая 5.x.x не ниже 5.3.0. Это вариант по умолчанию.
  • ~5.3.0 — только патчи: 5.3.x.
  • 5.3.0 — ровно эта версия.

node_modules и package-lock.json

Пакеты скачиваются в папку node_modules, вместе с их собственными зависимостями — поэтому она бывает огромной. В git её не добавляют (строка в .gitignore): её всегда можно восстановить командой npm install.

Файл package-lock.json записывает точные версии всего дерева пакетов. Его в git добавляют: так у всех разработчиков и на сервере стоят одинаковые версии. На сервере и в CI (автоматической проверке, которая запускается на сервере при каждом пуше в репозиторий) ставят командой npm ci — строго по lock-файлу.

npx

npx запускает команду из пакета: из node_modules/.bin проекта, а если её там нет — скачивает пакет во временную папку. npx eslint . вызывает локальный ESLint. С незнакомыми пакетами осторожнее: npx что-то скачает и выполнит чужой код с вашими правами.
