Комбинаторы: all, allSettled, any, race

Четыре статических метода принимают массив промисов и возвращают один промис. Различаются они тем, чего ждут и как реагируют на ошибки — это главная тема теста в RS App:

МетодВыполнитсяОтклонится
Promise.allкогда выполнены все — массивом значений по порядкупри первой ошибке
Promise.allSettledвсегда, когда все завершились — массивом объектов { status, value | reason }никогда
Promise.anyпервым успешным значениемесли отклонены все — AggregateError
Promise.raceесли первым завершился успехесли первой завершилась ошибка

Подробнее с проверенными примерами — раздел «Promise.all и родственники».

3. getFirstResolvedPromiseResult — первый успешный

[Promise.resolve(1), Promise.resolve(2), Promise.resolve(3)] => Promise fulfilled with 1
[Promise.reject(1), Promise.resolve(2), Promise.resolve(3)]  => Promise fulfilled with 2
[Promise.resolve(1), Promise.reject(2), Promise.resolve(3)]  => Promise fulfilled with 1
[Promise.reject(1), Promise.reject(2), Promise.reject(3)]    => Promise rejected

Ошибки пропускаем, нужен первый успех — это Promise.any. Если отклонены все, он отклоняется с AggregateError, где в поле errors лежат все причины. Обратите внимание: «первый» здесь — по времени выполнения, а не по порядку в массиве.

function getFirstResolvedPromiseResult(promises) {
  return Promise.any(promises);
}

Задача 1. Свой Promise.any ★★★ с подвохом

Напишите any(promises): выполняется первым успешным значением. Если отклонились все, отклоняется AggregateError с массивом причин в поле errors в порядке входного массива. Пустой массив сразу даёт отклонение с пустым errors.

Зачем: any — зеркальное отражение all: там первая ошибка всё прерывает, а успех ждёт всех; здесь первый успех всё решает, а ошибка ждёт всех. Если увидеть эту симметрию, оба метода запоминаются вместе.

Решение и разбор
export function any<T>(promises: readonly (T | PromiseLike<T>)[]): Promise<T> {
  return new Promise((resolve, reject) => {
    const errors = new Array<unknown>(promises.length);
    let left = promises.length;
    if (left === 0) return reject(new AggregateError([], 'All promises were rejected'));
    promises.forEach((p, i) => {
      Promise.resolve(p).then(resolve, (reason: unknown) => {
        errors[i] = reason;
        if (--left === 0) reject(new AggregateError(errors, 'All promises were rejected'));
      });
    });
  });
}

Код почти совпадает с all, только роли поменялись: resolve срабатывает сразу, а ошибки копятся по индексам. Пустой массив отклоняется сразу, и в этом отличие от race: «ни один не выполнился» для пустого списка — правда. Текст сообщения взят как у встроенного метода в V8 (из общих знаний).

4. getFirstPromiseResult — первый завершившийся

const promise1 = Promise.resolve(1)
const promise2 = Promise.reject(2)
const promise3 = new Promise((resolve) => setTimeout(() => resolve(3), 50))
const promise4 = new Promise((resolve) => setTimeout(() => resolve(4), 100))
const promise5 = new Promise((resolve) => setTimeout(() => resolve(5), 150))
const promise6 = new Promise((reject) => setTimeout(() => reject(6), 10))
[promise3, promise6, promise1] => Promise fulfilled with 1
[promise4, promise3, promise5] => Promise fulfilled with 3
[promise3, promise6, promise2] => Promise rejected with 2
[promise3, promise4, promise6] => Promise rejected with 6

Неважно, успех или ошибка — побеждает тот, кто завершился раньше. Это Promise.race. В примере [promise3, promise6, promise1] выигрывает promise1: он уже выполнен (Promise.resolve(1)), а остальные ждут таймеров. Такой приём используют для тайм-аутов: Promise.race([fetch(url), timeout(5000)]).

function getFirstPromiseResult(promises) {
  return Promise.race(promises);
}

Задача 2. Свой Promise.race и пустой массив ★★☆ практика

Напишите race(promises): завершается так же, как первый завершившийся промис, — успехом или ошибкой. Ответьте: что вернёт race([]) и почему это не ошибка в спецификации?

Зачем: race — самый короткий комбинатор, но в нём есть ловушка: с пустым массивом промис не завершается никогда. Код await race(list) с пустым списком просто зависнет без ошибки.

Решение и разбор
export function race<T>(promises: readonly (T | PromiseLike<T>)[]): Promise<T> {
  return new Promise((resolve, reject) => {
    for (const p of promises) Promise.resolve(p).then(resolve, reject);
  });
}

Каждый промис подписывает на себя одни и те же resolve и reject. Выигрывает первый, остальные вызовы игнорируются. С пустым массивом подписываться некому, и промис остаётся в ожидании навсегда. Встроенный Promise.race([]) ведёт себя так же: «гонка без участников» не имеет победителя. Если список может быть пустым, проверяйте это до вызова.

5. getAllOrNothing — все или ничего

[Promise.resolve(1), Promise.resolve(2), Promise.resolve(3)] => Promise fulfilled with [1, 2, 3]
[Promise.resolve(1), Promise.reject(2), Promise.resolve(3)] => Promise rejected with 2

Promise.all выполняется массивом значений в порядке исходного массива (а не завершения), а при первой же ошибке сразу отклоняется с её причиной. Остальные промисы при этом продолжают выполняться — их просто никто не ждёт.

function getAllOrNothing(promises) {
  return Promise.all(promises);
}

Задача 3. Свой Promise.all ★★★ с подвохом

Не используя статические методы Promise (кроме Promise.resolve), напишите all(values). Результаты в порядке входного массива, а не в порядке завершения. Обычные значения в массиве (не промисы) тоже допустимы. Пустой массив сразу даёт []. При первом отклонении результат отклоняется с этой причиной.

Зачем: повторить встроенный метод — лучший способ запомнить его контракт до мелочей: что с порядком, что с пустым массивом, что с не-промисами. Именно эти мелочи и спрашивают на собеседованиях.

Решение и разбор
export function all<T>(values: readonly (T | PromiseLike<T>)[]): Promise<T[]> {
  return new Promise((resolve, reject) => {
    const results = new Array<T>(values.length);
    let left = values.length;
    if (left === 0) return resolve([]);
    values.forEach((value, i) => {
      Promise.resolve(value).then((v) => {
        results[i] = v;
        left -= 1;
        if (left === 0) resolve(results);
      }, reject);
    });
  });
}

Индекс i фиксируется в замыкании, поэтому результат ложится на своё место, когда бы промис ни завершился. Счётчик left, а не results.length: длина массива известна с самого начала, и по ней нельзя понять, все ли ответили. Повторные вызовы reject после первого игнорируются самим промисом, так что отдельный флаг не нужен. Promise.resolve(value) превращает обычные значения и «thenable»-объекты в промисы.

6. getAllResult — все результаты, null вместо ошибок

[Promise.resolve(1), Promise.resolve(2), Promise.resolve(3)] => Promise fulfilled with [1, 2, 3]
[Promise.resolve(1), Promise.reject(2), Promise.resolve(3)]  => Promise fulfilled with [1, null, 3]

Promise.allSettled ждёт всех и никогда не отклоняется: для каждого промиса он даёт объект { status: 'fulfilled', value } или { status: 'rejected', reason }. Остаётся пройти результаты map-ом и заменить отклонённые на null. Так показывают на странице всё, что загрузилось, даже если часть запросов упала.

function getAllResult(promises) {
  return Promise.allSettled(promises).then((results) =>
    results.map((r) => (r.status === 'fulfilled' ? r.value : null))
  );
}

Задача 4. Свой Promise.allSettled ★★☆ практика

Напишите allSettled(promises) без статических методов (кроме Promise.resolve): результат — массив { status: "fulfilled", value } или { status: "rejected", reason } в порядке входа. Сам результат никогда не отклоняется.

Зачем: это all, у которого ошибка — тоже результат. Если написать его через своё all из прошлой задачи, видно, что разница всего в одной строке: каждый промис заранее «обезвреживается» своим catch.

Решение и разбор
export type Settled<T> = { status: 'fulfilled'; value: T } | { status: 'rejected'; reason: unknown };

export function allSettled<T>(promises: readonly (T | PromiseLike<T>)[]): Promise<Settled<T>[]> {
  const wrapped = promises.map((p) =>
    Promise.resolve(p).then(
      (value): Settled<T> => ({ status: 'fulfilled', value }),
      (reason): Settled<T> => ({ status: 'rejected', reason }),
    ),
  );
  return new Promise((resolve) => {
    const out = new Array<Settled<T>>(wrapped.length);
    let left = wrapped.length;
    if (left === 0) return resolve([]);
    wrapped.forEach((w, i) =>
      w.then((s) => {
        out[i] = s;
        if (--left === 0) resolve(out);
      }),
    );
  });
}

Каждый промис превращается в такой, который всегда выполняется: ошибка становится объектом-описанием. После этого сбор результатов ничем не отличается от all, только отклоняться уже нечему. Тип Settled<T> — размеченное объединение по status, как и у встроенного PromiseSettledResult.
