Комбинаторы: all, allSettled, any, race

Четыре статических метода принимают массив промисов и возвращают один промис. Различаются они тем, чего ждут и как реагируют на ошибки — это главная тема теста в RS App:

МетодВыполнитсяОтклонится
Promise.allкогда выполнены все — массивом значений по порядкупри первой ошибке
Promise.allSettledвсегда, когда все завершились — массивом объектов { status, value | reason }никогда
Promise.anyпервым успешным значениемесли отклонены все — AggregateError
Promise.raceесли первым завершился успехесли первой завершилась ошибка

Подробнее с проверенными примерами — раздел «Promise.all и родственники».

3. getFirstResolvedPromiseResult — первый успешный

[Promise.resolve(1), Promise.resolve(2), Promise.resolve(3)] => Promise fulfilled with 1
[Promise.reject(1), Promise.resolve(2), Promise.resolve(3)]  => Promise fulfilled with 2
[Promise.resolve(1), Promise.reject(2), Promise.resolve(3)]  => Promise fulfilled with 1
[Promise.reject(1), Promise.reject(2), Promise.reject(3)]    => Promise rejected

Ошибки пропускаем, нужен первый успех — это Promise.any. Если отклонены все, он отклоняется с AggregateError, где в поле errors лежат все причины. Обратите внимание: «первый» здесь — по времени выполнения, а не по порядку в массиве.

function getFirstResolvedPromiseResult(promises) {
  return Promise.any(promises);
}

4. getFirstPromiseResult — первый завершившийся

const promise1 = Promise.resolve(1)
const promise2 = Promise.reject(2)
const promise3 = new Promise((resolve) => setTimeout(() => resolve(3), 50))
const promise4 = new Promise((resolve) => setTimeout(() => resolve(4), 100))
const promise5 = new Promise((resolve) => setTimeout(() => resolve(5), 150))
const promise6 = new Promise((reject) => setTimeout(() => reject(6), 10))
[promise3, promise6, promise1] => Promise fulfilled with 1
[promise4, promise3, promise5] => Promise fulfilled with 3
[promise3, promise6, promise2] => Promise rejected with 2
[promise3, promise4, promise6] => Promise rejected with 6

Неважно, успех или ошибка — побеждает тот, кто завершился раньше. Это Promise.race. В примере [promise3, promise6, promise1] выигрывает promise1: он уже выполнен (Promise.resolve(1)), а остальные ждут таймеров. Такой приём используют для тайм-аутов: Promise.race([fetch(url), timeout(5000)]).

function getFirstPromiseResult(promises) {
  return Promise.race(promises);
}

5. getAllOrNothing — все или ничего

[Promise.resolve(1), Promise.resolve(2), Promise.resolve(3)] => Promise fulfilled with [1, 2, 3]
[Promise.resolve(1), Promise.reject(2), Promise.resolve(3)] => Promise rejected with 2

Promise.all выполняется массивом значений в порядке исходного массива (а не завершения), а при первой же ошибке сразу отклоняется с её причиной. Остальные промисы при этом продолжают выполняться — их просто никто не ждёт.

function getAllOrNothing(promises) {
  return Promise.all(promises);
}

6. getAllResult — все результаты, null вместо ошибок

[Promise.resolve(1), Promise.resolve(2), Promise.resolve(3)] => Promise fulfilled with [1, 2, 3]
[Promise.resolve(1), Promise.reject(2), Promise.resolve(3)]  => Promise fulfilled with [1, null, 3]

Promise.allSettled ждёт всех и никогда не отклоняется: для каждого промиса он даёт объект { status: 'fulfilled', value } или { status: 'rejected', reason }. Остаётся пройти результаты map-ом и заменить отклонённые на null. Так показывают на странице всё, что загрузилось, даже если часть запросов упала.

function getAllResult(promises) {
  return Promise.allSettled(promises).then((results) =>
    results.map((r) => (r.status === 'fulfilled' ? r.value : null))
  );
}
