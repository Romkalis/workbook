Создание промиса и обработка результата

Промис — объект, который сейчас в ожидании (pending), а потом станет выполненным (fulfilled) со значением или отклонённым (rejected) с причиной. Основы — в уроке «Клиент-серверное взаимодействие», обработка ошибок — в уроке «Обработка ошибок».

1. getPromise — выполнить или отклонить по знаку числа

-1   => promise that will be rejected
0    => promise that will be fulfilled
1    => promise that will be fulfilled

Конструктор new Promise((resolve, reject) => ...) сразу вызывает переданную функцию-исполнитель. Внутри мы решаем исход: resolve(number) для неотрицательного числа (0 по условию положительный), reject(...) для отрицательного. Отклонять принято объектом Error, а не голым значением: у ошибки есть стек, и линтер airbnb (правило prefer-promise-reject-errors) требует именно этого.

function getPromise(number) {
  return new Promise((resolve, reject) => {
    if (number >= 0) resolve(number);
    else reject(new Error('Negative number'));
  });
}

2. getPromiseResult — всегда выполненный промис со словом

Promise.resolve('success') => promise that will be fulfilled with 'success' value
Promise.reject('fail')     => promise that will be fulfilled with 'fail' value

then принимает два обработчика: для успеха и для ошибки. Каждый возвращает строку, а then всегда возвращает новый промис, который выполняется значением, возвращённым обработчиком. Поэтому ошибка исходного промиса превращается в успешный промис со значением «fail» — отклонение «поймано». То же можно записать как source.then(() => 'success').catch(() => 'fail').

function getPromiseResult(source) {
  return source.then(
    () => 'success',
    () => 'fail'
  );
}
