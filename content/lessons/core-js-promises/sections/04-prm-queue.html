Последовательная цепочка без статических методов

Последняя задача проверяет, понимаете ли вы цепочки then: тест запрещает Promise.all, allSettled, any и race (функция isPromiseUsed ищет их в коде). Promise.resolve не запрещён.

7. queuePromises — склеить значения по порядку

const promise1 = Promise.resolve(10)
const promise2 = Promise.resolve(20)
const promise3 = Promise.resolve(30)
const promise4 = new Promise((resolve) => setTimeout(() => resolve(40), 10))
[promise1, promise3, promise2] => Promise.resolved('103020')
[promise1, promise4, promise3] => Promise.resolved('104030')
[promise1, promise4, promise3, promise2] => Promise.resolved('10403020')

Нужно получить значения в порядке массива, а не в порядке выполнения, и склеить в строку. Строим цепочку через reduce: начинаем с уже выполненного промиса с пустой строкой Promise.resolve(''), а на каждом шаге продолжаем цепочку: «дождись предыдущего результата acc, потом дождись очередного промиса и верни acc + value». Так каждое звено ждёт предыдущее, и порядок совпадает с массивом, даже если promise4 выполняется позже promise3.

Почему acc + value даёт строку, а не сумму: начальное значение — пустая строка, а строка плюс число — склейка. '' + 10 = «10», затем «10» + 40 = «1040».

Та же логика на async/await — с циклом for...of и await внутри. Но линтер airbnb запрещает и for...of (no-restricted-syntax), и await в цикле (no-await-in-loop), поэтому для задания удобнее reduce.

function queuePromises(promises) {
  return promises.reduce(
    (chain, promise) =>
      chain.then((acc) => promise.then((value) => acc + value)),
    Promise.resolve('')
  );
}
