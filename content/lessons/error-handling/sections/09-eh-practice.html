Практика и вопросы

Упражнения

  1. В консоли браузера вызовите по очереди: null.x, notDefined, new Array(-1), decodeURIComponent('%'), JSON.parse('{'). Запишите тип каждой ошибки и сравните сообщения в Chrome и Firefox.
  2. Напишите функцию safeParse(text, fallback): возвращает разобранный JSON или fallback, если JSON битый, но пробрасывает любые другие ошибки.
  3. Создайте AppError, HttpError и ValidationError из урока. Проверьте name, instanceof и cause. Удалите строку с this.name и посмотрите, что изменится в консоли.
  4. Оберните fetch в функцию getJson(url), которая выбрасывает HttpError при неуспешном статусе. Покажите в интерфейсе разные сообщения для 404, для 5xx и для отсутствия сети (режим Offline в DevTools → Network).
  5. Добавьте на страницу глобальные обработчики error и unhandledrejection, которые выводят плашку «Что-то пошло не так». Проверьте их ошибкой в setTimeout и забытым Promise.reject.
  6. Сделайте картинку с битым адресом и заглушкой через событие error.

Вопросы

Почему try...catch не ловит ошибку в setTimeout?

try работает синхронно и заканчивается раньше, чем запустится колбэк таймера. Когда колбэк выбросит ошибку, обёртки уже нет. try нужно ставить внутри колбэка.

Чем плох пустой catch?

Он прячет все ошибки, включая баги, о которых вы не знаете. Код молча работает неправильно, а причину не найти. Обрабатывайте ожидаемые ошибки и пробрасывайте остальные.

Зачем в своём классе ошибки строка this.name = this.constructor.name?

Без неё name берётся у Error и равно 'Error'. В консоли и журнале все ваши ошибки будут выглядеть одинаково.

Почему внутри try пишут return await, а не просто return?

Без await функция возвращает промис и выходит из try. Если промис потом отклонится, catch уже не сработает, и ошибка уйдёт наружу.

Можно ли поймать SyntaxError?

Только если текст разбирается во время работы: JSON.parse, eval, new Function. Синтаксическая ошибка в самом скрипте не даст ему запуститься.

Какое событие ловит забытые отклонения промисов?

unhandledrejection на window. Событие error для них не срабатывает.
