Источники

Программа модуля: RS School, Stage 2, JavaScript Error Handling. Материалы открыты и разобраны 14 ноября 2026 года.

Видео и слайды

  • Лекция RS School «JS Error Handling» — прочитана по автоматической расшифровке: способы вызвать ошибку, try...catch...finally, ловушка с пропущенным await, .catch и второй аргумент .then, window.onerror и ошибки элементов, свои классы с кодом статуса, граница ошибок в main. В конце лекции — организационные объявления о задании, к теме не относятся.
  • Слайды Дмитрия Цебрука — план лекции и полный код со стрима; исправленная версия кода приведена в разделах о своих ошибках и архитектуре.

Звук в лекции плохой (на это жалуются и слушатели), часть слов в расшифровке не распознана; ход мысли восстановлен по коду со слайдов.

Справочники и статьи

  • MDN: Error, конструктор Error, EvalError, RangeError, ReferenceError, SyntaxError, TypeError, URIError, AggregateError, InternalError.
  • MDN: throw, try...catch, Window: error event, HTMLElement: error event.
  • javascript.info: Error handling, "try...catch", Custom errors, Error handling with promises, Async/await: error handling. Русские версии — на learn.javascript.ru.
  • Kinsta: A Definitive Guide to Handling Errors in JavaScript — типы, стек, десять частых ошибок, способы обработки.
  • Valentino Gagliardi: A Mostly Complete Guide to Error Handling — ошибка и исключение, таймеры, события, комбинаторы промисов, Node.js.

Не удалось разобрать

  • SitePoint: The Ultimate Guide to JavaScript Error Handling — сайт отвечает проверкой на бота (код 403) вместо статьи. Её темы покрыты статьями Kinsta и Гальярди.

Из общих знаний: поведение Node.js при необработанном отклонении, коды ошибок Node.js, сервисы мониторинга, советы по сообщениям пользователю. Все примеры запущены в Node.js 22.23 (типы ошибок, finally, свои классы, cause, промисы и комбинаторы, исправленный код лекции); события error, unhandledrejection и ошибка загрузки картинки проверены в Chrome.
