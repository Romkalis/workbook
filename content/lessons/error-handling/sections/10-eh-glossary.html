Словарь

Ошибка (error)
Объект, описывающий проблему: name, message, stack, cause.
Исключение (exception)
Выброшенная через throw ошибка, которая прерывает выполнение до ближайшего catch.
Неперехваченная ошибка
Исключение, для которого не нашлось catch; «Uncaught ...» в консоли.
Стек вызовов (stack trace)
Цепочка функций с файлами и строками, которая привела к ошибке.
Проброс (rethrow)
Повторный throw пойманной ошибки, которую текущий код не умеет обработать.
cause
Исходная ошибка, сохранённая внутри новой при оборачивании.
Свой класс ошибки
Наследник Error с собственным name и полями (статус, код, поле формы).
Отклонённый промис
Промис в состоянии rejected; аналог выброшенной ошибки в асинхронном коде.
Необработанное отклонение
Отклонённый промис без .catch и без await в try.
AggregateError
Ошибка с массивом errors; её выбрасывает Promise.any.
Граница ошибок (error boundary)
Место, где ошибки ловят, записывают и превращают в понятное состояние интерфейса.
Логирование
Запись ошибок в журнал или сервис мониторинга, чтобы разработчик узнал о сбое.
Error-first callback
Соглашение, при котором ошибка передаётся первым аргументом колбэка.
