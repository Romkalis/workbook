Функция как объект: имя, текст, длина

Функция в JavaScript — объект. У неё есть свойства, как у любого объекта: name, length, метод toString(). Первые три задачи — про них.

1. getCurrentFunctionName — имя функции

getCurrentFunctionName() => 'getCurrentFunctionName'

У объявленной функции свойство name содержит её имя. Внутри функции её имя доступно как обычная переменная, поэтому функция может прочитать собственное свойство.

function getCurrentFunctionName() {
  return getCurrentFunctionName.name;
}

Старый способ — arguments.callee.name — в строгом режиме бросает ошибку, а ES-модули и классы всегда строгие. Имя есть и у стрелок, присвоенных переменной: const f = () => {} даёт f.name === 'f'.

2. getFunctionBody — текст функции

function hiHello() { console.log('hello world'); }
getFunctionBody(hiHello) => "function hiHello() { console.log('hello world'); }"
getFunctionBody() => ''

toString() у функции возвращает её исходный текст, ровно как он написан, с комментариями и пробелами. Тест вызывает функцию и без аргумента и ждёт пустую строку, поэтому нужна проверка.

function getFunctionBody(func) {
  return func ? func.toString() : '';
}

У встроенных функций текст не показывается: Math.max.toString() даёт function max() { [native code] }. Этим же свойством пользуется проверка в соседнем задании core-js-dates: она читает текст функции и ищет в нём комментарии.

3. getArgumentsCount — число параметров

getArgumentsCount([function(){...}, function myFunc(x) {...}, (a, b) => a * b]) => [0, 1, 2]

length у функции — число объявленных параметров до первого параметра со значением по умолчанию или rest-параметра.

function getArgumentsCount(funcs) {
  return funcs.map((fn) => fn.length);
}

Это не число переданных аргументов: function f(a, b) {} имеет length 2, как её ни вызывай. Ловушки: (a, b = 1) => {} — длина 1, (...args) => {} — 0. Библиотеки используют length, например, чтобы понять, ждёт ли колбэк next (так Express отличает обработчик ошибок с четырьмя параметрами).
