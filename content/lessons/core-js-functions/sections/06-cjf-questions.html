Чему равно ((a, b = 2, c) => {}).length?

1. Длина считает параметры до первого со значением по умолчанию.

Почему memoize хранит флаг, а не проверяет value === undefined?

Функция может вернуть undefined как настоящий результат, и проверка по значению вызывала бы её повторно.

Что такое замыкание в одном предложении?

Функция вместе с переменными окружения, в котором она создана; она видит их и после того, как внешняя функция завершилась.

Почему исходный файл задания падает на npm test?

Линтер находит лишние пустые строки (правило Prettier). Лечится npm run lint:fix.
