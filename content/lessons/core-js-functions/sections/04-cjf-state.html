6. memoize — запомнить результат

const memoizer = memoize(() => Math.random());
memoizer() => случайное число; memoizer() => то же число

Тест считает вызовы: исходная функция должна выполниться ровно один раз.

function memoize(func) {
  let cached = false;
  let value;
  return () => {
    if (!cached) {
      value = func();
      cached = true;
    }
    return value;
  };
}

Почему отдельный флаг cached, а не проверка value === undefined? Функция может честно вернуть undefined, и тогда проверка по значению вызывала бы её снова и снова. Эта версия запоминает один результат для функции без аргументов. Мемоизация с аргументами хранит Map «аргумент → результат», такой пример есть в задачах урока Design Patterns (кеш загрузки).

7. retry — повторить при ошибке

retry(fn, 3)() — вызывает fn, пока она не перестанет бросать ошибку, не больше 3 раз
function retry(func, attempts) {
  return () => {
    let lastError;
    for (let i = 0; i < attempts; i += 1) {
      try {
        return func();
      } catch (err) {
        lastError = err;
      }
    }
    throw lastError;
  };
}

Условие не уточняет, означает ли attempts число всех попыток или число повторов после первой. Тест проходит при обоих прочтениях: функция успешна с третьей попытки, а попыток три. Здесь выбрано «всего попыток»: так понятнее при чтении вызова. Если все попытки провалились, бросается последняя ошибка — без этого retry молча вернула бы undefined, и вызывающий код не узнал бы о сбое. return внутри try сразу выходит и из цикла, и из функции. Асинхронная версия с паузами между попытками — в задачах урока Async JS.
