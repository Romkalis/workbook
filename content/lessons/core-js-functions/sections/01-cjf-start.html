Задание и правила

core-js-functions — 10 функций в файле src/functions-tasks.js. Цель — научиться работать с функциями как со значениями: читать их свойства, возвращать функции из функций и хранить состояние в замыканиях. Условие каждой задачи — в комментарии над функцией, примеры — в @example, тесты — в test/functions-tests.js.

Как запустить и сдать

  1. Сделать форк репозитория и склонировать свой форк.
  2. npm install — поставить Mocha, ESLint (правила airbnb) и Prettier. Node.js лучше 22-й версии: проверяющая система работает на ней.
  3. В функции раскомментировать параметры, удалить throw new Error('Not implemented'), написать решение.
  4. npm test — сначала линтер, потом тесты. Нерешённые задачи показываются как pending.
  5. Закоммитить, запушить в форк, в RS App выбрать задание и нажать Submit.

Любая ошибка ESLint — 0 баллов за всё задание. Подвох: исходный файл задания (проверено 20.11.2026) сам не проходит линтер — между getPolynom и memoize лишние пустые строки, Prettier на них ругается. Первым делом запустите npm run lint:fix, и перед сдачей — ещё раз npm run lint. Про настройку линтера — урок Линтеры, форматтеры и Husky.

Пул-реквест с ответами в исходный репозиторий открывать нельзя — только свой форк. Решения ниже — один из вариантов: полезнее сначала решить самому, потом сравнить. Теория по функциям — MDN: Functions и Closures; про чистые функции и функции высшего порядка — урок Functional Programming.
