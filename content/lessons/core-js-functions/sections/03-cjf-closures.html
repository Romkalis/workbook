Функции, которые возвращают функции

Следующие задачи возвращают новую функцию, которая «помнит» переменные места, где её создали. Это замыкание: функция плюс окружение, в котором она объявлена.

4. getPowerFunction — степень как функция

const power2 = getPowerFunction(2); power2(4) => 16
const power05 = getPowerFunction(0.5); power05(16) => 4
function getPowerFunction(exponent) {
  return (x) => x ** exponent;
}

Возвращённая стрелка запомнила exponent. Каждый вызов getPowerFunction создаёт новое окружение, поэтому power2 и power05 не мешают друг другу. Оператор ** — то же, что Math.pow, но короче.

5. getPolynom — многочлен по коэффициентам

getPolynom(2, 3, 5) => y = 2*x^2 + 3*x + 5
getPolynom(1, -3)   => y = x - 3
getPolynom(8)       => y = 8
getPolynom()        => null

Коэффициенты идут от старшей степени к младшей. Можно для каждого считать c * x ** (n - 1 - i), но удобнее схема Горнера: 2x² + 3x + 5 = (2·x + 3)·x + 5. Аккумулятор на каждом шаге умножается на x, затем прибавляется очередной коэффициент.

function getPolynom(...coefficients) {
  if (coefficients.length === 0) return null;
  return (x) => coefficients.reduce((acc, c) => acc * x + c, 0);
}

Проверим на x = 2: 0·2 + 2 = 2, 2·2 + 3 = 7, 7·2 + 5 = 19. Тест ожидает 19. Схема Горнера делает одно умножение на коэффициент и не возводит в степень, поэтому её используют и в вычислительной математике (из общих знаний). null для пустого списка — требование условия, хотя по смыслу естественнее был бы многочлен-ноль.
